# 整理規範（給整理 agent）

目標：把 `extracted/pages/*.md`（逐字抄錄的書頁）與 `extracted/figures/`（圖）整理成
**每個操作方法一份文件**，人讀得懂、LLM 也能精確解析與執行。**全部用繁體中文撰寫**，
術語沿用書中原詞（K 線、紅K/黑K、頂雙黑、底雙紅、停損、補進場、反手……）。

## 輸入

- 頁面檔：`extracted/pages/<IMG>.md`，frontmatter 有 `book`、`pages`、`chapter`。
  用 `grep -l "chapter: .*<章名關鍵字>" extracted/pages/*.md` 找出你負責章節的所有頁面，
  **依頁碼排序後完整讀完**。注意章名寫法可能有空格差異（例：`第三章頂底母子訊號` / `第三章 頂底母子訊號`）。
- 圖檔：`extracted/figures/`。頁面檔裡的 `![...](../figures/xxx)` 與「圖說」段落描述了每張圖。
  需要時可以直接 Read 圖檔確認細節。
- 照片只拍了部分頁面，章節中可能有缺頁。**不要腦補缺頁內容**，在文件中標明缺哪些頁。

## 輸出

- 位置：`methods/<書簡稱>/`，書簡稱為 `期貨奇績2` 或 `期貨奇績3`。
- 檔名：`<書代號>-<章號兩位數>-<方法名>.md`，例：`q3-01-頂底雙紅黑.md`、`q2-06-RSI背離.md`。
  書代號：期貨奇績2 → `q2`，期貨奇績3 → `q3`。
- **一個操作方法一份檔案。** 同一型態的多空鏡像（例：頂雙黑放空 / 底雙紅作多）寫在同一份，
  分別列出多方與空方規則。一章若有多個獨立方法（例：第八章的「五分鐘順向策略」與「均線順向策略—豬陽訊號」），
  就拆成多份。另寫一份章節總覽 `<書代號>-<章號>-00-章節總覽.md`，只在該章有 ≥2 個方法時需要。
- 圖片引用用相對路徑：`![圖 1-5](../../extracted/figures/期貨奇績3-fig-1-5.jpg)`（SVG 同理）。

## 每份方法文件的格式

```markdown
---
id: q3-01-頂底雙紅黑
name: 頂雙黑 / 底雙紅

source_pages: [14, 15, 18, 19, ...]      # 實際用到的頁碼
missing_pages: [16, 17]                   # 本章範圍內沒有照片的頁
instrument: 台指期                        # 書中適用商品
timeframe: 1分鐘K線                        # 書中所用週期（若多個全列）
direction: 多空皆可                        # 多 / 空 / 多空皆可
category: 反轉訊號                          # 反轉 / 順勢 / 突破 / 背離 / 開盤 / 選擇權 ...
indicators: [K線]                          # 用到的指標（均線、RSI、KD、PVT、SAR…）
related: [q3-02-V字轉折]                    # 相關方法 id

# 頂雙黑 / 底雙紅

> 一句話摘要：……

## 1. 核心概念
為什麼這個訊號有效、作者的市場觀點（用自己的話濃縮，但不得偏離原意）。

## 2. 適用前提
市場狀態、時段、位置（盤中高低點…）等前提條件。

## 3. 訊號定義
用**編號條列**、**可逐條判斷真假**的條件寫出。數字門檻一律寫明（例：「幅度 ≤ 20 點」），並附出處頁碼（p.15）。
多方、空方分開列。

## 4. 進場
何時、以什麼價格進場；立刻進場 vs 等拉回；補進場條件。

## 5. 停損
停損位置與點數；停損後是否反手。

## 6. 出場 / 停利
停利、移動停損、出場訊號。書中沒寫就寫「書中未明確說明」。

## 7. 過濾：不做的情況
例：幅度過大、非盤中極端點、跳空…… 每條附頁碼。

## 8. 範例解析
逐一列出書中範例圖：圖片、圖號、圖說，並以條列說明「這張圖示範了哪條規則、進出場點在哪、結果如何」。

## 9. 作者提醒與常見錯誤

## 10. 規則速查（Checklist）
- [ ] 條件一
- [ ] 條件二 …

## 13. 原文出處

## 原則

1. **忠於原文**：所有規則、數值都要能在原文找到，附頁碼。推論必須標註「（推論）」。
2. **精確**：避免模糊詞，把原文的條件拆成可判斷的原子條件。
3. **完整**：原文每個範例圖都要在「範例解析」出現；每條例外/過濾規則都不能漏。
4. **易讀**：短句、條列、表格優先；專有名詞第一次出現時簡短解釋。
5. 只寫你負責的章節檔案。不要 commit。

## 完成時回報

簡短回報：產出的檔案清單（每份一句話說明方法）、缺頁/存疑事項、以及你用到的**術語清單**
（術語：一句話定義），供後續彙整成總術語表。
