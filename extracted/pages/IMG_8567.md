**圖 6-58**

> 圖說（figure notes）：台指期近分時走勢圖，左上角報價列標示「BX003台指期近 1031015 12:01開8694.00 高8696.00 低8693.00 收8694.00 量159」。上方為 K 線圖，下方為「自訂界限RSI指標」圖。K 線走勢先上漲至最高點 8763.00（標示紅色圓圈字母 A），A 右側稍下方標示紅色圓圈字母 C，A、C 之間以一條弧線（似箭頭曲線）連接。價格自 A 附近開始下跌，另有一條紅色斜直線自 A 下方延伸至下方 B 點附近。B 點（紅色圓圈字母 B）與其右側一個紫色圓圈（無字母標示）相鄰，B 右上方另標示一水平線段並文字「停損位置」。B、紫色圓圈下方有白底紅框文字方塊「倒N型空訊」，以紅線指向 B 與紫色圓圈一帶。圖左上角另有兩行黑色小字說明：「合A開始出現倒N型至D位置變大，不宜當作放空操作。」價格其後持續走低，最低點標示價位 8670.00，之後小幅反彈、盤整震盪，最終在圖右側回升至約 8700 附近收尾。下方 RSI 圖中，對應 A 的位置為一波峰（紅色圓圈標示字母 A，數值超過 90），對應 B 的位置為一波谷（紅色圓圈標示字母 B，數值低於 10 的嚴重超賣區）。RSI 其後在 10～90 區間反覆大幅震盪，多次觸及嚴重超買、超賣區。

自超買區發動的放空訊號位置，其 RSI 數值不能已經穿過嚴重超賣區，儘管在嚴重超賣區可能出現續跌的鈍化行情，但誰能判定行情一定呈現鈍化走勢呢？如圖 6-58 裡標示 A 為 RSI(5) 穿過 90 以上的峰位，雖然價格自 A 後，並沒有再創新峰位，因此開始觀察向下是否出現倒 N 型空訊，結果在標示 D 位置形成倒 N 型，看似符合空訊條件，但要注意在 B 位置，RSI(5) 已經跌破嚴重超賣區 10 界限，應該尋找可能的買訊或者自 B 開始的鈍化倒 N 型空訊，而且從 A 到 D 的距離，已經超過 40 點，都顯示 D 位置不宜作為放空訊號，因此自 B 開始反彈到 C 峰位後，我們要的是拉回不破 B 點，再向上過 C 的正 N 型買點，或者是自 C 開始向下破 B 形成的倒 N 型空訊，在本例是發生從反彈的 C 峰位，向下呈現三段式倒 N 型空訊。

![圖 6-59](../figures/期貨奇績2-fig-6-59.jpg)

**圖 6-59**

> 圖說（figure notes）：台指期近分時走勢圖，左上角報價列標示「BX003台指期近 1041001 11:28開8304.00 高8304.00 低8298.00 收8301.00 3.00(-0.04%) 量419」。上方為 K 線圖，下方為「自訂界限RSI指標」圖。K 線走勢自左段低檔盤整（最低點標示價位 8116.00）後急漲一根長紅 K，漲至標示紅色圓圈字母 A 處，A 右下方有紅色文字方塊「沒有層級2谷點」，以線條指向 A 下方那根急漲 K 棒，說明此段漲勢缺乏一個層級 2 的谷點。價格自 A 續漲整理，途中依序標示黑色圓圈數字「0」「1」、紅色圓圈字母 B、黑色圓圈數字「2」、白底紅框文字方塊「買」（緊鄰黑色圓圈數字「3」右側）、紅色圓圈字母 C，最終漲至最高點 8325.00（標示紅色圓圈字母 D，位於圖右上方），D 右側另有紫色圓圈數字「2」與「3」相鄰標示。D 之後價格小幅拉回又回升，於圖右側在 8300 附近盤整收尾。下方 RSI 圖中，由左至右依序標示紅色圓圈字母 A（波峰，接近 90）、B（波峰，接近 90）、C（波峰，超過 90）、D（波峰，超過 90），RSI 曲線在 A、B、C、D 各波峰之間數次回落至 50～70 區間，未觸及嚴重超賣區。

到達嚴重超買區 90 後產生的續漲的鈍化買進訊號，最重要的步驟在於確定自最高點拉回形成一個層級 2 谷點，才能再進行向上 N 型三波，如果拉回無法產生層級 2 谷點，就不能隨便拉推升三波當作 N 型，如圖 6-59 裡，當盤中在 A 位置創新高時，RSI(5) 亦到達嚴重超買區 90，此時，行情走倒 N 型則為空訊，若拉回一波後，向上走 N 型過 A 峰點，則為鈍化買進訊號，事實上 A 之後，既沒有走倒 N 型產生空訊，其拉回亦沒有產生層級 2 谷點，只能繼續觀察行情，直到 B 位置，RSI 再次穿越 90，行情隨即折回形成標示 0 的層級 2 谷點，然後出現向上三波的 N 型在標示 3 位置形成鈍化買點。C 位置雖再次出現 RSI 來到 90 以上，除非它產生向下倒 N 型空訊，不然若持續出現鈍化買點則忽略訊號，至於 D 位置雖有倒 N 型空訊，但臨近當天收盤，亦採取忽略。
