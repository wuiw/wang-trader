**圖 4-24**

> 圖說（figure notes）：台指期近（BX003）分時走勢圖，報價列顯示「1040822 10:49開8325.00 高8329.00 低8325.00 收8328.00 3.00(0.04%) 量130」，左上標示「昨日區間」。圖中三條水平線由上而下為「昨高」（紅線）、今開（藍線，位置略低於昨高）、「昨收」（暗紅線，位於下方）。開盤附近先出現標示 Ⓐ（紅色圓標，位於「昨收」線上方起漲處），行情上攻至標示 Ⓑ（紅色圓標）高點後受阻於昨高之下，隨即反轉向下，中途以文字框「觸及停損」牽引指向標示 Ⓓ（於今開關卡附近）。價格續跌至標示「1」、「2」附近低點，並在虛線「停損位置」下方觸及最低點約8260，以文字框「空」與圓標 Ⓒ／編號「3」標示放空訊號K線。隨後行情止跌反彈，於標示 Ⓔ 附近突破今開關卡，再上攻至編號「1」、Ⓕ／「3」處，並以文字框「買」牽引指向該突破K線。突破後價格一路走高越過昨高，於8340.00附近觸頂（圖右上標示），隨後在8290~8330區間反覆震盪至圖右緣。

在圖 4-24 的案例裡，昨高與昨收距離達 65 點，顯然前一天震盪中空方制壓積極，而今天跳高 25 點開盤，卻是在困在昨高之下，因為標示 A 在今開之下不及 3 根 K 線，不能據此發展買訊，當多頭攻抵 B 峰點，便無力再向昨高推進，開始向下跌破開盤價，同時跌破關卡後就沒有一根 K 線返回開盤之上，符合關卡優勢要求，因此在標示 C 位置形成放空三步驟，但這個空訊並沒有引導價格進一步向下跌破昨收（平盤），反而立即逆轉上攻，當成空訊在標示 D 位置停損，而後更朝開盤之上挺進，並從標示 E 向上產生過關卡買進訊號，在標示 F 可以進場做多單，價格持續向昨高挑戰，好不容易突破昨高，卻無法站穩，隨即拉回，超過 15 點折返，多單觸及停利出場。

## p.151

![圖4-25](../figures/期貨奇績2-fig-4-25.jpg)

**圖 4-25**

> 圖說（figure notes）：台指期近（BX003）分時走勢圖，報價列顯示「1050712 10:15開8776.00 高8777.00 低8774.00 收8774.00 2.00(-0.02%) 量239」，左上標示「昨日區間」。圖左下角起點8722.00，行情開盤前段先上漲至一小段高檔區（以黃色網底標示的紅黑K線群，上緣有綠色虛線水平延伸），標示「0」於此高檔區起點、圓標 Ⓐ 於高點、圓標②於隨後拉回的低點，文字框「2不可高於0，不像倒N型」以線牽引指向此拉回K線，說明此處反彈峰點高於起始0點、不符合倒N型定義。價格續於「開盤」水平線（藍線）附近整理，出現藍色圓標①與紅色①、②等多個小轉折，另有黃色網底標示一段密集K線（含③、B、C等標記）與紅色水平線「昨高」交會。行情其後於「0」「0」兩個起點標示（位於「昨收」綠線附近）之下方盤整，再度上攻，於編號「1」、圓標 Ⓓ 附近以文字框「買」牽引指向突破K線（編號「3」），隨後行情一路走高，最高觸及8795.00（圖右上標示），之後在8770~8790區間震盪走低收尾。

在觀察 N 型或倒 N 型三步驟時，要特別注意起始 0 點必然是整個 N 型結構的最低谷點，拉回的谷點(2)，絕對不能低於起始 0 點；而在倒 N 型結構中，起始 0 點是位處結構的最高峰點，反彈的峰點(2)，絕對不能高於起始 0 點，任何違反這樣的線形出現時，只能重新尋找 N 型或倒 N 型。如圖 4-25 的狀況，跳昨高開盤後，橫盤不到 10 分鐘，價格開始向下跌破開盤價，可以從標示 A 開始尋找倒 N 型三步驟，但反彈的峰點(2)出現高於起始 0 點，便不須再數，必須重新尋找，接著我們可以再從 B 點觀察向上突破昨高的 N 型買進步驟，前二項要求都符合，當突破藍色(1)即形成買進時，卻發生黑色標示(1)影線突破收盤未突破現象，雖然稍後會在標示 D 位置出現無遮蔽買點，但我們亦可以從 C 為起始 0 點，以開盤價為關卡，進行 N 型買進步驟計數。
