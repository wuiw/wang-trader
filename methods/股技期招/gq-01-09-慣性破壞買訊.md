# 慣性破壞買訊

> 一句話摘要：整理格局中若連續超過20個交易日都沒有一根K線收盤突破前2日高（形成盤整期間的K線慣性），一旦出現一根大漲K線收盤突破此慣性（下斜式整理須同時突破區間下降趨勢線），即為買進訊號；停損可設在該大漲K線最低點，或以收盤價向下7%為停損。

## 1. 核心概念

- 價格陷入回檔整理格局時，投資人常被突然一根上漲K線引誘進場，但後續行情仍脫離不了盤整，造成停損或苦等真正突破；整理格局中價格上上下下的過程，同樣存在K線慣性，這種現象會持續到慣性受破壞為止，慣性被破壞即意謂盤整區間結束、新趨勢行情啟動（p.41）。
- 這種慣性持續的時間，須先界定**至少超過20個交易日**（代表盤整持續超過一個月），顯示行情處於波段漲幅滿足後的中段整理；若整體推升不是一波到頂的單峰漲勢，盤整結束後代表另一個漲勢開始，破壞整理區間K線慣性即是一個潛在的起漲買點訊號（p.41）。
- **盤整格局分兩種類型**（p.42，圖1-43）：
  - **水平式橫向整理**：上下界距離不大，維持在**二成以內**的空間擺盪，慣性被破壞後的突破效果愈好。
  - **下斜式整理**：價格拉回呈現三段式修正（形如倒「N」字），其上界峰點可連成一條下降趨勢線；此類格局出現破壞慣性現象時，最好能同時突破其下降趨勢線。
- 慣性破壞時須檢視改變慣性的K線品質：除了須是**大漲K線**外，理想情況下其收盤宜突破均線壓力，並（依整理型態）突破區間內的下降趨勢線（p.42、p.46）。

## 2. 適用前提

- 整理（慣性持續）期間須先確立**至少超過20個交易日**（p.41）；書中各範例實際累計天數不一（21、24、26、28、29、30、32天皆有出現），但均超過此門檻。
- 期間內的慣性定義：連續期間內沒有任何一根K線**收盤突破前2日**區間最高點（p.41、p.43–49）。

## 3. 訊號定義（多方）

1. C1：整理格局持續累計**超過20個交易日**，期間內沒有任何一根K線收盤突破前2日區間最高點（K線運動慣性）（p.41、p.43）。
2. C2：出現一根**大漲K線**，其**收盤**一舉突破先前維持已久的「不過2日高」慣性 → 慣性破壞（p.41–49）。
3. C3（依整理型態而定的確認條件）：
   - 若為**下斜式整理**（倒N字修正，可連成下降趨勢線）：訊號K線須**同時**收盤突破區間內的下降趨勢線（p.42、p.45、p.50–51）。
   - 若為**水平式整理**（窄幅橫向）：不須另以下降趨勢線檢定，只須確認訊號K線為大漲K線即可（p.47）。
4. C4（品質加分條件）：訊號K線收盤宜同時突破**均線壓力**（p.46）。
5. C5（次級確認，N字二次確認）：若訊號K線雖屬大漲K線，卻**未突破**下降趨勢線，須等待後續某根K線**收盤突破**該大漲K線的最高點（線圖呈現「N」字形狀的二次突破），才可進場（p.48–49）。

## 4. 進場

- **直接進場**：C1–C4 皆符合時，於訊號K線（大漲K線）收盤時進場買進（p.42–51，多篇範例）。
- **N字二次確認進場**：若大漲K線未突破下降趨勢線（C3不完全符合但C2、C4基本符合），須待 C5 成立（後續K線收盤突破大漲K線最高點）之當根K線收盤才進場（p.48–49，圖1-49）。

## 5. 停損

- 二擇一（原文未強制指定何者優先，兩者皆為原文明列的選項）：
  1. 以該根大漲K線（訊號K線）的**最低點**做為停損位置（p.42、p.47、p.47：「並以該K線最低點做為停損」）。
  2. 以訊號K線**收盤價向下7%**做為停損位置（p.43、p.47：「或者沒有跌破以標示3之K線收盤向下7%為停損位置」；「或以固定7%為停損位置」）。

## 6. 出場 / 停利

- 只要停損（第5節二擇一之一）未被觸及，就應以**波段角度持有**，原文明言「就應該持波段的角度去持有，好好賺一波」（p.44）。
- 書中未提供明確的停利目標點數或另立的出場訊號；出場依據僅為第5節的停損規則。

## 7. 過濾：不做的情況

1. 慣性被破壞的K線若不是大漲K線（例如只是小漲K線），且後續也沒有大漲K線補強其不足，買進訊號失敗機會大增，不宜貿然進場（p.45–47，圖1-47反例）。
2. 小漲K線若同時**未穿越均線**（仍受均線壓力掣肘）、也**未突破**區間內的下降趨勢線，多項濾網皆不符合時，不宜進場做買進動作（p.46–47）。
3. 在**下斜式整理格局**中，若訊號K線僅突破區間但**未突破下降趨勢線**，並非正確買訊，尤其在價格已推升一段時間後的潛在高檔區，更要特別小心（p.50，圖1-52反例）。
4. 整理期間累計未達「超過20個交易日」的短暫盤整，不在本方法適用範圍內（推論，依第1、2節的前提條件）。

## 9. 作者提醒與常見錯誤

- 破壞慣性的K線若非大漲K線，或雖是大漲K線卻未突破下降趨勢線／均線壓力，訊號的失敗機會就大增；透過「大漲K線＋突破下降趨勢線／均線」這層濾網結構，可以有效摒除錯誤的訊號（p.45–47）。
- 訊號K線僅突破區間、未突破下降趨勢線時，可再觀察後續是否出現「N」字形二次突破，讓原本不符合濾網的訊號獲得再確認，而非直接放棄或直接進場（p.48–49）。
- 在下斜式整理格局、且價格已推升一段時間的潛在高檔區，若訊號K線只突破區間卻未突破下降趨勢線，須特別提高警覺，此類訊號較易失敗（p.50）。

## 10. 規則速查（Checklist）

- [ ] 整理格局累計超過20個交易日，期間K線收盤不曾突破前2日區間最高點
- [ ] 出現大漲K線收盤突破此「不過2日高」的慣性
- [ ] 下斜式整理：訊號K線須同時突破區間下降趨勢線；水平式整理：僅需確認為大漲K線
- [ ] （加分）訊號K線收盤宜同時突破均線壓力
- [ ] 若大漲K線未突破下降趨勢線，待後續K線收盤突破該大漲K線最高點（N字二次確認）才進場
- [ ] 停損：訊號K線最低點，或收盤價向下7%（二擇一）
- [ ] 停損未觸及前，以波段角度持有
