# 第六章 背離訊號總整理（章節總覽）

## 本章共收錄 4 個獨立操作方法

| 檔案 | 方法 | 使用指標 | 核心邏輯 |
|---|---|---|---|
| `q2-06-01-假性創新高創新低背離.md` | 假性創新高 / 假性創新低背離（假面峰谷背離） | 無（純 K 線價格） | 影線創新高（低），但收盤價未同步創新高（低），收盤跌破（突破）該假性峰（谷）點濾網即為訊號 |
| `q2-06-02-KD背離訊號.md` | 一分鐘 KD 背離訊號 | KD、MA8、SAR | 價格創新高（低）而 KD 未同步創高（低），兩端點須分別滿足 D 值 >80/<80（或 <20/>20）門檻，中間僅夾一次反向交叉，再次交叉時進場 |
| `q2-06-03-RSI背離訊號.md` | RSI 背離訊號 | RSI(5) | 價格創新高（低）而 RSI 未同步創高（低），兩端點須落在嚴重超買 90 以上／超賣 10 以下，時間距離 ≤30 根 K 線，RSI 穿越（跌破）50 時進場 |
| `q2-06-04-RSI鈍化N型倒N型訊號.md` | RSI 鈍化 N 型 / 倒 N 型訊號 | RSI(5) | RSI 觸及極端區後即進入「鈍化」狀態，不等第二個背離端點，改用價格層級 2 正 N 型／倒 N 型 123 步驟判斷進出場 |

## 章節脈絡與方法間關係

本章依「背離的判斷依據」由簡到繁分為三大類：

1. **純價格背離**（q2-06-01）：完全不用指標，只比較 K 線的影線極端值與收盤價是否同步創新高（低），是全章最基礎的判斷邏輯，也是後兩種指標背離的概念原型（p.189 章首段落命名「假面峰谷背離訊號」；內容延伸至 p.190–199、202）。
2. **KD 背離**（q2-06-02）：p.203 起以明確的段落標題「一分鐘 KD 背離訊號」開頭，將背離判斷邏輯套用在 KD 指標上，並提出「D 值門檻＋唯一反向交叉」的量化條件、跨日跳空的無縫接軌規則，以及訊號失敗後的停損反手規則（p.203–217）。
3. **RSI 背離與鈍化**（q2-06-03、q2-06-04）：p.220 起將同樣的背離邏輯套用在 RSI 指標上（q2-06-03），並提出更嚴格的極端區門檻（90/10）與時間距離濾網（30 根 K 線）；p.234 起（因 p.228–233 缺頁，確切轉折點無法百分之百確認）進一步發展出「RSI 鈍化」概念（q2-06-04）——當 RSI 長時間停留在極端區、背離訊號證據力減弱時，改用價格本身的正 N 型／倒 N 型三段式結構（123 步驟）判斷進出場，並訂出訊號衝突（只認第一個出現者）與同類型訊號再現時立即反手換手的規則。

**q2-06-03 與 q2-06-04 的切分依據**：p.233 原文以獨立小標題「一分鐘 RSI 正 N 倒 N 訊號」正式開啟 q2-06-04 的內容（此頁補拍後確認），且 p.245 原文明確將「RSI 的 N 型或倒 N 型訊號」與「RSI 背離訊號」並列討論兩者發生訊號衝突時的處理方式，證實兩者在書中被視為不同的訊號類型，因此本次整理將其拆為兩份獨立文件；但兩者共用同一套 RSI 極端區觸發前提，操作時應合併參考。

**共通的停損邏輯**：三種指標背離方法（KD、RSI 背離、RSI 鈍化）在停損設置上，都提到「取兩種算法中較嚴謹（點數較低）者」，並儘量把風險控制在 20 點以內；假性創新高低背離（q2-06-01）也遵循相同的 20 點原則，但停損算法的具體名稱（0 位法、端點極端值法、均線訊號停損法）依方法略有不同，使用時請對照各檔案第 5 節。

## 全章共用術語（詳細定義請見各方法文件第 3、9 節）

- **背離（背離向上／背離向下）**：價格與指標（或收盤價）走勢不同步——價格創新高但指標／收盤未創新高（背離向下），或價格創新低但指標／收盤未創新低（背離向上）。
- **假性創新高／假性創新低**：K 線影線（最高／最低點）創新高（低），但收盤價未同步創新高（低），代表該極端點是「假面」，不具備真正的動能延續力。
- **鈍化**：0～100 震盪型指標（RSI、KD、威廉指標等）長時間停留在超買（超賣）極端區的現象，此時背離變得像常態、反轉證據力轉弱。
- **層級 2 轉折點**：本章多處引用的價格結構概念（書中其他章節定義的「N 型／倒 N 型」轉折層級之一），用於界定 N 型、倒 N 型或背離端點之間必須經過的中繼轉折點。
- **正 N 型／倒 N 型**：由層級 2 峰谷點構成的三段式價格結構；正 N 型為向上三波（買訊結構），倒 N 型為向下三波（空訊結構），K 線收盤突破（跌破）結構中的關鍵峰（谷）點即完成 123 步驟訊號。
- **無縫接軌**：背離兩端點跨越交易日時，若開盤跳空點數在 10 點以內，視為與前一日走勢無縫接軌，可延用前一日尾盤的超買超賣紀錄；跳空超過 10 點則不得延用。
- **0 位設法**：RSI 背離方法中提及的一種停損設置法，以 RSI 對應之特定價位為停損參考（原文用語，具體換算方式書中未展開說明）。

## 使用建議

閱讀順序建議依檔名編號 01→04，先掌握最基礎的純價格背離判斷邏輯（01），再理解 KD（02）與 RSI（03）如何用指標把背離量化，最後理解鈍化狀態下如何改用 N 型／倒 N 型價格結構替代背離判斷（04）。四份文件之間的停損、訊號衝突處理邏輯有共通之處，建議交叉參照。
