# SAR 轉化為買賣訊號

> 一句話摘要：以 SAR（Stop And Reverse）轉折取代第一章的均線，做為判斷多空控盤方的依據；當 K 線**影線**穿越/跌破 SAR 後尋找層級2轉折峰谷點，折返過程要求**影線不觸及 SAR**（而非收盤不破），再以收盤突破/跌破的「1-2-3」N型/倒N型結構產生買賣訊號，停損公式與第一章相同。

## 1. 核心概念

第一章「穿越均線買賣策略」的三大步驟，若把「突破均線」換成「穿越 SAR 停損停利點」，一樣能形成完整的操作策略（p.67）。SAR 在趨勢行情中，不管向上或向下，都能展現優質的輔助出場效果；而在行情窄幅區間游走時，SAR 會不斷被上下穿越（一會在價格上方當空方防護，一會又移到下方當多方防守），這個特性反而讓操作者容易辨識盤整或趨勢盤（p.67）。

本章與第一章最關鍵的差異在於「折返段的檢驗方式」：第一章以**K線收盤**是否穿越均線來判斷折返是否失敗；本章因為 SAR 本身有「影線一觸及即翻轉到K線另一側」的特性，改以**K線影線是否觸及 SAR**做為檢驗標準——折返段中任一根K線的影線只要觸及 SAR，SAR 立刻翻轉到區間高（低）點，該次計數即失敗、須重新開始（p.67）。

## 2. 適用前提

- 一分鐘K線圖，台指期近月商品（p.67-91各圖報價列所示）。
- 需搭配 SAR 指標繪製於K線圖上。
- SAR 在窄幅盤整時會被頻繁上下穿越，此特性可用來輔助辨識盤整格局（p.67，p.69圖2-2：「橫盤走勢無法形成N或倒N字123形式」）。
- 其餘適用前提（時段限制等）書中未見額外說明，可比照第一章。

## 3. 訊號定義

### 3.1 買進三步驟（多方，p.67-68，圖2-1）

1. **C1** K線**影線**向上穿越 SAR 後，形成第一個層級2轉折**峰點(1)**。此峰點有時就出現在突破 SAR 當根K線本身（前提是不能出現在觸及 SAR 之前）；也可能是突破隔幾根之後，價格拉回測試 SAR 時才形成（p.68）。
2. **C2** 拉回過程中，**所有K線的影線都不觸及 SAR**（不是收盤不破均線），形成層級2轉折**谷點(2)**。K線影線只要觸及 SAR，SAR 立刻由原本在K線下方翻轉至區間最高點，該次折返視為失敗（p.67）。
3. **C3** 其後K線**收盤**向上突破峰點(1)，即形成買進訊號(3)（p.67-68）。

整個過程即「K線突破SAR後，形成層級2轉折點的N型運動」（p.68）。

### 3.2 放空三步驟（空方，p.67-69，鏡像規則）

1. **C1'** K線**影線**向下跌破 SAR，SAR 隨即翻轉至K線上方的區間高點，形成第一個層級2轉折**谷點(1)**。
2. **C2'** 反彈過程中，**所有K線的上影線都不觸及 SAR**，形成層級2轉折**峰點(2)**。
3. **C3'** 其後K線**收盤**向下跌破谷點(1)，即形成放空訊號(3)。

整個過程即「K線跌破SAR後，形成層級2的倒N型運動」（p.67-68）。

### 3.3 潛在峰谷點的補進場（p.80，圖2-13）

- 谷點(1)形成後尋找反彈的潛在峰點(2)時，只要該K線**左邊**已有2根較低的K線，即可視為「潛在峰點」，**不必等右邊也出現2根較低K線的正式確認**；只要隔根立即出現K線收盤跌破谷點(1)，訊號即成立。書中強調：「如果去硬扯層級2峰點的右邊一定要有2根較低的K線，那就喪失絕佳的空點機會」。買方鏡像同理。

### 3.4 無遮蔽原則與水平濾網移動限制（p.70-73，圖2-3～2-6）

- 訊號同樣要求「無遮蔽」：若K線影線先穿越峰(谷)位但收盤未過關，而該K線的上（下）影線又比隔根K線的高（低）點更極端，則隔根即便收盤突破前高（跌破前低），仍會被前一根的影線「遮蔽」，不構成有效訊號，須等後續某根K線收盤真正突破遮蔽K線本身的高（低）點（p.70-71，圖2-3、圖2-4）。
- **水平濾網移動規則**：最初以突破/跌破SAR後第一個峰(谷)點的最高（低）點畫第一條水平濾網；若發生遮蔽，且遮蔽K線的隔根高（低）點低（高）於遮蔽K線本身，可把濾網移到遮蔽K線的最高（低）點，形成第二條水平線；若再度遮蔽，可再移動一次形成第三條水平線。**最初水平線加移動，總數以三條為限**（即最多移動兩次）；超過三條仍未能收盤突破濾網，該訊號**應放棄、不再等待**（p.72-73，圖2-5、圖2-6）。

### 3.5 層級2轉折點須確實符合左右K線條件（p.71，圖2-4）

- 若某轉折點左邊沒有超過2根較高（低）的K線，即不構成層級2轉折點，不能作為(0)/(1)/(2)起始點使用，即使外觀上行情已反轉，也不成立訊號（p.71：標示E「左邊沒二根較高K線」，故後續G不構成放空訊號）。

## 4. 進場

- 買進：C3 成立當根K線收盤進場作多。
- 放空：C3' 成立當根K線收盤進場作空。
- 潛在峰谷點補進場：見第3.3節，隔根收盤即突破/跌破谷(峰)點(1)時可提前視為訊號成立。
- 書中未見與第一章「隔日尾盤延續」相同的明文敘述，若日後補拍到相關頁面應再確認是否適用（見第12節）。

## 5. 停損

- **與第一章完全相同的公式，本章原文重新明確列出**（p.72-73）：
  - 買進：`停損位置 = 訊號K線收盤 − (10 + 買進訊號價格個位數)`
  - 放空：`停損位置 = 訊號K線收盤 + (20 − 放空訊號個位數)`
  - 若收盤為整數價位，停損點數固定20點（比照第一章）。
- 停損以**盤中價格觸及**為準（比照第一章慣例，本章圖例皆標示水平「停損位置」線）。
- **反向訊號優先於停損**：持倉尚未觸及停損時，只要出現反向訊號（符合完整三步驟），須**立即平倉並反手**操作，同時重新設定新方向停損，不可留在原部位情緒中觀望（p.70，圖2-3；p.82，圖2-15）。

## 6. 出場 / 停利

沿用與第一章相同的多種停利機制（可依行情特性擇一或搭配使用）：

### 6.1 固定點數折返停利（p.81-83，圖2-14～2-16）

- 預設獲利目標（15點或20點），達到後開始依創新高（收盤與最高點同時創新高，且不受前一根遮蔽）折返15或20點設定移動停利點；若K線收盤達目標但最高點被前一根遮蔽，須延遲到真正無遮蔽的K線才開始折返計算（p.81，圖2-14標示C、D）。

### 6.2 區間高低點停利（p.84）

- 獲利達到預設目標後，可改採「20根K線區間高低點」做為移動停利參考，機制與第一章的區間停利法（見 q2-01 第6.5節）一致。

### 6.3 SAR本身作為停利（p.85）

- 獲利達到預設目標後，啟用 SAR 做為停利防守點，以**K線收盤**突破/跌破 SAR 才平倉；若價格尚未達目標即用SAR做停利，容易因SAR被緩步行情頻繁上下穿越而失效，故仍須等目標達成才啟用（p.85）。

### 6.4 求不賠 / 反向訊號同時發生時的處理（p.82）

- 若行情已達到預設獲利目標後又折返回原訊號進場價位，或折返過程中同時出現反向訊號，宜選擇小賺或小賠一二點平倉出場，不必執著等待原定移動停利觸發（p.82：「宜選擇小賺或小賠一二點平倉出場」）。

### 6.5 持倉時間與操作次數（提醒，非硬性規則）

- 不必堅持等到1小時才離場；若持倉30分鐘仍不見大K線波動、進退兩難，也可選擇小賠/小賺離場，讓心情恢復平常心，再等下一個訊號（p.79）。
- 建議每日操作以3次為宜，不鼓勵無限制操作；當日第一次操作獲利已達30點以上，或連續兩趟操作皆獲利，可考慮收工休息（p.83，p.86）。

## 7. 過濾：不做的情況

1. **起始點到訊號確認距離 >50點 → 忽略**：從跌破/突破SAR前最近的層級2峰（谷）點(0)，到放空（買進）三步驟確認收盤(3)的距離，若超過50點，建議忽略，因為此時跌勢（漲勢）可能已經「表演完畢」，容易在極端點附近才出訊號形成陷阱（p.75，圖2-8；p.77再次確認50點上限）。書中亦提及部分風險承受度高的操作者選擇不設此濾網，但強調風險確實增加。
2. **同向訊號僅取第一次，除非中間出現足夠幅度的反向擺動**：在同一趨勢方向中，只取第一個同向訊號操作；除非兩個同向訊號之間，夾著一段**單筆幅度超過30點**的行情，或出現**三段式N型/倒N型**反向擺動，才能再取後續同向訊號，否則第二個（以後）同向訊號應忽略（p.77-79，圖2-10、圖2-11）。
3. **訊號產生過程反覆折返、行情持續墊高（破底）卻遲遲不成立，最終訊號已大幅偏離 → 忽略**：若期間每次潛在峰（谷）點皆因影線觸及SAR而失敗、須不斷重新計數，直到終於出現符合三步驟的訊號時，價格早已大幅偏離起漲（跌）點（書中舉例近90點）且耗時超過1小時，此類訊號宜忽略，不因「終於等到訊號」而急於進場（p.76，圖2-9）。書中未給出此規則的精確點數/時間門檻，僅以範例呈現（見第12節）。
4. **幅度過大的N型（倒N型）忽略**：訊號結構本身擺動幅度過大時，即使技術上符合，仍建議忽略（p.91，圖2-27「幅度過大的N型，採取忽略」），與規則1（50點濾網）精神一致，為同一原則的重申。

## 9. 作者提醒與常見錯誤

- 當多單尚未觸及停損卻已出現反向放空訊號時，須立即平倉反手，不可留在原有部位的情緒中觀望（p.70，p.74）。
- 起始點到訊號確認的幅度過大（如超過50點），或訊號產生過程反覆延遲、最終出現時已大幅偏離起漲點，即使技術上符合三步驟定義，仍可能是行情已經走到極端、隨時反轉的「陷阱」訊號；作者建議忽略此類訊號，但也承認部分高風險承受度的操作者選擇照做，需自行衡量（p.75-77）。
- 任何訊號都不具排他權，只要反向訊號成立，原先的訊號便要平倉，同時加入反向操作（p.70）。
- 同向趨勢中只取第一個訊號，其餘同向訊號除非中間有足夠反向擺動，否則不宜重複操作，避免對單一波段過度加碼（p.77）。
- 操作不必每天跟到收盤，達成滿意獲利（如單趟超過30點，或連續兩趟皆獲利）即可考慮休戰，享受生活品質，不必貪戰（p.83，p.86）。
- 建議每日操作以3次為宜，不鼓勵無限制地反覆進出（p.83）。

## 10. 規則速查（Checklist）

**進場（多方，空方鏡像）**
- [ ] K線影線穿越SAR，形成層級2轉折峰點(1)（C1）
- [ ] 折返過程所有K線影線皆未觸及SAR（C2）（注意：是影線不觸及，非收盤不破）
- [ ] 潛在峰谷點只需左側2根較低/高K線即可，不必等右側確認（補進場）
- [ ] K線收盤突破峰點(1)，且無遮蔽（C3）→ 買進訊號
- [ ] 若發生遮蔽，水平濾網最多移動2次（含首條共3條），超過則放棄訊號
- [ ] 起始點(0)到訊號確認收盤(3)距離 ≤50點
- [ ] 同向趨勢中為第一個同向訊號，或與前一同向訊號間已有>30點單波行情/三段反向擺動

**停損**
- [ ] 買進：停損 = 收盤 − (10 + 個位數)；整數價位固定20點
- [ ] 放空：停損 = 收盤 + (20 − 個位數)；整數價位固定20點
- [ ] 持倉未停損時出現反向訊號 → 立即平倉反手，設定新停損

**出場**
- [ ] 獲利達15/20點後啟動移動停利（固定點數折返 / 20根區間高低點 / SAR，擇一）
- [ ] 折返停利觸及＝盤中突破停利線超過1點
- [ ] 達目標後折返回訊號價位，或同時出現反向訊號 → 小賺小賠出場（求不賠）
- [ ] 持倉約30-60分鐘無明顯輸贏，考慮提前離場
