# 一分鐘穿越均線的買賣策略（均線三步驟訊號）

> 一句話摘要：以一分鐘K線收盤「突破／跌破均線後形成層級2轉折點，再折返不破均線，最後收盤再度突破／跌破轉折點」的三步驟，作為順勢買賣訊號，並以個位數規則設停損，搭配多種可替換的移動停利機制出場。

## 1. 核心概念

均線代表市場眾人的平均持有成本（p.1）。當眾人平均成本持續墊高，均線朝上，代表看漲預期形成羊群效應，價格愈漲愈高；反之亦然，直到偏見消失、情緒反轉，完成漲跌循環（p.1）。

作者認為單純「價格穿越均線」或「站上/跌破均線 N 根以上」的判斷方式，在盤整期間容易受窄幅假訊號干擾（p.1）。因此設計了一套「穿越均線三步驟」規則，要求價格突破均線後，還必須先出現一次不破均線的折返，再次收盤突破先前轉折點，才視為有效訊號，藉此大幅降低盤整雜訊（p.2）。

價格運動的基本模型為：(1) 衝刺 → (2) 休息（含反向拉回）→ (3) 再衝刺，形如 N 型（多）或倒 N 型（空）（p.2-3）。

訊號K線本身的漲跌點數也是品質指標：漲跌點過大，容易遭獲利回吐反噬；漲跌點過小，則表態不足，容易被對手看破手腳、反手擒拿（p.26，見第7節過濾規則1、4）。

## 2. 適用前提

- 僅用一分鐘K線圖，不借助其他指標來界定「趨勢」，僅以均線（書中圖例為 MA30）本身作為順勢依據（p.2）。
- 台指期貨一天交易約 5 小時、300 根一分鐘K線，本策略捕捉的是盤中微觀短趨勢（可能僅維持 20 分鐘），並非日線趨勢（p.2）。
- 每日訊號數約 1～5 次（p.25）。
- **其他商品適用性**（p.51）：本法亦適用海外期貨商品，但須依商品特性微調：
  - 成交量夠大、每分鐘皆有撮合（無真空缺口）的商品，可沿用一分鐘K線。
  - 若價格常出現數分鐘無成交的真空狀態，不宜用一分鐘K線，須改用五分鐘K線圖，且每日K線根數至少須有120根以上（即每日交易時數在10小時以上）。
  - 停損點數不一定要沿用第5節的個位數公式，可依操作者風險承受度微調，例如改採「步驟2」的高低點作為停損位置；若進場點到停損點仍超過操作者可承受範圍，應考慮縮小部位、改採固定點數停損，或更換操作商品。

## 3. 訊號定義

### 3.1 層級2轉折峰谷點（位）的定義（p.4-5，圖1-2、圖1-3）

- **層級1峰點**：某K線最高點，左右各一根K線的最高點都較低。
- **層級2峰點**：某K線最高點，左右各兩根K線的最高點都較低（左右兩根K線彼此不必分高低，只要都低於峰點即可）。
- 峰位可以是「單峰」（一根K線）、「雙峰」（兩根等高K線相鄰，或中間夾一根較低K線的「變形雙峰」）、「三峰」（三根等高K線相鄰，或夾一根較低K線的「變形三峰」）。
- **層級2谷點**：定義與峰點對稱（左右各兩根K線的最低點都較高），同樣分單谷、雙谷、三谷及其變形。
- PVT章節提到本策略同樣可調整為更高層級（如層級4）判定峰谷點，層級愈高訊號愈少但愈不受短暫波動干擾（此觀念完整敘述見第三章 PVT 通道，q2-03-01）。
- **常見誤判**（p.10）：判定峰點時，該K線「左邊」必須確實有兩根較低的K線，若左邊僅有一根較低K線（不足兩根），或左邊根本沒有較低K線，都不構成層級2峰點；谷點鏡像同理。書中範例顯示，誤把不合格的峰谷點當作轉折點，會導致訊號步驟遲遲無法完成，須耐心等待真正符合條件的轉折點出現（p.10）。

### 3.2 買進三步驟（多方，p.3）

1. **C1** 價格突破均線，在均線上方形成第一個層級2轉折**峰位**。
2. **C2** 價格拉回過程中，所有K線**收盤**都不跌破均線（均線視為支撐）。
3. **C3** 價格再度上攻，K線**收盤**突破步驟1的峰位，即形成買進訊號（N型推升）。

### 3.3 放空三步驟（空方，p.4，鏡像規則）

1. **C1'** 價格跌破均線，在均線下方形成第一個層級2轉折**谷點**。
2. **C2'** 價格反彈過程中，所有K線**收盤**都不突破均線（均線視為壓力）。
3. **C3'** 價格再度下殺，K線**收盤**跌破步驟1的谷點，即形成放空訊號（倒N型下殺）。

### 3.3.1 峰谷位可隨新極值移動（p.12-13，圖1-13）

- 折返過程中若又出現更高（多方）或更低（空方）的層級2轉折點，須把步驟1的峰位／谷位**移動**到新的極值位置，再等待收盤突破/跌破新位置才算訊號成立。

### 3.3.2 折返中收盤穿越均線 → 步驟重新計數（p.11-12，圖1-11、圖1-12）

- 在步驟2的折返過程中，只要出現**任一根K線收盤**穿越（多方跌破、空方突破）均線，即判定該次折返失敗，整個三步驟訊號**必須重新計數**。此規則可有效排除窄幅反覆盤（書中範例：兩個多小時、震幅不到30點的盤整，靠此規則濾掉A～G共7次無效重新計數，見圖1-12；另見圖1-11的多方、空方重新計數示意）。

### 3.3.3「無遮蔽」收盤突破要求（p.16-17，圖1-16）

- 訊號K線的收盤，必須是「行情突破/跌破均線後，至當根為止所有K線中的最高/最低收盤」，即收盤本身不能被同段走勢中先前任何一根K線的最高/最低點「遮蔽」。若K線最高點雖已突破峰位但收盤未站上（如圖1-16標示A），則須等後續某根K線收盤真正突破該K線的高點（而非原峰位）才算有效訊號。

## 4. 進場

- 買進：C3 成立當根K線收盤時，即以該收盤價（或次一根開盤）進場作多。
- 放空：C3' 成立當根K線收盤時，即以該收盤價（或次一根開盤）進場作空。
- **補進場（同一峰谷位内）**：折返段中，若某根K線左側已有兩根較高（谷）/較低（峰）K線可預先判定為潛在轉折點，但尚不足右側兩根條件，只要該根之後某根K線收盤已突破/跌破原峰谷位濾網，即可提前視為訊號成立，不需要等右側轉折點正式確認（p.16，圖1-15標示A、B、C說明）。
- **隔日尾盤訊號延續進場**（p.23，圖1-21）：若訊號發生在收盤前30分鐘內而被忽略（見第7節過濾），但隔日開盤第一根K線最高點/最低點與昨日尾盤最後一根K線出現重疊（無真空缺口），可沿用昨日尾盤訊號，於開盤第一根K線範圍內擇點進場，停損位置沿用昨日尾盤訊號所設定的停損；若開盤第一根K線與昨日最後一根K線之間出現真空（未重疊），則不可沿用。
- **提早進場（小博大）情境**（p.19，圖1-18）：正常應忽略的大幅度跳空訊號，若市場當時處於整體波動明顯放大階段（如書中舉例2015年7月陸股暴跌造成的多空對決期），可等待價格拉回，回到距離停損位置不到10點時，再考慮進場（實質是延後進場以縮小停損）。

## 5. 停損

- **買進方向公式**（p.13）：
  `停損位置 = 訊號K線收盤 − (10 + 收盤個位數)`
  - 例：收盤 7905 → 個位數 5 → 停損 = 7905 − (10+5) = 7890（停損15點）。
  - 例：收盤 7902 → 個位數 2 → 停損 = 7902 − (10+2) = 7890（停損12點）。
  - 若收盤為整數價位（…00、10、20…90），停損點數固定為 **20點**（p.13）。
- **放空方向公式**（p.14，原文明確列出，非鏡像推論）：
  `停損位置 = 訊號K線收盤 + (20 − 放空訊號個位數)`
  - 例：收盤 7665 → 個位數 5 → 停損 = 7665+(20−5) = 7680（停損15點）。
  - 例：收盤 7701 → 個位數 1 → 停損 = 7701+(20−1) = 7720（停損19點）。
  - 若收盤為整數價位，停損點數同樣固定為 **20點**（p.14）。
  - 註：`20−個位數` 等於 `10+(10−個位數)`，意即「收盤價到上方最近十位整數的距離＋10」，與買進方向「收盤價到下方最近十位整數的距離＋10」邏輯對稱，兩者並非把加減號互換、個位數原封不動相加即可（見第12節「改動說明」）。此放空公式亦於第二章 SARC 訊號中再次明確引用（p.72-73），確認為全書通用公式。
- 停損風險通常在20點以內，且採**盤中價格**觸及即停損（非等收盤）（p.21）。
- 峰谷位若在訊號成立前已移動（見3.3.1），停損公式以最終訊號K線收盤為準。
- 若某次移動停損位置時遇到已有更高（谷點，空方濾網）/更低（峰點，多方濾網）的轉折點出現，不可把濾網移動到這個較優位置，仍應以最初、最極端的濾網為準，否則訊號可靠度將受質疑（p.14-15，圖1-14：標示A為另一略高的谷點，不可將濾網從標示1移至A）。
- 海外商品或風險承受度不同時的替代方案，見第2節。

## 6. 出場 / 停利

書中提供多種可互相替換的停利機制（皆屬本方法的出場模組，操作者可依行情速度與個人風格擇一或搭配使用；書中明言「沒有硬性規定哪一種才是最好的」，p.36）：

### 6.1 反向訊號立即平倉反手（p.21，圖1-19、1-20）

- 持倉尚未觸及停損時，若出現反向三步驟訊號，須**立即平倉並反手**操作反向訊號，同時重新設定新方向的停損。

### 6.2 固定點數移動停利（創新高/創新低折返點數）（p.28-35，圖1-24～1-32）

1. 先預設一個獲利目標點數（書中常見15點或20點），當價格K線**收盤**超過該位置後，才啟動移動停利機制，避免無感波動時被雜訊誤導平倉（p.28）。
2. 獲利達到初始目標後，只要出現「創新高的紅K線」（多方，定義：K線**收盤最高**且**上影線最高**兩條件皆符合）或「創新低的黑K線」（空方，定義：**收盤最低**且**下影線最低**皆符合），即把停利點移至「新高（低）點回落（彈）15點或20點」處，形成階梯式上移（下移）的停利線（p.29）。
3. 更嚴苛的變體：可再加上「該K線收盤必須無遮蔽」的條件，但書中指出「通常這裡不限制」，即預設版本不要求無遮蔽（p.29）。
4. 停利點被「觸及」定義為：**盤中價格突破該停利線超過1點**，即平倉出場（p.29）。
5. 折返點數並非固定不變：若行情在極短時間內（書中例：不到30分鐘內）即讓獲利達到約70點，屬於少見的大行情，此時可選擇立刻獲利了結，也可以選擇把折返點數放大為25點或30點，換取承受更大反彈空間、爭取更大獲利（書中範例最終獲利達208點）（p.34-35）。

### 6.3 SAR移動停利（p.37-41，圖1-33～1-38）

1. 獲利達到初始目標點數後，開始啟用 SAR 作為停利參考（SAR 在盤整格局容易被上下頻繁穿越、產生雜訊，故不在一開始就用它）。
2. SAR 特性：只要K線影線（非收盤）觸及 SAR 點，SAR 即於下一根反向；但本策略規定**須K線收盤真正跌破/突破，才平倉**。
3. 若K線僅以影線觸及 SAR（收盤未跌破/突破），則把該根K線的 SAR 位置畫成**水平線延用**為停利參考，不因 SAR 點位在下一根轉向而失效；直到某根K線**收盤**真正跌破/突破此水平線，才平倉出場。
4. 若之後又有K線影線觸及新的水平延用線，重複步驟3的邏輯，持續延用最近一次未被收盤突破的水平線；若後續又有K線影線穿越回與原部位同向的一側，則改回以當時的 SAR 點位（而非水平延用線）作為停利參考，直到收盤真正突破/跌破才出場（p.37）。
5. 行情速度愈快時，SAR 愈能緊貼行情、控制獲利回吐（p.40）；行情橫向盤整時，SAR 頻繁被穿越，不適合作為停利依據，此特性本身也可用來偵測盤整（p.40，另見 q2-02 SARC 訊號章節據此特性另闢蹊徑產生進場訊號）。

### 6.4 均線移動停利法（MA30 / MA10）（p.42-45，圖1-39～1-42）

1. 獲利達到初始目標（20點）後，先以 **MA30** 作為停利參考；當獲利點數擴大到 **50點以上**，改以參數較小的 **MA10** 作為停利參考（p.42）。
2. 出場條件為K線**收盤**突破（空單）或跌破（多單）所使用的均線，才平倉（p.42-43）。
3. 邏輯依據：行情接近末端常會加速、乖離率與斜率放大，此時用參數較小的均線較能貼近速度盤、減少獲利回吐；若行情緩步前進，沿用 MA30 反而能讓獲利極大化，兩者孰優孰劣不一定，須視行情變化決定（p.42）。
4. 均線停利法與固定點數折返停利法比較，績效可能有明顯差異（書中一例：均線停利獲利40點，創新高折返20點停利法獲利120點），但作者強調這不是通例，選用哪種方式應以「找到適合自己操作風格」為最重要考量，不必比較若換一種方式是否賺更多（p.45）。

### 6.5 區間高低點停利法（p.46-51，圖1-43～1-47）

1. 獲利達到初始目標（20點）後，取「最近N根K線區間」的最高點（空單）或最低點（多單），提供給**隔一根**K線作為停利參考；每經過一根K線就重新計算一次N根區間高/低點，隨行情逐步移動停利線（p.46-47）。
2. 預設N＝15根，可依行情速度調整：行情盤整時間較長（如超過20根K線），可放大為20根或30根區間，讓停利點不致過早被觸及；行情呈現速度盤時，可縮小為10根、8根，甚至更快的4～5根區間，愈快貼近行情（p.48-49）。也可依獲利階段搭配多種區間根數，例如初期用15或20根，獲利擴大到50點以上時改用8或10根，出現大幅K線時再縮到4～5根（p.49）。
3. 若計算出的區間高/低點比原始停損位置**更不利**（例如空單的區間最高點比原始停損還高），不可將停利點移到比原始停損更差的位置，應維持原始停損不動，直到區間高/低點不再劣於原始停損時才開始移動（p.48）。
4. 出場條件：K線**影線**觸及停利點超過1點即平倉（p.47，與6.2、6.3的「收盤才出場」條件不同，此法以影線觸及為準）。

### 6.6 固定點數出場法（窄幅盤整適用）（p.28）

- 當行情明顯陷入窄幅盤整、一分鐘K線漲跌幅多半很小（書中以**漲跌幅超過7點**做為判斷是否「有感波動」的參考門檻）時，不建議使用移動停利，改採**固定點數**（書中舉例10點）達到即出場，追求積小勝為大勝，而非執著等待大行情。

### 6.7 出場方式的取捨、求不賠與時間停損

- 6.2～6.6 五種停利機制的選用，書中未給出統一規則，屬操作者可視行情特性自行選用、搭配的替代方案。
- **求不賠／保本出場**：若持倉已一度出現超過**15點**的獲利（例如創新低/新高後），隨後行情反轉、逐漸逼近或回到進場價位，應**立即無痛出場**保住戰果，不必堅持等到正式停損或移動停利被觸發才出場（p.32-33，圖1-27）。此規則與「若獲利後價格拉回接近進場點，可考慮先行保本出場，之後如有新訊號可再進場」（p.22，圖1-20標示C、D說明）為同一精神的具體化版本。
- **時間停損**：部位持有過久（超過60根K線／約1小時）仍未見明顯獲利，宜考慮先行離場，不必堅守原訊號（p.22）。
- **盤感出場（主觀提醒，非可判斷規則）**：操作者累積經驗後，若盤中「感覺不對盤」，即便未觸及停利或停損，也可主動出場（p.62，圖1-68「看破出場」）。此屬經驗性提醒，不列入機器可讀規則。

## 7. 過濾：不做的情況

1. **大K線訊號忽略**：訊號K線漲跌幅 ≥15點（原文：「不宜是大K線，即漲跌幅在15點以上」）宜第一時間忽略；若稍後行情折返，且逼近大K線高低點在10點以內，可考慮再以最小停損進場（p.18）。
2. **偏離均線起漲/跌點過遠忽略**：訊號發生位置距離「均線被突破/跌破的起始位置」超過**60點**，獲利空間相對縮小，宜忽略（p.18）。
3. **偏離平盤過遠忽略**：訊號K線收盤距離當日平盤（昨收）超過**60點**，宜忽略（門檻為60點；圖1-17示範距平盤90點的反例，90點僅為該圖之實例數值，非另訂門檻）；但若當時市場處於整體波動放大階段（如單日震盪動輒超過百點），可彈性放寬，考慮等拉回至距停損不到10點時進場（p.18-19）。
4. **訊號K線幅度過小忽略**：訊號K線本身漲跌點數過小（書中舉例僅1點）不宜視為有效訊號，至少須有**2點以上**的漲跌幅（p.24-25）。訊號K線幅度過大或過小都表示多空表態力道有問題：過大容易遭獲利回吐反噬，過小則表不了態、易被對手看破（p.26）。
5. **收盤前30分鐘訊號忽略**：訊號發生在當日收盤前30分鐘內，通常忽略，不再進場；但可沿用至隔日開盤第一根K線（見第4節隔日延續規則）（p.23）。
6. **窄幅盤整/單筆行情獲利有限**：行情陷入停滯橫走格局時，訊號進場後獲利往往不超過5點也不觸及停損，屬操作辛苦但非硬性禁止條件，屬提醒而非可判斷條件（p.24，見第9節）。

## 9. 作者提醒與常見錯誤

- 操作當沖須極快反應盤中多空變化，不能以日線或前一晚的看法堅持盤中方向；原多單被停損後、若隨即出現放空訊號，須立即轉換思緒做空，不能停留在停損的情緒中（p.20）。
- 沒有人能預知每筆交易能賺多少點，能處理小點數獲利者，愈能積小勝為大勝（p.21）。
- 行情不是每天都有大行情，一個月中大約只有5～7個交易日會出現一路上漲/下跌的大行情，其餘時間只能取得較小獲利；只要能維持不輸，累積起來仍能有正報酬（p.25）。
- 操作以「滿足」為最高原則：達成理想獲利後選擇休息，勝過連續找訊號操作造成精神耗損（p.24）。
- 出場沒有標準步驟或固定模型可循，「更像禪學一般」，操作者應依市場變化與自身盤感選擇適當的出場模型，而非執著單一模式（p.27）。
- 小行情（獲利5～20點之間）佔多數（超過60%），瞧不起小行情、只想賺大波段者，長期結算反而容易是輸家（p.28）。
- 不同停利機制孰優孰劣難以定論；重點是讓持倉、出場「有所依據」而非隨個性任意操作，不必計較若換一種方式是否能多賺（p.45）。
- 盤感的養成需要經驗累積；發現行情「不對盤」時，即使未觸及既定規則，也可以主動出場（p.62）。

## 10. 規則速查（Checklist）

**進場（多方，空方鏡像）**
- [ ] 價格突破均線，形成層級2轉折峰位（C1）
- [ ] 折返過程所有K線收盤皆未跌破均線（C2）
- [ ] 折返段中若出現任一收盤穿越均線 → 重新計數
- [ ] 若折返段出現更高峰位，移動C1至新峰位
- [ ] K線收盤再度突破C1峰位，且為「無遮蔽」最高收盤（C3）→ 買進訊號
- [ ] 訊號K線漲跌幅 < 15點（否則忽略，除非拉回至停損10點內）
- [ ] 訊號距均線起漲位置 < 60點
- [ ] 訊號距平盤 < 60點（波動放大期可放寬）
- [ ] 訊號K線漲跌幅 ≥ 2點
- [ ] 訊號未發生在收盤前30分鐘內（否則僅可沿用至隔日開盤重疊部分）

**停損**
- [ ] 買進：停損 = 收盤 − (10 + 收盤個位數)；整數價位固定20點
- [ ] 放空：停損 = 收盤 + (20 − 收盤個位數)；整數價位固定20點
- [ ] 濾網（峰谷位）不可移動到較優（較高谷點/較低峰點）的新轉折點

**出場**
- [ ] 持倉中出現反向三步驟訊號 → 立即平倉反手
- [ ] 獲利達15或20點後啟動移動停利（固定點數折返 / SAR / 均線 / 區間高低點，擇一或依行情切換）
- [ ] 固定點數折返：觸及＝盤中突破停利線超過1點；區間高低點停利：觸及＝影線觸及超過1點
- [ ] 曾獲利超過15點後行情逼近進場點 → 立即無痛出場（求不賠）
- [ ] 持倉逾60根K線無明顯獲利，考慮提前離場
- [ ] 窄幅盤整（K線漲跌幅多半≤7點）可改採固定點數（如10點）出場

## 12. 待確認事項

無重大待確認事項。原「放空方向停損公式為鏡像推論」一項，已由新補拍的 p.14（IMG_8463）與第二章 p.72-73（IMG_8488）的原文明確公式解決，不再是推論，並修正了本文件先前的錯誤鏡像公式（見下方「本次修訂改動說明」）。缺頁 p.54-61、p.64-65 僅影響範例圖數量，不影響核心規則完整性（見 frontmatter `missing_pages`）。

**本次修訂改動說明（依 p.14-15、p.72-73 新頁修正）**：

- 原文件第5節、第11節的「放空鏡像公式」寫作 `收盤 + (10 + 個位數)`，為舊版在缺頁狀態下對買進公式的機械鏡像猜測，**並不正確**。新補拍的 p.14 明確列出放空方向公式為 `收盤 + (20 − 個位數)`，並於第二章 p.72-73 再次確認（「放空訊號發生K線收盤+(20-放空訊號個位數)」）。兩者僅在個位數為5時數值相同（10+5=20−5=15），其餘個位數（例如1、6、7…）計算結果不同，屬於**會影響程式碼停損計算的實質修正**，已於本文件第5、8、11節更新並附新頁碼佐證。
