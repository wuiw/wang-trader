# RSI 鈍化 N 型 / 倒 N 型訊號

> 一句話摘要：當 RSI(5) 進入嚴重超買（90 以上）或超賣（10 以下）而長時間停留（鈍化），此時不必等待第二個背離端點，而是改用價格的層級 2 正 N 型（三段式上漲）或倒 N 型（三段式下跌）123 步驟作為進出場依據。

## 1. 核心概念

在一分鐘 K 線圖裡運用 RSI 指標尋找交易訊號時，除了背離訊號之外，另一種方式是尋找**正 N 型／倒 N 型**買賣訊號，藉此解決「RSI 進入嚴重超買超賣區域時，該判斷多空哪一邊」的難題（p.233）：RSI 來到 90 時，究竟該認為價格隨時會拉回下跌，還是應以鈍化角度認為價格會持續走高？過去這個問題難有標準答案，作者提出的解法是：進入 90（或 10）當下不要立刻做買賣決定，而是「讓子彈飛一下」，改用價格走出的**正 N 型／倒 N 型**外觀來決定操作方向（p.233）。

RSI 觸及 90（超買）或 10（超賣）之後，接下來的行情發展只會走出以下**兩種路徑之一**，兩者互斥：

1. **無鈍化（直接反轉）**：RSI 觸及 90（10）對應的最高（最低）K 線，若價格**直接**走出倒 N 型（正 N 型）三段式下跌（上漲），K 線**收盤跌破（突破）倒 N 型（正 N 型）第 1 步的谷（峰）點**時，即為放空（買進）訊號——這表示行情**沒有**出現鈍化現象，會直接拉回（反彈）做修正（p.233、238）。
2. **鈍化（續勢）**：RSI 觸及 90（10）後，價格先從極端點拉回（反彈）出現一個谷（峰）點，隨後**重新**向上（下）出現正 N 型（倒 N 型），此時 K 線收盤必須**同時**突破（跌破）：(a) 正 N 型（倒 N 型）自身的峰（谷）點，**及** (b) 當初 RSI 觸及 90（10）所對應的**最高（最低）K 線的最高（最低）點**——兩者缺一不可，才是「鈍化買進（放空）訊號」（p.233、238）。此舉解決了 RSI 在嚴重超買（賣）區到底該拉回或持續噴出的兩難。

本方法與「RSI 背離訊號」（q2-06-03）同樣以 RSI 極端區為觸發條件，但**不要求**第二端點也落在極端區、也不要求兩端點之間夾層級 2 點做背離比較，而是直接用價格的 N 型／倒 N 型 123 步驟確認進出場，兩者是書中明確區分的**不同訊號類型**（p.245：「RSI 的 N 型或倒 N 型訊號，與 RSI 背離訊號…」即為原文對兩者並列的直接證據）。

> **重要更正**：本文件先前版本（因 p.228–233 缺頁）將「RSI 觸及 90 後走出倒 N 型」與「RSI 觸及 10 後走出正 N 型」直接稱為「鈍化訊號」的兩個方向，並未要求突破/跌破當初觸發 90/10 的最高/最低 K 線。經 p.233、238 補拍確認，原文明確區分「無鈍化（直接倒 N 型/正 N 型反轉）」與「鈍化（續勢，須額外突破/跌破原極端K線）」兩種不同機制，且**鈍化訊號的成立條件比先前版本嚴格**（須額外突破原極端點）。本次已依原文全面修正第 3、4、10、11 節，詳見下方「改了什麼」相關內容。

## 2. 適用前提

- 使用「自訂界限 RSI 指標」，書中範例採 **RSI(5)**，於 1 分鐘 K 線圖上。
- 觸發前提：RSI(5) 必須先觸及**嚴重超買 90 以上**或**嚴重超賣 10 以下**（p.234、236）。
- 觸及極端區之後，價格必須先從極端點拉回（反彈）形成一個**層級 2 轉折點**，才能開始計算 N 型（倒 N 型）的 123 步驟；若拉回未能形成層級 2 轉折點，不可隨意將後續推升／下跌視為三波 N 型（p.237，圖 6-59）。
- 所有 N 型或倒 N 型的峰谷轉折點，皆須為**層級 2**的峰谷轉折點（p.235）。

## 3. 訊號定義

RSI 觸及極端區後，會走出「無鈍化（直接反轉）」或「鈍化（續勢）」兩種路徑之一，條件分列如下（p.233、238）。

### 3.1 RSI 觸及嚴重超買 90 以上

**(a) 無鈍化放空訊號（倒 N 型，直接反轉）**

1. C1：RSI(5) 觸及**嚴重超買 90 以上**時的價格最高 K 線為觀察起點（0 點）（p.233、234）。
2. C2：價格自 0 點拉回，形成層級 2 谷點（倒 N 型的第 1 步／標號 1）。
3. C3：價格反彈但未超過 0 點高點，再度拉回並跌破第 1 步谷點，構成倒 N 型的第 2、3 步（三段式下跌）。
4. C4：K 線**收盤跌破**倒 N 型第 1 步谷點時，於完成點（3）形成**放空訊號**；此路徑代表行情**沒有**出現鈍化，會直接拉回修正（p.233、234，圖 6-56）。

**(b) 鈍化買進訊號（正 N 型，續勢）**

1. C1b：RSI 觸及 90 以上所對應的最高 K 線（0 點）之後，價格拉回出現**層級 2 谷點**（正 N 型第 1 步）。
2. C2b：價格重新向上，走出正 N 型三段式上漲。
3. C3b：K 線收盤必須**同時**突破 (i) 正 N 型自身的峰點，**及** (ii) 當初 RSI 觸及 90 所對應的**最高 K 線之最高點**，兩者缺一不可，才是「鈍化買進訊號」（p.233、238，圖 6-60）。
4. C4b：拉回谷點不可與更早的起始谷點同低（甚至更低），否則不符合鈍化買點條件（p.238，圖 6-60：「(2)不可與(0)同低」）。
5. C5b：鈍化訊號的突破幅度不宜距離原極端 K 線最高點太遠，**最好控制在 20 點以內**，超過太遠須提防獲利回吐賣壓（p.238）。

### 3.2 RSI 觸及嚴重超賣 10 以下（鏡射 3.1）

**(a) 無鈍化買進訊號（正 N 型，直接反轉）**

1. C1'：RSI(5) 觸及**嚴重超賣 10 以下**時的價格最低 K 線為觀察起點（0 點）（p.233、234）。
2. C2'：價格自 0 點反彈，形成層級 2 峰點（正 N 型第 1 步）。
3. C3'：價格拉回但不破 0 點更低位置，再度上攻，構成正 N 型第 2、3 步（三段式上漲）。
4. C4'：K 線**收盤突破**正 N 型第 1 步峰點時，於完成點（3）形成**買進訊號**；此路徑代表行情沒有鈍化，會直接反彈修正（p.233、234，圖 6-56）。

**(b) 鈍化放空訊號（倒 N 型，續勢）**

1. C1b'：RSI 觸及 10 以下所對應的最低 K 線（0 點）之後，價格反彈出現**層級 2 峰點**（倒 N 型第 1 步）。
2. C2b'：價格重新向下，走出倒 N 型三段式下跌。
3. C3b'：K 線收盤必須**同時**跌破 (i) 倒 N 型自身的谷點，**及** (ii) 當初 RSI 觸及 10 所對應的**最低 K 線之最低點**，兩者缺一不可，才是「鈍化放空訊號」（p.233、238，鏡射 C3b）。
4. C4b'：反彈峰點不可與更早的起始峰點同高（甚至更高），否則不符合鈍化空點條件（鏡射 C4b）。
5. C5b'：鈍化訊號的跌破幅度宜控制在原極端 K 線最低點下方 20 點以內（鏡射 C5b）。

### 3.3 兩路徑互斥、續勢與反轉的判斷順序

- 「無鈍化」與「鈍化」是同一次 RSI 極端區觸發後**互斥**的兩種可能路徑：只要價格直接走出倒 N 型（正 N 型）完成 123 步驟，即成立無鈍化放空（買進）訊號；若拉回未破前一層級 2 點、且重新推升的峰點與原極端點同高或更高（更低），則放棄無鈍化放空（買進）的可能性，改觀察正 N 型（倒 N 型）鈍化訊號（p.235，圖 6-57：「從拉回的 C 向上走 N 型」／「從 B 向下走倒 N 型」示範同一波段中先後出現兩種可能路徑的判斷邏輯）。
- 過濾條件（見第 7 節）：RSI 觸及 90（10）後，若在拉回（反彈）形成第 1 步轉折點**之前**，RSI 峰（谷）位發生過位移，僅限**一次**，且須在**5 根 K 線內**完成位移；此位移**僅允許發生在「尚未出現任何層級 2 反向轉折點」的情況**，一旦已先出現層級 2 反向轉折點（1），即使後續行情走出更極端的新高（低），也絕不允許將起算的 0 點位移過去（p.239，圖 6-61；p.241）。
- 若 RSI 觸及 10 以下（90 以上）後**隨即**先出現反彈峰點（拉回谷點），則自該峰（谷）點之後**只能**往下（上）數倒 N 型（正 N 型）的放空（買進）步驟，**不能**再回頭數另一方向的 N 型（p.241，圖 6-63：須先形成谷點才能數正 N 型，若先出現峰點，則只能沿峰點向下找倒 N 型）。

## 4. 進場

- 無鈍化放空：K 線收盤跌破倒 N 型谷點（第 1 步標號）時進場（p.233、234）。
- 無鈍化買進：K 線收盤突破正 N 型峰點（第 1 步標號）時進場（p.233、234）。
- **鈍化買進（續勢）**：K 線收盤須**同時**突破正 N 型自身峰點**及**當初 RSI 觸及 90 所對應之最高 K 線的最高點，兩者皆突破時才進場；突破幅度超過該最高點太遠（宜以 20 點為界）須提防獲利回吐賣壓，不宜追價進場（p.233、238）。
- **鈍化放空（續勢）**：鏡射，K 線收盤須同時跌破倒 N 型自身谷點及當初 RSI 觸及 10 所對應之最低 K 線的最低點（p.233、238）。
- **延遲失效**：若 N 型（倒 N 型）123 步驟因濾網一再上移（下移）而延遲過久才完成（例如拖延超過 1 小時），即使最終條件符合，也必須**忽略**該訊號，不進場（p.240，圖 6-62）。
- **訊號衝突處理**：若 RSI 觸及極端區後，可能同時醞釀「倒 N 型（正 N 型）空（買）訊」「鈍化續勢正 N 型（倒 N 型）買（空）訊」或「RSI 背離訊號」三種走勢之一，**只取第一個實際出現的訊號**進場；之後即使出現反向訊號，也一律忽略，不因後見的反向訊號而轉向（p.245–246，圖 6-67／6-68）。
  - 例外：若原有部位尚未觸及停損，但又出現**同樣屬於 N 型/倒 N 型（而非背離）**的反向訊號，且該反向訊號是 RSI 再度觸及對側極端區（例如原空單持有中，RSI 又觸及 10 以下並走出正 N 型買訊），則不論原部位是否已觸及停損，**立即平倉並反手**建立新方向部位（p.242–243，圖 6-64／6-65；此例外與上一條「只取第一訊號」的差異在於：上一條是指「N 型/倒N型訊號」與「RSI背離訊號」之間互斥擇一，本條則是指RSI二度觸及極端區、再度走出同類型N型訊號時的換手規則，兩者判斷情境不同，已依原文脈絡分列說明）。

## 5. 停損

- 停損位置（p.234，圖 6-56 說明）：「可以取最高點 A 為停損位置，或照均線買賣策略的停損設置，亦可比較兩者取較高者，但仍宜控制停損點數在 20 點以內」——即倒 N 型空單以觸發峰位 A（結構起點）為停損，或採第一章均線訊號的個位數停損公式，或取兩者較遠者；點數控制在 20 點以內。多方鏡像。
- 圖 6-64、6-65 另以灰色虛線標示「停損位置」於 N 型（倒 N 型）結構的關鍵轉折點。
- 開盤跳空情境下的停損／不進場判斷：
  - 若跳空幅度**小於 30 點**，或屬開盤 15 分鐘內 RSI 即觸及 10／90 的情況，可一概忽略、不視為有效鈍化訊號起點（p.243）。
  - 若跳空幅度**大於 30 點以上**，才值得依此觸發買賣訊號（p.243，圖 6-65：跳空約 50 點後續漲逾 65 點，RSI 持續 90 以上游移，方視為有效起點）。
  - 若開盤跳空點數在 **10 點以內**（無縫接軌），RSI 觸及 90 超買區後走出倒 N 型空訊，通常**忽略**；但若走出向上 N 型鈍化買訊，因跳高開盤偏多，可**採行**操作多單（p.244，圖 6-66）。鏡像地，向下跳空小於 10 點、RSI 觸及 10 以下時，向上 N 型買訊忽略，向下倒 N 型鈍化空訊可採行（p.244）。

## 6. 出場 / 停利

書中未明確說明固定停利規則；本節提供的是「反手換手」規則（見第 4 節訊號衝突處理），即遇到 RSI 再度觸及對側極端區並走出同類型 N 型訊號時，不論原部位停損與否，立即平倉反手（p.242–243）。

## 7. 過濾：不做的情況

0. 自超買區（超賣區）發動的訊號，其 RSI 在觀察期間不能已經穿過對側的嚴重超賣區（超買區）；若已穿過，須改由對側極端點重新觀察買訊或自反彈峰（回檔谷）起算的倒 N 型（正 N 型）（p.236，圖 6-58）。
1. 拉回未形成層級 2 轉折谷（峰）點前，不得將後續推升（下跌）視為三波 N 型（倒 N 型）（p.237，圖 6-59：C 峰值再度觸及 90 但若未先產生倒 N 型空訊、其拉回又未產生層級 2 谷點，則只能繼續觀察，不可強行認列 N 型買點）。
2. N 型（倒 N 型）123 步驟若因濾網反覆上移（下移）而延遲過久（例如超過 1 小時、經多次峰谷位移）才完成，即使最終符合條件，也應忽略不操作（p.240，圖 6-62）。
3. RSI 觸及極端區後，若峰（谷）位已先發生位移，僅允許**一次**位移，且須在 **5 根 K 線內**完成；超過此限制的位移不得採認為有效峰（谷）點（p.241）。位移**僅在「尚未出現任何層級 2 反向轉折點」時才允許**——若已先出現層級 2 反向轉折點，之後即使行情走出更極端的新高（低），也絕不允許將起算 0 點位移過去（p.239，圖 6-61）。
3b. 鈍化訊號（3.1(b)／3.2(b)）的拉回谷點（反彈峰點）若與更早的起始谷（峰）點同低（同高）甚至更低（更高），不符合鈍化買（空）點條件（p.238，圖 6-60）。
3c. 鈍化訊號突破（跌破）原極端 K 線最高（低）點的幅度過遠（超過約 20 點），提防獲利回吐賣壓，不宜追價（p.238）。
4. 若 RSI 觸及超賣 10 以下後，行情**先**出現反彈峰點，之後只能沿峰點向下找倒 N 型空訊，不可再回頭數向上正 N 型買訊（反之於超買情境亦然）（p.241，圖 6-63）。
5. 開盤跳空幅度不足 30 點、或開盤 15 分鐘內 RSI 即觸及 10／90，一概忽略、不作為鈍化訊號的有效起點（p.243）。
6. 同一波段中，若「RSI 的 N 型／倒 N 型訊號」已先於「RSI 背離訊號」出現（或反之），僅取第一個出現者，忽略稍後出現的反向訊號（p.245–246）。
7. 臨近當天收盤才浮現的倒 N 型（正 N 型）訊號，宜採取忽略（p.237，圖 6-59：D 位置雖有倒 N 型空訊，但臨近收盤，忽略）。

## 9. 作者提醒與常見錯誤

- RSI 觸及 90（10）後，「直接倒 N 型/正 N 型反轉」與「先拉回、再突破原極端點的鈍化續勢」是兩種互斥路徑；鈍化訊號比直接反轉訊號**多一道門檻**——收盤必須同時突破/跌破 N 型自身峰谷點及原極端 K 線的高低點，缺一不可（p.233、238）。
- 拉回沒有形成層級 2 谷（峰）點前，不可強行把後續推升（下跌）當作三波 N 型，這是最容易誤判之處（p.237、239）。
- 峰谷位移只在「尚未出現層級 2 反向轉折點」時才允許；一旦已有反向轉折點，就不能再把 0 點位移到後續更極端的新高（低）（p.239）。
- 鈍化訊號的拉回谷點（反彈峰點）不可與起始 0 點同低（同高），且突破/跌破原極端點的幅度不宜超過約 20 點，否則有獲利回吐賣壓風險（p.238）。
- 訊號若因濾網反覆上移（下移）而拖延過久才成立，代表時效性已喪失，務必忽略，不論該訊號在技術定義上是否「最終符合條件」（p.240）。
- RSI 觸及超買（賣）後，若先出現反向的層級 2 轉折點（峰或谷），方向已被鎖定，不可回頭尋找另一方向的 N 型（p.241）。
- 開盤跳空幅度是否足夠（30 點門檻），以及跳空方向與訊號方向是否一致（跳高偏多、跳低偏空），都應納入是否採行訊號的判斷（p.243–244）。
- 當「N 型/倒N型訊號」與「RSI 背離訊號」在同一波段內先後出現時，只認第一個出現的訊號，避免因訊號反覆而頻繁進出（p.245–246）。
- 唯一允許「無視原部位停損、立即反手」的情況，是 RSI 再度觸及對側極端區、且走出同類型 N 型（倒 N 型）訊號時（p.242–243），與前一條「只取第一訊號忽略反向」的規則須加以區分。

## 10. 規則速查（Checklist）

RSI 觸及嚴重超買 90 以上：
- [ ] （無鈍化放空）價格自 0 點直接拉回形成層級 2 谷點，再跌破該谷點（倒 N 型 123 步驟完成，未涉及原極端點比較）
- [ ] （鈍化買進）價格拉回形成谷點且不與 0 點同低，重新上攻，K 線收盤**同時**突破正 N 型峰點及 0 點（原 RSI-90 對應最高 K 線）的最高點；突破幅度未超過原極端點約 20 點太遠
- [ ] 峰谷位移（如有）僅一次、於 5 根 K 線內完成，且發生在尚未出現層級 2 反向轉折點之前
- [ ] 訊號未因濾網延遲過久（未超過約 1 小時／多次位移）
- [ ] 未臨近當日收盤

RSI 觸及嚴重超賣 10 以下（鏡像）：
- [ ] （無鈍化買進）價格自 0 點直接反彈形成層級 2 峰點，再突破該峰點（正 N 型 123 步驟完成）
- [ ] （鈍化放空）價格反彈形成峰點且不與 0 點同高，重新下攻，K 線收盤同時跌破倒 N 型谷點及 0 點的最低點；跌破幅度未超過原極端點約 20 點太遠
- [ ] 未先出現反彈峰點鎖定倒 N 型方向（若已先出現，只能沿峰點向下找倒 N 型，不可回頭找正 N 型）
- [ ] 訊號未因濾網延遲過久
- [ ] 開盤跳空情境符合對應規則（跳空 <10 點：與跳空方向一致者可採行、逆方向忽略；<30 點且非跳空首 15 分鐘觸及極值者忽略；≥30 點可採行）

- [ ] 若原部位尚未停損，RSI 再度觸及對側極端區並走出同類型 N 型訊號 → 立即平倉反手
- [ ] 若「N 型/倒N型訊號」與「RSI 背離訊號」同時醞釀 → 僅認第一個出現者，忽略之後的反向訊號
