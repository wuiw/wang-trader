# 豬陽變色（價格與均線碰撞版）

> 一句話摘要：在 MA10、MA20 黃金交叉至死亡交叉的「最佳操作區域」內，當價格拉回（或反彈）觸及均線後，若紅K線收盤突破最靠近的一根黑K線最高點（或黑K線收盤跌破最靠近的一根紅K線最低點），即為豬陽變色的買進（賣出）訊號。

## 1. 核心概念

- **紅黑K線互換的意義**：多頭趨勢中，K線收黑代表賣壓出籠；若趨勢要延續，須先突破該黑K線最高點，粉碎空方防線，這就是買進訊號。空頭趨勢中，收黑K為常態，出現紅K代表多方試圖防守；若空頭要延續，須向下跌破該紅K線最低點，讓多方買盤停損棄守，這就是放空訊號。由黑K突破轉紅、或紅K跌破轉黑，作者稱之為「豬陽變色」（p.97）。
- **價格與均線碰撞原理**：本章把「可操作的多頭區間」界定為 MA10（10日均線）與 MA20（20日均線，又稱月線）形成黃金交叉至死亡交叉之間；價格從高點拉回，若只是上漲過程中的整理，會回探觸及 MA10 或 MA20，並在均線助漲效果下恢復上漲。檢定整理完成、確認重新上攻的必要訊號，就是價格觸及均線後，出現紅K線收盤突破「最靠近它的一根黑K線」最高點（p.97–98，圖3-1）。空方鏡像：MA10/MA20 死亡交叉的空頭區間內，價格反彈觸及均線後，黑K線收盤跌破「最靠近它的一根紅K線」最低點，即為賣出訊號（p.98–99，圖3-2）。
- **最佳操作區域**：只選取 MA10、MA20 黃金交叉至死亡交叉之間的區域操作，這是主力或市場最奮力作多（或作空）的區間，回檔（反彈）大多溫和，甚少重挫，故也稱「操作安全區間」（p.100）。
- **第一次回檔（反彈）最重要**：區域內每一次價格碰撞均線產生的豬陽變色都可操作，但最重視「第一次訊號」，往往是整個波段最佳的進場位置；若不是「一波到頂」的行情，均線附近的豬陽變色會帶動另一波更大行情。一波到頂的走勢，拉回往往直接下殺，不會在均線位置出現豬陽變色（p.100）。
- **三步驟進場邏輯**：①脫離均線（至少一根K線表態，做出明顯的大漲／大跌動作）→②碰撞均線（價格拉回／反彈觸及均線）→③濾網（即豬陽變色的突破／跌破訊號本身），依此三步驟可有效判斷正確的買賣訊號（p.117，圖3-17；p.118，圖3-18空方鏡像）。
- **與 `q3-08-02-豬陽訊號`（期貨奇績3）的異同**：兩者同源自作者另一著作「交易訊號之直覺操作」下冊的豬陽變色概念（本書 p.97 明確提及）。差異：(1) 商品／週期不同——本章以個股日線為主，`q3-08-02` 以台指期5分鐘K線為主；(2) 多空分界不同——本章以 MA10/MA20 交叉界定多空區域，`q3-08-02` 以 MA10 單一均線方向界定；(3) 「最靠近的黑/紅K」定義寬鬆度不同——本章的「最靠近的一根黑（紅）K線」不限定必須是緊鄰前一根K線（例如圖3-5的A訊號K前還有其他同色K線），`q3-08-02` 則嚴格限定訊號必須是「緊鄰前一根」黑接紅／紅接黑的兩根K線組合；(4) 本章多了「均線碰撞」的觸價前提與多組時間／幅度濾網（3天內、不破MA20逾3%等），`q3-08-02` 則以「距均線轉折點10點」「距開盤60點」等點數濾網為主。規則細節僅依本書原文撰寫，不套用 `q3-08-02` 的規則。

## 2. 適用前提

- 商品：本章主要以個股（如可成、友達、揚智、緯創等）示範；書末另以歐元（圖3-26）、NASDAQ（圖3-27）示範可用於匯市與海外期貨（p.123、126–127）。
- 週期：日線為主；亦可用於分時線，但均線參數須做調整（p.126，原文未說明如何調整）。
- 多空分界：MA10 與 MA20 呈現黃金交叉（多方）或死亡交叉（空方），且此交叉須「維持」——若黃金交叉後價格立即又跌破均線、重新形成死亡交叉，此段不算數，通常只是盤整或盤底過程（p.104）。
- 「第一次回檔（反彈）」的認定：黃金（死亡）交叉之後，行情必須已經脫離均線、與均線保持距離，且兩條均線須呈現「張口」（即兩線間距擴大、非緊貼），此時的回測才能算是第一次回檔；若價格在剛交叉時就立刻貼近均線，不能算第一次回檔（p.110–111，圖3-11）。
- 均線選擇的敏感度：多空分界固定用 MA10、MA20 交叉判斷；但若個股強勢、拉回僅觸及 MA3、MA5 或 MA8 而未觸及 MA10，可另外參考 MA5、MA3 輔助判斷「是否觸及均線」，唯 MA3、MA5 本身的交叉不可用來替代 MA10/MA20 的多空分界（p.109–110，圖3-10）。
- 均線角度：宜挑選 MA10、MA20 交叉後開口角度大（陡）的個股，代表漲跌速率快、股性活潑，訊號發生後較易迅速表態；開口角度近乎橫向發展的個股，不具漲勢格局，不建議操作（p.115–117，圖3-16）。
- 死亡交叉不必然等於空頭市場：仍須配合季線等更長期均線狀況判斷（p.119）。

## 3. 訊號定義

### 多方（買進訊號）

1. 行情處於 MA10、MA20 黃金交叉之後，且交叉狀態持續維持（未又跌破重新形成死亡交叉）（p.97–98、104）。
2. 屬於黃金交叉後「已脫離均線」（至少一根K線表態明顯上漲）之後的回檔，且回檔發生時 MA10、MA20 已呈現張口（非剛交叉、價格立即貼近均線）（p.110–111、117）。
3. 價格拉回，觸及 MA10 或 MA20（強勢股可另以 MA8/MA5/MA3 輔助判斷是否觸及）（p.97、109–110）。
4. 觸及均線後，出現一根紅K線，其收盤價突破「最靠近它的一根黑K線」最高點 → 形成豬陽變色買進訊號（p.98）。
5. 「不跌了」的判斷基準：不預設拉回應觸及的目標價位（如黃金分割率 0.382／0.5／0.618），而是等出現條件4的豬陽變色訊號才視為止跌，再行買進（p.102）。

### 空方（賣出／放空訊號，鏡像）

1. 行情處於 MA10、MA20 死亡交叉之後，且交叉狀態持續維持（p.98）。
2. 屬於死亡交叉後「已脫離均線」（至少一根K線表態明顯下跌）之後的反彈，且反彈發生時 MA10、MA20 已呈現張口（p.117–118，圖3-18）。
3. 價格反彈，觸及 MA10 或 MA20（p.98）。
4. 觸及均線後，出現一根黑K線，其收盤價跌破「最靠近它的一根紅K線」最低點 → 形成豬陽變色賣出（放空）訊號（p.99）。
5. 反彈過程須符合：K線收盤曾突破前一天K線最高點，且整個反彈過程至少要有2根K線呈現創高的動作（不須連續）；只有1日反彈（無2根創高K線）的情況應排除（p.119，圖3-19：範例中反彈段有3根創高K線）。

## 4. 進場

- 以豬陽變色訊號K線（第4條所述的紅K／黑K）的「收盤」確認即可進場，可在收盤前（盤中第一時間）進場操作，以掌握第一時間的買賣點位置（p.98、120）。
- 若訊號K線本身留有相當長的上（下）影線，或當日只是小漲（小跌）一兩檔，訊號不夠明確時，可透過隔天走勢加以確認：若隔日出現大漲（跌）K線，或收盤越過前一日上（下）影線，即可確認訊號可靠性後再進場（p.106，圖3-7）。
- 若訊號K線本身是小星線（實體很小），除了依條件4收盤突破（跌破）進場外，也可以選擇等隔一根跳空（跳高／跳低）的K線再買（賣）入；一般而言，最好選擇一根長紅（長黑）K線作為進場位置，向上（下）企圖較明確（p.105，圖3-6）。
- 進場後，該波段行情中每一次價格回檔（反彈）至均線再出現的豬陽變色訊號，皆可作為加碼點的選擇位置（p.103、105、107，圖3-5、3-6、3-7），直到高檔（低檔）出現死亡交叉（黃金交叉）為止（p.103，圖3-5）。
- 系統化篩選：可將本訊號程式化為篩選系統，於盤中第一時間找出符合豬陽變色的個股，於當天收盤前進場，效率較盤後篩選、隔日進場更高（p.120）。

## 5. 停損

- **買進**：停損設於買進紅K線「真實低點」下方一檔。「真實低點」＝比較該紅K線最低點與前一天收盤價，取兩者中較低者；若買進訊號的紅K線是跳空K線，真實低點即為前一天收盤價（p.99、103）。
- **賣出（放空）**：停損設於黑K線「真實高點」上方一檔。「真實高點」＝比較該黑K線最高點與前一天收盤價，取兩者中較高者（p.99）。
- **停損後是否反手**：書中未明確說明。
- **均線破位的重新評估規則（非單筆停損，而是候選訊號的失效重啟）**：黃金交叉後，價格拉升一波再回探均線時，不宜跌破 MA20 之下；時間上不宜超過3天，幅度上不宜跌破 MA20 之下3%以上。若發生此狀況，該個股必須重新觀察，等價格回升至 MA10 之上，再重新開始整個豬陽變色訊號辨認流程（p.115）（推論：此規則描述的是「候選標的失去有效性、須重新等待訊號」，是否等同於已進場部位的停損出場，原文未明確說明，見第12節待確認）。
- **另見的百分比停損**：在系統化篩選、比較個股相對強弱勢的段落中，作者提到選擇熱門股買進時，「把最大的停損位置設在7%的位置」（p.121）。此為原文另一處出現的停損口徑，與「真實低點下方一檔」的規則是否為互斥或併用，原文未明確交代（見第12節待確認）。

## 6. 出場 / 停利

- 進場後，該波段每一次回檔（反彈）至均線出現的豬陽變色訊號，可以「依其各點的停損位置作為停利位置」，即前一次加碼點的停損可上移（下移）作為部分停利的參考點（p.105：「標示3-7可以視為加碼點或者依其各點的停損位置作為停利位置」）。
- 整段操作直到高檔出現死亡交叉（或低檔出現黃金交叉）為止，視為波段的自然出場點（p.103，圖3-5）。
- 其餘明確的停利／出場規則，書中未明確說明。

## 7. 過濾：不做的情況

1. 黃金（死亡）交叉後又立即反向交叉（未能維持）的區段，不視為有效的最佳操作區域，通常只是盤整或盤底（p.104，圖3-6標示1、2）。
2. 剛完成黃金（死亡）交叉、價格立即貼近均線（均線尚未張口）時的回測，不算第一次回檔，不宜視為訊號的基準（p.110–111，圖3-11標示1）。
3. 主要跌勢（如 MA60 明顯向下）中，即使 MA10/MA20 出現黃金交叉，也常常不會產生豬陽變色買進訊號；此類情境縱使交叉成立，仍不易同時滿足碰撞均線後的突破條件，作者以此提醒下跌趨勢中要滿足此訊號並不容易（p.108，圖3-9）。
4. 碰觸均線後，宜在3天內出現豬陽變色訊號；若拖得過久，容易使 MA10 彎頭，其後產生的訊號容易是騙線，應提高警覺或不做（p.115）。
5. 若回檔已導致 MA10 彎頭下彎，訊號K線收盤須收在 MA10 之上才可信賴；訊號K線收盤在均線之下者，並非好的買點，應等隔日K線收在 MA10 之上再買進，否則不做（p.115）。
6. 黃金交叉後回檔跌破 MA20 之下超過3天，或跌破幅度超過3%以上，此候選訊號失效，須重新等待價格站回 MA10 之上、重新出現豬陽變色才可操作（p.115）。
7. MA10、MA20 交叉後開口角度近乎橫向發展（幾近水平）的個股，代表人氣稀鬆、不具漲勢格局，不必挑選這種個股操作（p.116–117，圖3-16）。
8. 放空情境下，若一波跌到底後的反彈只是盤整、不會再續跌，此時放空不見得有利可圖，須額外考慮死亡交叉後的時間長短及跌幅深度（p.118）。
9. 放空訊號成立前的反彈過程，若不符合「K線收盤突破前一天K線最高點，且至少有2根K線創高（不須連續）」，應視為雜訊剔除，不成立有效的豬陽變色賣出訊號（p.119，圖3-19）。
10. 放空的最佳時機（第一次反彈後出現的豬陽變色），最好發生在死亡交叉後20天內，或初跌段跌幅不深；若已時間拖得很長、跌幅已深，訊號的可靠性存疑（p.119，原文為「最好」的建議語氣，非絕對硬性門檻）。
11. 個股先前線形呈現橫向擺盪、均線走橫向格局，或成交量沒有逐日擴增（無量群在推），可在選股階段先行剔除（p.122）。

## 9. 作者提醒與常見錯誤

- 不要陷入「老和尚症候群」：面對回檔時，不要預設應該觸探的目標價位（如黃金分割率），這類思考容易讓人猶豫不決、進退失據；正確做法是等價格出現豬陽變色訊號（收盤站上最靠近的黑K線最高點）才視為止跌訊號，再行買進（p.102）。
- 第一次回檔（黃金交叉後首次拉回均線）的豬陽變色訊號失誤率相當低，是全波段最佳買點；大多數被停損的訊號，往往發生在黃金交叉後第二次以後的回測，不應因為某次被停損而對訊號本身失去信心，只要之後再度出現豬陽變色，仍應再次進場（p.105）。
- 訊號K線若留有長影線或漲跌幅過小（訊號不明確），應以隔天K線的表現加以確認，不宜貿然進場（p.106）。
- 個股操作以 MA10、MA20 交叉作多空分界，與作者在「交易訊號之直覺操作」下冊中期貨操作以 MA60 為分界不同，是為了在個股操作上提供更安全機會所做的調整，兩者並不衝突（p.108）。
- 使用輔助均線（MA5、MA3）判斷是否觸及均線時，切勿誤把這些短期均線的交叉當成多空分界的依據，仍應以 MA10、MA20 交叉為準，才不會打亂原先設定的多空意義（p.110）。
- 選股應優先挑選均線開口角度大（漲跌速率快、股性活潑）的個股，橫盤、開口角度近乎水平的個股人氣稀鬆，不必勉強操作（p.115–117）。
- 死亡交叉不代表必然進入空頭市場，仍須參照季線等更長期的均線狀況判斷；一波跌到底後如果只是盤整、不再續跌，放空未必有利可圖（p.118）。

## 10. 規則速查（Checklist）

- [ ] MA10、MA20 已形成黃金交叉（多）／死亡交叉（空），且交叉狀態持續維持
- [ ] 屬於交叉後已脫離均線（至少一根K線明顯表態）之後的回檔／反彈
- [ ] 回檔／反彈發生時，MA10、MA20 已呈現張口（非剛交叉、價格立即貼均線）
- [ ] 價格已實際觸及 MA10 或 MA20（強勢股可用 MA8/MA5/MA3 輔助判斷）
- [ ] 觸及均線後，紅K收盤突破最靠近的黑K最高點（買）／黑K收盤跌破最靠近的紅K最低點（賣）
- [ ] （空方限定）反彈過程至少有2根K線創高、且收盤曾突破前一天最高點
- [ ] 停損＝真實低點（高點）下方（上方）一檔，已設定
- [ ] 觸及均線後3天內即出現訊號（未拖延導致均線彎頭）
- [ ] 若均線已彎頭，訊號K收盤在均線之上（買）／之下（賣）
- [ ] 回檔未跌破 MA20 逾3天或逾3%（未跌破則候選仍有效）
- [ ] 個股均線開口角度夠陡、非橫盤格局

## 12. 待確認事項

1. **7%停損與「真實高低點下方一檔」停損的關係未明確**：p.99 明訂「真實低點（高點）下方一檔」為停損位置，但 p.121 在挑選熱門股（鴻海、鴻準）的段落又提到「把最大的停損位置設在7%的位置」。原文未說明兩者是否為同一套規則的不同表述（例如7%是「真實低點下方一檔」在高價股上換算後的近似值）、或是兩種可併用/取代的獨立停損口徑。此點影響停損金額的實際計算方式，故列入待確認，本文件依原文分別列出，未自行合併或選邊。
2. **MA20跌破逾3天/3%的規則，是對「候選訊號」的重新評估，還是對「已進場部位」的停損／出場觸發，原文未明確界定**：p.115 原文語境是「該檔個股就必須重新觀察」，較像是候選標的訊號失效、須重新等待，而非明確描述已進場部位的停損或停利觸發時機。此規則會影響「已進場部位遇到此情況該如何處理」的判斷，故列入待確認；本文件依原文語意，將其歸類為「候選訊號失效」而非直接等同停損。
