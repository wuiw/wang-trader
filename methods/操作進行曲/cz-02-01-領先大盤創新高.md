# 個股（類股）領先大盤創新高

> 一句話摘要：把個股（或類股）走勢與大盤指數同期比對，只要股價比大盤更早突破整理區間高點／前波高點，就是強勢股的發動訊號，配合大漲K線與均線背景兩層濾網決定進場時機。

## 1. 核心概念

- 每一波大盤反彈或多頭走勢中，領軍的類股或個股一定是「反彈就衝過前波高點，或率先突破盤整格局」，光是抗跌但不領先衝刺的股票（作者稱「老僧入定型」）不是強勢股（p.57）。
- 篩選分兩層：先比對**類股指數 vs 大盤指數**找出領先產業，再比對**個股 vs 大盤指數（或該類股指數）**，從領先產業中挑出領先個股（p.57, p.60）。
- 強勢股通常在大盤指數尚未突破前波高點／盤整區間頸線之前，就已領先創新高，且當日常以最高價附近收盤，力道最強悍；若大盤漲 10%，這類股票常有 50% 以上超水準表現（p.60）。
- 選股邏輯不依賴基本面或消息面領先掌握（散戶難以取得法人研究資源），而是相信「基本面或消息面終將反映在價格上」，價格是最終事實，只要股價領先大盤突破就值得介入（p.60）。
- 大盤陷入盤整或不穩定時，多數投資人會對個股失焦；但強勢股正是在此時提前大盤攻擊、率先創新高，因此每日須預先準備：把最靠近前波高點、最接近盤整區間上緣的個股記錄下來，隔日盤中一旦突破立刻反應（p.61）。

## 2. 適用前提

- 需要能同時檢視「大盤指數」與「類股指數／個股」的同期日線圖，逐一比對相對高點位置（p.57–59, 62–69）。
- 比對基準為「盤整區間上緣（頸線）」或「前波高點」；若大盤已突破最近一個波峰，則需改比對更前一個波峰，逐級往前比對（p.83–84，見圖 2-22 示意圖）。
- 書中範例橫跨大盤多頭初升段與盤整格局，作者強調在「大盤處於盤整」時最容易篩出真正的領先強勢股，因為突破新高後有更多時間發展漲勢（p.90–91）。
- 可人工逐檔比對，亦可用電腦選股程式（書中示範『大財保【專業版】投資策略系統』自設條件「高山青」「領頭羊」）在盤中/盤後自動篩出當日領先突破新高的個股（p.84–87, 92–95）。

## 3. 訊號定義

### 第一層：類股 vs 大盤（前置篩選，非必要但建議）

- C0：將大盤指數與各分類股指數同期日線圖比對，觀察大盤指數在反彈或整理格局中，哪一類股領先突破自身近期盤整區間上緣（p.57–59，圖 2-1、2-2）。

### 第二層：個股 vs 大盤（核心訊號）

- C1：個股（或已篩出的強勢類股中的個股）日線股價，領先大盤指數突破自身近期整理區間頸線（上緣）或前波高點，創出相對新高，而此時大盤指數尚未突破其對應的高點（p.60, 62–69）。
- C2：突破當日K線須為「大漲K線」，收盤價貼近當日最高價附近；不可是短小K線；若帶上影線，上影線不宜過長（p.65, 70–71）。
- C3：突破當日最好帶跳空缺口，訊號威力更強（p.65）。
- C4（均線背景，第二層濾網）：檢視個股均線（MA10/20/60/120/240）排列：
  - C4a　最佳型態「萬佛朝宗」：突破前，各天期均線糾結收斂在同一狹窄區間，此時以大漲K線（常伴跳空）創新高突破，是最佳強勢股訊號（p.74–77，圖 2-14、2-15、2-16）。
  - C4b　若突破訊號正上方緊鄰長天期均線（尤其半年線MA120、年線MA240）且距離很近，隔日易受反壓折返（p.78–81，圖 2-17、2-18、2-20）。
  - C4c　若最近的長天期均線距目前價位仍有相當空間（書中例：季線MA60距現價尚有約 3 元、約 2 成漲幅空間），視為可大膽買進的情況；但若上方還有更遠一層長天期均線（如年線），漲勢仍可能在該均線受阻（p.80–81，圖 2-19）。
  - C4d　極少數個股可一次直接穿越頭上呈空頭排列的多條長天期均線（p.82，圖 2-21）。

多／空方：本章僅列多方（做多強勢股）規則，原文未提供放空鏡像。

## 4. 進場

- E1：符合 C1＋C2，且不落入第 7 節任一過濾條件時，於盤中股價突穿前波高點／區間頸線當下，即以**市價買進**；愈是強勢（愈接近或觸及漲停）愈要買，不宜因「追高」而卻步（p.61, 90）。書中原話：「把昨天在線形圖上，最靠近前波高點的個股及最接近盤整區間上緣的個股，先抄錄出來……當某一檔入選的個股，在盤中突穿高點時，就準備市價買進」（p.61）。
- E2：若突破當日K線非「大漲K線」（例如帶長上影線的紡錘線），**不可**在當下追價，須等隔日K線同時滿足「收盤價 > 前一日訊號K線最高點」且「當日亦為大漲K線」才進場；否則持續觀察、不進場（p.70–71，圖 2-10、2-11 反例）。
- E3：若上方緊鄰長天期均線（C4b 情況），須等股價實際突破/站上該均線並再度創新高時才進場，不宜在初次突破區間但緊貼均線反壓時介入（p.78–79 華寶標示2、飛宏標示2）。
- E4：亦可用電腦選股程式（書中示範條件「高山青」「領頭羊」）於盤中或盤後篩出當日領先大盤突破新高的個股，程式輸出的「進場點」即為當日盤中觸及的突破價（p.84–87, 92–95）。
- 補充：對已出現漲停鎖住的突破K線，不必因「追漲停」的恐懼而卻步；作者認為第一次由整理區間突破的漲停板，當天最高價往往是最安全的進場位置（p.90）。

## 5. 停損

以下為原文中不同情境下出現的停損定義，彼此為並列的替代做法，未說明何時該用哪一種為優先：

- S1（一般型）：停損設在「訊號K線的真實最低點」與「當天收盤價」兩者中**較低**的價格（p.68，台揚案例：標示1收盤37.6元，停損設於當日真實低點與收盤價兩者較低者）。
- S2（均線突破型）：若個股是越過重要長天期均線（MA120/MA240）才進場，則以「突破該均線當根K棒的最低點」為停損；此低點之後只要被跌破，就停損／停利出場（原文將此情況的停損與停利視為同一出場動作）（p.82，國聯案例）。
- S3（程式篩選型）：作者示範將程式篩選標的的停損設為「最大停損 7%」（即進場價下方 7% 處）（p.87；對照圖 2-25、2-26 篩選結果視窗「初始停損點」與「進場點」約相差 7%，例如進場 75.10 元、初始停損點 69.84 元）。
- S4（定性防線）：「除非殺回成本，否則勇敢地跟下去」——即以「跌破買進成本（進場價）」作為最寬鬆的持股/停損防線，作者認為不應僅因大盤同步下跌就出場（p.66–67，禾昌案例）。

停損後是否反手：原文未規定。

## 6. 出場 / 停利

- 原文未明確提供量化的停利或移動停利規則。
- 定性原則：只要個股持續維持「領先大盤創新高」的相對強勢地位，就續抱；一旦股票不再創相對新高、走勢轉為落後大盤（即使表面上仍上漲或再度漲停），就不應視為原訊號的延續而再追買（p.72–74，英群、飛宏反例）。
- 圖 2-9（三芳）標示②處另標有「出場」字樣與箭頭，但正文並未說明其具體判斷依據，僅可視為作者示範的出場參考位置（p.68–69；詳見第 12 節待確認事項）。
- 觸及第 5 節任一停損價位（S1–S3）或跌破成本價（S4）即出場，為書中唯一明確的出場觸發條件。

## 7. 過濾：不做的情況

- F1：突破當日K線非大漲K線、上影線過長（帶長上影的紡綞線）→ 不可在當下追價，須待隔日確認（p.70，華寶案例：隔日開高走低、填補缺口、未收盤越過前高，其後轉急跌，共跌掉23.5元）。
- F2：個股先前曾領先大盤創新高、大漲一波後，進入高檔盤整，其間即使再度出現放量上漲或漲停，只要未重新「領先大盤」創出相對新高，就不可視為原強勢訊號的延續而追買（p.72–74，英群、飛宏案例）。
- F3：突破當下正上方緊鄰長天期均線（尤其半年線MA120、年線MA240）反壓很近時 → 不宜立即介入，需等股價實際突破該均線再做（p.78–81，毅嘉案例：標示1突破區間但隔日觸及半年線即折返）。
- F4：當日爆量達平日近十倍、以跳躍式衝至漲停但盤中又打開、行情呈現「一日行情」特徵（作者稱此類主力為「蟑螂主力」）→ 排除，不宜視為真正的領先突破（p.77）。
- F5：股票已連續多根漲停後，出現「漲停開盤卻遭盤中賣壓打到跌停」的量價背離現象 → 視為主力出貨（攙壓式出貨）警訊，非本方法鎖定的「第一次突破」情境（p.89–90，訊達反例）。

## 9. 作者提醒與常見錯誤

- 不必等基本面或消息面明朗才進場；強勢股常在市場還在找理由解釋「為什麼漲」之前就已經噴出，唯一能做的就是趕快上車（p.75）。
- 追高是散戶常見的心理障礙；作者主張「買強不買弱、買漲停反而最安全」，因為鎖漲停的股票當天最高價往往是最安全的位置，反而是「未鎖漲停、留長上影線」的個股容易當天套在高點（p.90）。
- 不要對曾經讓你賺錢的股票留戀：同一檔股票在不同波段不見得都是強勢股，必須用同一套「是否仍領先大盤創新高」的邏輯重新驗證，不能單憑過去印象持續加碼或回補（p.72–74）。
- 須辨識「蟑螂主力」式的假突破（爆量近十倍、跳躍式衝漲停又打開）與已連續飆漲多支漲停後的出貨型態（漲停開盤殺到跌停），這兩者都不是本方法要追的「第一次領先突破」（p.77, 89–90）。
- 均線背景是選股的「第二層濾網」，只看到領先大盤突破仍不夠，還須確認上方有無長天期均線反壓，否則容易陷入「漲不動、原地踏步」的假強勢股（p.79–82）。
- 在大盤盤整期間率先創新高的個股，能提前取得更多天數發展漲勢（時間換空間），比等大盤整理結束才進場選股更有效率、命中率更高，因為屆時符合創新高的候選股會大幅增加、篩選準確率反而下降（p.90–91）。

## 10. 規則速查（Checklist）

- [ ] C0：（前置，非必要）先比對類股指數是否領先大盤突破盤整區間
- [ ] C1：個股股價領先大盤指數，突破自身整理區間頸線／前波高點
- [ ] C2：突破當日為大漲K線，收盤貼近最高價，上影線不過長
- [ ] C4：檢查均線背景 — 是否為萬佛朝宗（加分）／是否緊鄰長天期均線（扣分，需等突破）
- [ ] F1：非大漲K線 → 不追價，待隔日確認
- [ ] F2：舊強勢股未重新創相對新高 → 不追買
- [ ] F3：緊鄰長天期均線反壓 → 待突破均線再做
- [ ] F4：疑似蟑螂主力當沖爆量 → 排除
- [ ] F5：已飆漲多支漲停後再出現漲停轉跌停 → 排除（非第一次突破）
- [ ] E1/E4：符合以上條件，盤中突破當下市價買進（或依程式篩選進場點）
- [ ] S1/S2/S3：依情境設定停損（訊號K真實低點與收盤價較低者／越均線K棒最低點／最大停損7%）
- [ ] S4：以跌破成本價作為最寬鬆防線
- [ ] 出場：不再領先創新高、跌破停損或成本價 → 出場（原文未給量化停利）

## 12. 待確認事項

- p.68「停損的設定，可以設在標示1K線的真實低點位置，即當天的收盤，取兩者較低的價格」一句語意上多數情況下等同「訊號K線最低點」（因為大漲K線收盤通常高於最低點），此處僅依原文字面轉錄為 S1，未做推論修改，但條件本身在何種情況下「收盤價會低於真實低點」並不清楚，可能單純是作者行文上的保險說法。
- p.87「我們把停損設成最大停損7%」僅出現一次，原文未明說這是否為作者對本方法的通用建議，還是僅該次程式操作示範時的個別設定（S3）；與 S1、S2 兩種以K線位置為準的停損法之間，原文未說明優先順序或使用時機的區分規則。
- 圖 2-9（三芳，p.69）標示②處另標有「出場」字樣與箭頭，但正文完全未描述其對應的判斷依據或規則，僅能視為圖說示意，未列入第 6 節的可執行規則。
- p.92 圖說原書印刷編號為「圖2-18」，與 p.78 真正的圖 2-18（華寶）重複編號（應為原書印刷錯誤，正確應是圖2-28一類的後續編號），抽取時已另存檔名 `操作進行曲-p92-1.jpg` 以區分；另外 `extracted/figures/操作進行曲-fig-2-29.jpg` 存在於圖檔資料夾但未被本章任何頁面檔引用，兩者是否為同一張圖的不同副本無法確認。
