依 `methods/方向判斷驗證/SPEC.md` 與 `methods/方法分類.md` §2。腳本：`scripts/direction_state.py`
（`uv run python scripts/direction_state.py`，約 3 分鐘）；明細：`results/direction/state_metrics.csv`
（工具×週期×h×子集）、`results/direction/state_verdict.csv`（工具×週期判定）。

> 2026-09-28 以更正時區後的資料（2024-05-09～2026-09-24，575 日）重跑，本文數字與結論全部更新。
> 舊版（311 日）用的其實是夜盤時段資料，已作廢；新舊差異見 §5 開頭。

## 1. 做法

- 資料：`data/tx_day_{1,3,5}min.parquet`（2024-05-09～2026-09-24，575 個交易日；前半 2024-05～2025-12 共 401 日、後半 2026-01～2026-09 共 174 日），先 `core.bars.prepare()`。
- 每根K線的方向 dir ∈ {+1, −1, 0}，只用第 i 根（含）以前的資料；大週期與日線只用**已完成**的K線。
- fwd(i, h)：第 i 根收盤後 h 分鐘（以時間找目標K線，同一交易日內，超過收盤取收盤）的收盤變化；
  r = dir × fwd，÷ 當日開盤 × 10000 為 bp。h = 15、30、60、120、到收盤（csv 全有，本文只列 60 與到收盤）。
  dir = 0 的K線不計入。命中率＝r>0 / r≠0。
- 基準：
  - 整體漂移：全部K線平均 fwd。**本期日盤盤中漂移是負的**：60 分 −0.37～−0.40 bp、到收盤 −2.54～−2.57 bp
    （台指這段大漲主要來自夜盤／跳空，日盤盤中平均是往下）。所以這裡「一直做多」反而吃虧，多方側 bp 為負多半是漂移造成。
  - **p置換**（SPEC 指定）：把非 0 的方向在非 0 的K線之間打亂 1000 次（保留多空根數），右尾比例。
  - **p平移**（補充、較保守）：整條方向序列隨機循環平移 1000 次（保留狀態的持續性），右尾比例。
    狀態型方向一段一段地持續，fwd 又彼此重疊，逐根打亂會嚴重低估隨機變異，幾乎每個工具都 p≈0.001；
    p平移比較能代表「換成同樣持續度但時間錯開的狀態」會怎樣。
  - 另附「收盤 群集t」：平均 r 以交易日為群集的穩健 t 值。
- 判定（SPEC，60 分或到收盤任一 h 符合即可）：
  - **有用**：p置換 < 0.05、前後兩半平均 bp 都 > 0、多空兩側都不是明顯負值（平均 < 0 且群集 t ≤ −2）、兩半各 ≥ 30 日。
  - **反向**：左尾 p置換 < 0.05 且兩半都 < 0。
  - **弱**：p置換 < 0.05 但有一項不符，或 0.05 ≤ p置換 < 0.10 且兩半都 > 0。
  - **無**：其餘。**無法評估**：任一半不足 30 日。
  - **保守通過**：在同一個 h 上，p平移 < 0.05、兩半都 > 0、兩側都不是明顯負值。我建議以這欄為準。
- 狀態型沒有點數門檻，只跑一次（沒有原始／縮放兩版）。

## 5. 結論

### 與舊版（2025-03-14～2026-09-24，311 日）比較

舊版用的資料其實是夜盤 16:45～21:44（時區錯誤），結論已作廢。改用正確的日盤資料、期間拉長到 575 日後，主要變化：

- **盤中漂移變小**：到收盤由 −3.7 bp 變成 −2.5 bp，60 分由 −1.3 bp 變成 −0.4 bp。
- **舊版第 1 名 gq-01-11 5 日／3 日均線退步**：到收盤只剩約 2.1 bp（舊版 4.9 bp），前半段（2024-05～2025-12）到收盤是 −0.1 bp，
  所以到收盤不再通過；只剩 60 分鐘在三個週期都通過保守標準，而且主要靠後半段（後半 3.5 bp、前半 0.3 bp）。
- **EMA 類（河流圖兩版、EMA30/55）變成最穩**：三個週期、60 分與到收盤全部通過保守標準（舊版河流全排列主要在到收盤通過，EMA55 換位與 EMA30/55 只有 1 分K 到收盤通過）。
- **通過保守標準的工具變多**：MA10 方向／位置、15 分KD、SAR、MA10/20、MA20/50 三個週期到收盤都通過；
  PVT 層級2／層級4 在 3、5 分K 到收盤通過；gq-02 牛熊（日 MA5/20）也通過（舊版為弱）。
- **cz-05-01 年線**：舊版資料不足、無法評估；現在 MA240 約有 335 日有值，照 SPEC 為「反向」，但保守檢定不成立（見下）。
- 群集 t 普遍變大（樣本多了將近一倍），到收盤有好幾個工具超過 2；60 分只有河流全排列 5 分K（2.26）與 MA20/50 3 分K（2.01）超過 2。

### 整體

1. **照 SPEC 字面判定，幾乎所有工具都是「有用」**，原因仍是逐根置換檢定對狀態型太寬鬆（狀態一段一段地持續、fwd 又重疊，
   隨機打亂後的變異被低估，連「價格在平盤上／下」這種基準都拿到 p≈0.001）。**請以「保守通過」為準。**
2. **效果量很小**：最好的工具（河流全排列），到收盤平均順向約 3.3～4.0 bp（約 9～10 點），60 分約 1.2～1.9 bp。
   命中率都在 50～53%。這些工具只能讓方向「稍微偏對」，不能當成高勝率的方向判斷。
3. **盤中漂移是負的**（到收盤 −2.5 bp），所以多數工具的多方側 bp 為負或接近 0、空方側為正，順向報酬主要來自空方。
   扣掉漂移後（csv 的 `excess_vs_drift_bp`），除了年線與首根K方向，所有工具的多空兩側都是正的，代表工具確實有分辨能力。
   沒有一個工具的某一側「明顯負值」（群集 t ≤ −2）。
4. **大致規律：到收盤比 60 分鐘明顯；EMA／均線類最穩**。越接近多日趨勢的工具，60 分鐘也越容易通過
   （河流圖、EMA30/55、MA20/50、5 分K 的 MA30／MA10/20／SAR）。
5. 失敗或不穩定的：
   - **q3-11 30 分 MA100**：到收盤後半段為負（約 −2.1 bp），60 分後半段也為負 → 弱。
   - **gs-02 週KD**：照 SPEC 是「有用」，但保守檢定沒過（p平移 0.07～0.12），到收盤後半段為負 → 弱。
   - **四柱**（兩版）：到收盤 1.3～1.6 bp，比舊版大，但保守檢定全部沒過（p平移 0.07～0.14）→ 弱
     （且這裡的狀態化是詮釋，不等於書中完整的突破規則）。
   - **基準**：平盤上下、跳空方向照 SPEC 為「有用」，但保守檢定沒過；首根K方向只有後半段為正 → 弱／無。
     平盤上下到收盤約 1.9 bp，和多數均線工具差不多，表示「今天在平盤上或下」本身就帶有同等級的資訊，
     均線工具的優勢要和它比才有意義。
   - **cz-05-01 年線**：約 90% 的時間在年線之上（多方占比 0.90），照 SPEC 左尾置換顯著、兩半都為負 → 「反向」。
     但 p平移 0.79～0.81、群集 t −1.2，而且順向 bp（約 −2.9）和盤中漂移（−2.5）差不多，主要反映「多數時間做多、盤中往下飄」，
     **不當成可反著用的訊號**。
6. **沒有可靠的「反向」工具**（年線的「反向」見上）。

## 6. 注意事項

- 所有數字都**不計成本**，只衡量方向，沒有進出場。
- 狀態型與事件型的指標定義一致（r、bp、命中率、前後半、多空分開）；但狀態型的「樣本數」是根數，
  相鄰K線高度相關，實際獨立樣本接近交易日數（約 575），所以另外報告了群集 t。
- 詮釋或重寫的部分：四柱的狀態化、q3-11 的 30 分K 合成、河流圖兩種版本、gq-01-11 書中均線換算成根數、
  gq-02 的均線週期（書中未指定，沿用模組推論的 5/20）、cz-03-01 沒有處理「交叉須維持」。
- 沒有修改 `core/`、方法模組、測試與既有腳本。
