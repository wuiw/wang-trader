# 方向判斷驗證：狀態型（S）方向工具

依 `methods/方向判斷驗證/SPEC.md` 與 `methods/方法分類.md` §2。腳本：`scripts/direction_state.py`
（`uv run python scripts/direction_state.py`，約 3 分鐘）；明細：`results/direction/state_metrics.csv`
（工具×週期×h×子集）、`results/direction/state_verdict.csv`（工具×週期判定）。

## 1. 做法

- 資料：`data/tx_day_{1,3,5}min.parquet`（2025-03-14～2026-09-24，311 個交易日），先 `core.bars.prepare()`。
- 每根K線的方向 dir ∈ {+1, −1, 0}，只用第 i 根（含）以前的資料；大週期與日線只用**已完成**的K線。
- fwd(i, h)：第 i 根收盤後 h 分鐘（以時間找目標K線，同一交易日內，超過收盤取收盤）的收盤變化；
  r = dir × fwd，÷ 當日開盤 × 10000 為 bp。h = 15、30、60、120、到收盤（csv 全有，本文只列 60 與到收盤）。
  dir = 0 的K線不計入。命中率＝r>0 / r≠0。
- 基準：
  - 整體漂移：全部K線平均 fwd。**本期日盤盤中漂移是負的**：60 分 −1.33～−1.38 bp、到收盤 −3.66～−3.72 bp
    （台指這段大漲主要來自夜盤／跳空，日盤盤中平均是往下）。所以這裡「一直做多」反而吃虧，多方側 bp 為負多半是漂移造成。
  - **p置換**（SPEC 指定）：把非 0 的方向在非 0 的K線之間打亂 1000 次（保留多空根數），右尾比例。
  - **p平移**（補充、較保守）：整條方向序列隨機循環平移 1000 次（保留狀態的持續性），右尾比例。
    狀態型方向一段一段地持續，fwd 又彼此重疊，逐根打亂會嚴重低估隨機變異，幾乎每個工具都 p≈0.001；
    p平移比較能代表「換成同樣持續度但時間錯開的狀態」會怎樣。
  - 另附「收盤 群集t」：平均 r 以交易日為群集的穩健 t 值。
- 判定（SPEC，60 分或到收盤任一 h 符合即可）：
  - **有用**：p置換 < 0.05、前後兩半平均 bp 都 > 0、多空兩側都不是明顯負值（平均 < 0 且群集 t ≤ −2）、兩半各 ≥ 30 日。
  - **反向**：左尾 p置換 < 0.05 且兩半都 < 0。
  - **弱**：p置換 < 0.05 但有一項不符，或 0.05 ≤ p置換 < 0.10 且兩半都 > 0。
  - **無**：其餘。**無法評估**：任一半不足 30 日。
  - **保守通過**：在同一個 h 上，p平移 < 0.05、兩半都 > 0、兩側都不是明顯負值。我建議以這欄為準。
- 狀態型沒有點數門檻，只跑一次（沒有原始／縮放兩版）。

## 5. 結論

### 整體

1. **照 SPEC 字面判定，大部分工具都是「有用」**，原因是逐根置換檢定對狀態型太寬鬆（狀態一段一段地持續、fwd 又重疊，
   隨機打亂後的變異被低估，連「價格在平盤上／下」這種基準都能拿到 p≈0.001）。換成較保守的循環平移檢定
   與交易日群集 t 值後，能站得住的工具少很多。**請以「保守通過」為準。**
2. **效果量很小**：最好的工具，到收盤平均順向也只有約 5 bp（約 18 點），60 分約 2.5 bp（約 9 點）。
   命中率都在 50～53%。群集 t 只有一個工具在 60 分超過 2（gq-01-11 5 日／3 日均線，2.4），其餘都在 1.0～1.9。
   意思是：這些工具只能讓方向「稍微偏對」，不能當成高勝率的方向判斷。
3. **盤中漂移是負的**（到收盤 −3.7 bp），所以幾乎每個工具的多方側都是負 bp、空方側是正 bp，
   順向報酬主要來自空方。但扣掉漂移後（csv 的 `excess_vs_drift_bp`），均線類工具的多空兩側都是正的，
   代表工具確實有分辨能力，只是多方時段本身也在盤中往下飄。例外：四柱的空方側、平盤上下與跳空方向的多方側，
   扣掉漂移後仍為負。沒有一個工具的某一側「明顯負值」（群集 t ≤ −2）。
4. **大致規律：越慢、越接近「多日趨勢」的均線工具越有效**（5 日／3 日均線、河流圖、EMA30/55、MA10/20），
   而且到收盤比 60 分鐘明顯。快的工具（MA10、SAR、PVT 層級2、四柱）只有零星的週期通過。
5. 失敗或無法評估的：
   - **q3-11 30 分 MA100**：60 分為正，但到收盤後半段為負（−2.2 bp），不穩定 → 弱。
   - **gq-02 牛熊（日 MA5/20）**、**gs-02 週KD**：日線／週線方向對日內幾乎沒有分辨力；gs-02 照 SPEC 是「有用」（60 分），
     但保守檢定沒過，到收盤後半段為負，只能算弱。
   - **四柱**：兩版都只有 0.3～0.6 bp，保守檢定全部沒過 → 弱／無（且這裡的狀態化是詮釋，不等於書中完整的突破規則）。
   - **基準（跳空方向、首根K方向）**：只有一半期間為正 → 弱；**平盤上下**照 SPEC 為「有用」但效果極小（到收盤 0.4 bp），
     保守檢定沒過 → 可視為無。
   - **cz-05-01 年線**：MA240 需要 240 日，資料只有 311 日，只在 2026-06 之後約 71 日有值，且全部都在年線之上（多方占比 1.00），
     沒有前半、沒有空方 → **無法評估**。
6. **沒有「反向」工具。**

## 6. 注意事項

- 所有數字都**不計成本**，只衡量方向，沒有進出場。
- 狀態型與事件型的指標定義一致（r、bp、命中率、前後半、多空分開）；但狀態型的「樣本數」是根數，
  相鄰K線高度相關，實際獨立樣本接近交易日數（約 311），所以另外報告了群集 t。
- 詮釋或重寫的部分：四柱的狀態化、q3-11 的 30 分K 合成、河流圖兩種版本、gq-01-11 書中均線換算成根數、
  gq-02 的均線週期（書中未指定，沿用模組推論的 5/20）、cz-03-01 沒有處理「交叉須維持」。
- 沒有修改 `core/`、方法模組、測試與既有腳本。
