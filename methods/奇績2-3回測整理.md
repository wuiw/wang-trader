# 《期貨奇績2》《期貨奇績3》回測整理（點數 ×2 版）

產出日期：2026-09-28。本文件整理 q2（12 個方法）與 q3（13 個方法）在台指期日盤 1/3/5 分K 的回測結果。
**文中所有「點數」都已依台指期 10,000 點 → 20,000 點換算（×2）**，回測也以同樣 ×2 的點數參數執行；
書中原始點數版本只列一欄淨點數當對照。

## 1. 回測設定

| 項目 | 內容 |
|---|---|
| 資料 | 台指期連續月 TXFR1 日盤 1 分K（`../tick-db/kbars_1min.csv`，Shioaji API K棒），再合成 3／5 分K |
| 期間 | 2025-03-14 ～ 2026-09-25，保留 305 個交易日（剔除 4 天根數不足 290 根的日子） |
| 價位 | 期初開盤 21,941 點、期末收盤 47,978 點、期間平均約 31,774 點 |
| 成本 | 0（不計滑價、稅金、手續費） |
| 參數 | 各方法模組預設值；`scripts/point_params.py` 登記的點數欄位一律固定 ×2（`run_scaled.py --force-scale 2.0`） |
| 原始版 | `run_individual.py`，書中點數不縮放，僅作對照 |

資料處理說明：
- Shioaji K棒時間標在該分鐘收盤時刻，已往前平移 1 分鐘，改為本專案慣例的「K棒開盤時刻」，保留 08:45～13:44。
- API 資料零星缺分鐘（缺的分鐘分散在盤中，非整段缺失）：一天 ≥290 根者，以前一根收盤補成量 0 的平盤 K棒；
  不足 290 根的 4 天（2025-07-22、2025-08-20、2025-11-28、2025-12-25）剔除。
- 平盤／昨高低無效的交易日（前一日結算換月、資料缺漏後第一天）共 28 天，依 `scripts/build_bars.py` 規則標記。

### 1.1 點數換算規則（×2）

- **放大**：價格距離類的點數，包括停損、停利目標、折返點數、極端位置門檻、跳空、影線容忍、與平盤／前高低／均線的距離等。
- **不放大**：K 棒根數、分鐘數（如「1 小時」）、MA／RSI／KD 週期、RSI／KD 數值（90／10、80／20、50、RSI 差值 20）、
  成交量（q2-05-02 的 1500 口）、最小跳動類容忍值（q3-04「漲跌差距 ≤1 點」、階梯忽略差距 2 點等）、
  選擇權履約價間距 100 點。
- 個位數停損公式（q2-01 等）：程式把公式裡的常數 10、20 各 ×2，個位數本身不放大：
  多單停損＝收盤 −(20＋個位數)、空單停損＝收盤 ＋(40−個位數)、整數價位固定 40 點。

### 1.2 欄位說明

- 筆數：完成交易筆數；勝率：淨損益 >0 的比例（平手算未勝）。
- 淨點數：全部交易點數加總（1 口台指期）；平均：每筆平均點數。
- PF（獲利因子）＝總獲利 ÷ 總虧損；MDD＝以交易序列計算的最大回撤（點）。
- 原始筆數／原始淨點數：書中原始點數（不 ×2）的對照結果。

## 6. 注意事項

1. **固定 ×2 與實際價位**：《期貨奇績2》年代約 8,500 點（程式預設參考價），《期貨奇績3》約 10,000 點。
   本文件依指示兩本一律用 10,000 → 20,000（×2）。回測期間實際價位 22,000～48,000 點，後段相對波動來說門檻仍偏小。
   若要依當時價位動態縮放，可改用 `run_scaled.py`（不加 `--force-scale`）。
2. **q2-05-02 幾乎沒有訊號**：「最大量 ≥1500 口」是成交量絕對門檻，不隨價位縮放。
   本資料 1 分K 成交量中位數只有 27 口，≥1500 口的只有 9 根（5 分K 中位數 155 口，≥1500 口 272 根），
   所以 1/3 分K 為 0 筆、5 分K 只有 2 筆，結果沒有參考價值。
3. **q3-11 不是選擇權損益**：程式只產生標的的多空方向訊號，損益用期貨點數計算，不模擬權利金。
   另外 ×2 版是以月切段回測，跨月部位在月底強制平倉（原始版不切段），兩版不能直接比較。
   q3-11 原設計是 30 分K 波段，1/3/5 分K 的結果僅供參考。
4. **筆數極少的結果不可靠**：q3-09-02（3～6 筆）、q3-06（11～19 筆）、q2-03-01 5 分K（20 筆）、q2-05-02。
5. **勝率普遍偏低**：多數方法是小停損、讓獲利奔跑或折返出場的設計，勝率 10～30% 屬於正常；要看 PF 與平均每筆點數。
6. **×2 版的切段**：`run_scaled.py` 以月切段、每段帶 5 個交易日暖身，丟棄暖身期間進場的交易。
   當沖方法不受影響，但與原始版（整段連續跑）的筆數可能有少量差異。
7. **資料來源不同**：本次改用 Shioaji API 1 分K 重建資料，不是舊機器上由逐筆成交聚合的資料，
   因此數字與 2026-09-25 舊版 `results/回測報告.md` 不會完全相同。
8. 本次同時補登記 4 個原本遺漏的點數欄位到 `scripts/point_params.py`：
   q2-06-02 `stop_min_offset`、`stop_integer_points`，q2-03-02 `time_stop_flat_points`，q3-04 `reversal_stop_points`
   （交接說明 §3.1 的待辦）。

`results/individual/summary.csv`（原始版）、`results/scaled/compare.csv`（兩版對照）。
