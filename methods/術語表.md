# 術語表

本表把《期貨奇績2》（q2）、《期貨奇績3 勝杯在握》（q3）、《股技期招》（gq）、《操作進行曲》（cz）與《股勝先選》（gs）在各方法文件中用到的術語集中整理。
括號內為出處方法 id；**同一詞在不同書（甚至同一本書不同章）定義不同時分列**，使用時以該方法文件為準。

## 一、位置與結構

| 術語 | 定義 | 出處 |
|---|---|---|
| 平盤 | 昨日（日線）收盤價，當日多空基準線 | q3-07, q3-09-02 |
| 極端位置 | 盤中高低震幅 ≥ 30 點；震幅不足時，極端高/低點距平盤 ≥ 40 點亦可 | q3-01, q3-02 |
| 最高K線／最低K線 | 同時符合「最高點最高＋收盤最高」（或最低點最低＋收盤最低）的當下盤中極端K線 | q3-05 |
| 層級1峰點／谷點 | 左右各至少 1 根K線高點較低（谷點：低點較高）的局部轉折點 | q3-05, q3-08, q3-09 |
| 層級2峰點／谷點 | 左右各 2 根K線高點皆較低（谷點：低點皆較高）；可有單峰/雙峰/三峰及中間夾一根的變形 | q2-01, q2-03, q2-04, q2-06 |
| 高低轉折點與層級n（股技期招用法） | 層級n高（低）轉折點：某根K線左右兩側各至少有n根K線的最高（低）點比它低（高），兩側K線排列不需遞增或遞減；層級愈大者必為層級小者，反之不然 | gq-01-11（與上列 q2/q3「層級1／層級2峰谷點」概念相通，但未明文處理雙峰/三峰等同高變形，用語與判定細節不完全相同，故分列） |
| 河流圖 | 多條均線束（如EMA20/EMA50，或台指期5分K常用MA300/MA180；操作進行曲用EMA30/55為骨幹、EMA10~55共10條為河道）疊加而成的趨勢判斷工具：河道朝上＝多頭、朝下＝空頭；河道糾結橫向視為轉換期，可同時畫上升與下降趨勢線 | gq-01-11, cz-04-01, cz-04-02 |
| 脫離／回測（河流圖操作用法） | 價格明顯拉開、脫離河道邊界一段距離後，拉回（反彈）觸及河流圖任一均線的動作稱為「回測」；回測過程不可跌破（突破）河道另一端邊界均線，否則本次回測不算有效 | cz-04-01, cz-04-02 |
| 均線離差／變盤指標（股勝先選用法） | 均線離差(%) = ((最高均線值−最低均線值)／最高均線值) × 100；離差 ≤ 2% 視為「均線糾纏」，代表變盤在即 | gs-03-01 |
| 多方區域／空方區域（股勝先選第二章用法） | 週KD黃金交叉到下次死亡交叉之間稱多方區域（找買點）；死叉到金叉之間稱空方區域（找空點）；交叉「當週」不操作，須待隔週起才開始尋找日線進場訊號；與 q2-04-01「金叉區間／死叉區間」概念相通，但多一道「隔週才進場」的時間濾網，操作規則不同，故分列 | gs-02-00, gs-02-01, gs-02-02, gs-02-03 |
| 峰位濾網／谷位濾網 | 以峰谷點畫出的水平線，收盤突破/跌破即成立訊號 | q3-08, q2-03 |
| 無遮蔽（收盤） | 訊號K收盤須是該波段以來最高（低）收盤，不被同波段任何K線高低點遮蔽；影線觸及不算 | q2-01, q2-04, q2-05, gq-01-11（訊號K須無遮蔽站上短均線/河道再確認）, cz-01-01（量最縮K線突破時適用）, cz-02-01（前無遮蔽的相對新高）, cz-04-02, cz-04-03（前無遮蔽才可移動停損） |
| 過一高／破一低 | q3：反色K線收盤超過前一根同色K線的極端點；q2（PVT+RSI）：收盤突破前一轉折高點／跌破前一轉折低點 | q3-02, q3-06, q2-03-02 |
| 休息（狀態） | 突破/跌破均線後，K線暫不創新高/新低、收盤也未反向穿越均線的整理階段 | q3-08-01 |
| 縮腳 | K線影線或實體未延伸過前一極端點，力道減弱 | q3-06, q3-08 |
| 壘頂／壘底 | 相鄰兩根K線高點相同（壘頂）或低點相同（壘底） | q3-04 |
| 趨勢階梯（PVT 通道） | 相鄰兩個層級轉折點取孰低（多方）／孰高（空方）構成的階梯狀支撐壓力線 | q2-03 |
| 控盤易主 | 收盤突破/跌破趨勢階梯，只代表控盤方改變，本身不是買賣訊號 | q2-03 |
| 四柱／關卡 | 昨高、昨低、昨收、今開四個價格關卡 | q2-04-02 |
| 金叉區間／死叉區間 | 大週期 KD 黃金交叉到下次死亡交叉之間（或反之），作為順勢方向濾網 | q2-04-01 |
| 均線轉折點（均線谷點、彎曲中點） | 均線方向改變的位置 | q3-08, q3-09-01 |
| 卡在均線 | 拉回/反彈時收盤未真正穿越均線、只貼近均線，仍可能被認可為有效峰谷位 | q3-11 |

## 二、K線型態與訊號

| 術語 | 定義 | 出處 |
|---|---|---|
| 頂雙黑 | 當下盤中最高點為下跌黑K，下一根黑K收盤破前黑K低點 → 空訊 | q3-01 |
| 底雙紅 | 當下盤中最低點為上漲紅K，下一根紅K收盤過前紅K高點 → 買訊 | q3-01 |
| 底V字買訊／頂倒V空訊 | 兩根同向K（第二根為當下唯一極端）＋一根反向K收盤過一高/破一低 | q3-02 |
| 母K線／子K線 | 母K為當下盤中極端K線，子K實體被包在母K實體內（懷孕狀） | q3-03 |
| 頂母子空訊／底母子買訊 | 母子組合後，訊號K反色收盤穿越母K開盤價 | q3-03 |
| 以牙還牙 | 極端K線與隔根反色K線漲跌點數差距 ≤ 1 點的反轉訊號 | q3-04 |
| 過三高／破三低 | K線收盤同時突破（跌破）前 1 根與前 3 根K線區間高（低）點 | q3-05 |
| 連五黑遇首紅／連五紅遇首黑 | 連續 5 根以上同色K（幅度 > 40 點）後，隔根不創新極端的反色K → 反轉訊號；亦作停利口訣 | q3-06 |
| 跳高收黑空訊／跳低收紅買訊 | 開盤離平盤 ≥ 40 點，首根K線收盤方向與跳空方向相反 | q3-07 |
| 豬陽訊號（豬陽變色） | 黑K接紅K收盤突破其高點（買）／紅K接黑K收盤跌破其低點（賣）；操作進行曲版須先觸及均線或河流圖再出現此組合，且訊號K須為「最靠近的一根」反色K，核心K線定義相同 | q3-08-02, cz-03-01, cz-04-01 |
| 蜻蜓點水 | 單根K線短暫跌破/突破基準線（均線或平盤），隔根立即收回 | q3-09 |
| RSI 正差買訊／負差空訊 | 極端K線對應 RSI 後值較前值高（低）20 以上，且為 RSI 真正轉折 | q3-10 |
| N型／倒N型（0-1-2-3） | 0 起點 → 1 峰 → 2 拉回（不破 0）→ 3 收盤突破 1；倒 N 為空方鏡像 | q2-03, q2-04, q2-06-04 |
| 紅三兵／黑三兵 | 連續三根同色K線，在盤中極端位置視為反轉 | q2-05-01 |
| 極端位置最大量 | 盤中最高（最低）K線同時是盤中最大量K線 | q2-05-02 |
| 背離 | 價格與指標（或收盤）走勢不同步 | q2-06 |
| 假性創新高／創新低 | 影線創新高（低）但收盤未同步創高（低） | q2-06-01 |
| 鈍化 | 0～100 震盪指標長時間停在極端區，背離變常態、反轉證據力轉弱；均線排列一致（趨勢明確）時指標容易鈍化，宜改順勢操作 | q2-06-04, gq-02-03, gq-02-04, gq-04-02, gq-04-03 |
| 順向訊號／逆向訊號 | 順向跟隨趨勢，逆向為反轉；衝突時逆向優先 | q3-09 |
| 對立訊號不可侵入對方收盤 | 短距離內相反訊號，後訊號收盤若未越過前訊號收盤 → 忽略後訊號 | q3-02, q3-09 |
| 首度漲停 | 回溯 50 個交易日內未曾出現漲停收盤，今日（或訊號當日）首度出現漲停收盤K線 | gq-01-10 |
| 反軋買點 | 反轉K線組合（黑執帶／覆蓋線／吞噬線／下墜線）出現後，其最高點被後續某根K線收盤突破，代表原判斷的空方力道失敗、多方轉強的買進訊號 | gq-01-04, gq-01-05, gq-01-06, gq-01-07 |
| 黑執帶（會合線） | 前一日長紅K線＋連續上漲中，隔日跳空開高（通常≥5%，開盤即當日最高），價格走低以當日最低點收盤，收盤漲幅<1.5%但不低於前一日收盤，須配合爆量 | gq-01-04 |
| 覆蓋線 | 前一日長紅K線，隔日跳高開盤（通常<3%），之後走軟，收盤反跌收在前一根長紅實體中點以下 | gq-01-05 |
| 吞噬線 | 前一日長紅K線，隔日跳高開盤，價格越盤越低，黑K實體完全吞噬前一根長紅K線實體；高檔情境須配合爆量才視為反轉確認，低檔或無爆量情境則改觀察其最高點是否被突破找買點 | gq-01-06 |
| 下墜線 | 前一日長紅K線（尤其漲停），隔日跳低開盤，價格跌破長紅實體中點後持續破底，收盤跌破長紅最低點；須發生在高檔位置才具反轉意義 | gq-01-07 |
| K線慣性（K線運動慣性） | 一段期間內價格行為維持同一模式不變（例如「持續未收盤突破前N日高」），可作為界定進出場的參考基準 | gq-01-08, gq-01-09 |
| 慣性破壞（第一章：整理慣性） | 整理格局累計逾20個交易日，期間無K線收盤突破前2日區間最高點，其後出現大漲K線收盤突破此慣性 | gq-01-09 |
| 慣性破壞（第四章：威廉指標提前訊號） | 威廉指標尚未離開超買（賣）區，但先有連續8根以上K線未曾跌破（突破）前一天真實低（高）點的慣性，此次首度跌破（突破）即成立提前訊號；與第一章定義的「整理慣性」門檻不同，分列 | gq-04-03 |
| 提前訊號 | 指標（KD、威廉指標）尚未正式產生傳統訊號（如尚未離開超買超賣區）前，價格K線已提前出現轉折或突破前一天低（高）點，可提前視為訊號成立 | gq-02-05, gq-02-06, gq-04-03 |
| 萬佛朝宗 | 個股突破前，各天期均線（MA10/20/60/120/240）糾結收斂在同一狹窄區間，此時以大漲K線（常伴跳空）創新高突破，是作者認定最佳的強勢股訊號型態 | cz-02-01 |
| 蟑螂主力 | 作者對某類主力的戲稱：當日爆量達平日近十倍、以跳躍式衝至漲停但盤中又打開，行情呈現「一日行情」特徵，非真正的領先突破 | cz-02-01 |
| 攙壓式出貨 | 股票已連續多根漲停後，出現「漲停開盤卻遭盤中賣壓打到跌停」的量價背離現象，視為主力出貨警訊 | cz-02-01 |
| 甜蜜點（股勝先選用法） | 乖離值跌破 -10 後，價格出現反彈掙扎、企圖返回 -10 之上卻未能站上，隨即再度出現空方訊號的**第一次**放空點，是整段跌勢中品質最佳的切入位置 | gs-01-02 |
| 打水漂起攻 | 短天期均線與長天期均線（比例≥3倍）開合值由約10%附近逐步收斂到3%以內，短天期均線觸底彎頭後被K線收盤向上突破，且突破前須已有一段漲勢背景 | gs-03-02 |
| 巴掌行情（股勝先選用法） | 法人連續賣超逾10天，但價格區間震盪幅度≤10%（最佳≤5%）不破位，代表籌碼可能被隱形買家吸收；書中以此戲稱此類價量背離現象 | gs-04-02 |
| 一價到底（漲停／跌停K線） | 開盤即以漲停（跌停）鎖死、盤中不再打開的K線；出現時可將移動停利點直接調整至隔日平盤位置，不必等待其他停利條件 | gs-01-01, gs-01-02 |
| 背離向下／背離向上（股勝先選第二章用法：週KD） | 價格創新高，但週K值卻小於週D值（背離向下）；反之為背離向上；須等「價格創新高後、指標交叉才能認定背離發生」，與 q2-06 一般「背離」定義所用指標與時間尺度不同，故分列 | gs-02-00, gs-02-01 |
| 背離（股勝先選第五章用法：KD45＋RSI5） | KD(45) 觸及嚴重超買（賣）區但 RSI(5) 未能同步抵達，須觀察兩者是否呈現價格與指標不同步的背離走勢，並要求背離起點與對應點各自的 RSI 門檻值；與 q2-06、gs-02 的背離定義皆不同，故分列 | gs-05-02 |

## 三、進出場與風險管理

| 術語 | 定義 | 出處 |
|---|---|---|
| 補進場 | 訊號K距極端點過遠（停損 > 20 點）時，等拉回/反彈使停損縮小到 20 點內再進場；q3-01 規定 10 根K線內完成 | q3-01, q3-05, q3-08 |
| 大K線／超大K線 | q3-09-01：訊號K漲跌 > 30 點（大K線）；q3-09-02：> 60 點（超大K線，直接放棄）；q3-07：訊號K振幅大到 20 點停損蓋不住極端點 | q3-07, q3-09 |
| 反手 | 停損出場後轉向操作；各方法條件不同（60 點、15 點、100 點門檻等），見各文件 | q3-02, q3-07, q3-09-02, q3-10 |
| 停損並反手 | 訊號未獲確認時，在對側濾網被突破時停損原單並反向進場 | q3-10 |
| 折返停利 | 獲利達門檻（常見 15 點）後價格回吐到某點位即出場 | q3-07, q2-04, q2-03-02 |
| SAR 移動停利 | 達獲利目標後以 SAR 追蹤；影線觸及不出場，收盤觸及才出場；股勝先選另把「收盤突破/跌破SAR」當作訊號K線品質不佳時的**進場**確認工具（而非只用於停利），用法略有擴充 | q3-01, q2-01；gs-05-01, gs-05-02（作為進場確認與停利雙重用途） |
| 均線移動停利 | 達獲利目標後以 MA10（加速時 MA5/MA4）收盤跌破/突破出場 | q3-01, q3-11 |
| 階梯出場 | 每根創新高（低）K線與前一根比較，取較有利者墊高/降低移動停利 | q3-01 |
| 無縫接軌 | 跨日跳空 < 10 點時延用前日行情（超買超賣紀錄、極端點）；≥ 10 點不延用 | q2-06-02, q3-01, q3-10 |
| 0 位設法 | RSI 背離停損設法之一，以 RSI 對應價位作參考 | q2-06-03 |
| 真實高低點（股技期招第一章） | 真實低點＝訊號（大漲）K線本身最低點與前一日收盤價，兩者取其低；真實高點＝該K線本身最高點與前一日收盤價，兩者取其高 | gq-01-12, cz-01-02, cz-03-01（定義相同）, gs-01-02（定義相同） |
| 真實高低點（股技期招第四章） | 真實低點＝前一天K線最低點與前二天K線收盤價，兩者取其低；真實高點＝前一天K線最高點與前二天K線收盤價，兩者取其高；與第一章定義的參照K線不同，分列 | gq-04-03 |
