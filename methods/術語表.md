# 術語表

本表把《期貨奇績2》（q2）與《期貨奇績3 勝杯在握》（q3）在各方法文件中用到的術語集中整理。
括號內為出處方法 id；**同一詞在兩本書定義不同時分列**，使用時以該方法文件為準。

## 一、位置與結構

| 術語 | 定義 | 出處 |
|---|---|---|
| 平盤 | 昨日（日線）收盤價，當日多空基準線 | q3-07, q3-09-02 |
| 極端位置 | 盤中高低震幅 ≥ 30 點；震幅不足時，極端高/低點距平盤 ≥ 40 點亦可 | q3-01, q3-02 |
| 最高K線／最低K線 | 同時符合「最高點最高＋收盤最高」（或最低點最低＋收盤最低）的當下盤中極端K線 | q3-05 |
| 層級1峰點／谷點 | 左右各至少 1 根K線高點較低（谷點：低點較高）的局部轉折點 | q3-05, q3-08, q3-09 |
| 層級2峰點／谷點 | 左右各 2 根K線高點皆較低（谷點：低點皆較高）；可有單峰/雙峰/三峰及中間夾一根的變形 | q2-01, q2-03, q2-04, q2-06 |
| 峰位濾網／谷位濾網 | 以峰谷點畫出的水平線，收盤突破/跌破即成立訊號 | q3-08, q2-03 |
| 無遮蔽（收盤） | 訊號K收盤須是該波段以來最高（低）收盤，不被同波段任何K線高低點遮蔽；影線觸及不算 | q2-01, q2-04, q2-05 |
| 過一高／破一低 | q3：反色K線收盤超過前一根同色K線的極端點；q2（PVT+RSI）：收盤突破前一轉折高點／跌破前一轉折低點 | q3-02, q3-06, q2-03-02 |
| 休息（狀態） | 突破/跌破均線後，K線暫不創新高/新低、收盤也未反向穿越均線的整理階段 | q3-08-01 |
| 縮腳 | K線影線或實體未延伸過前一極端點，力道減弱 | q3-06, q3-08 |
| 壘頂／壘底 | 相鄰兩根K線高點相同（壘頂）或低點相同（壘底） | q3-04 |
| 趨勢階梯（PVT 通道） | 相鄰兩個層級轉折點取孰低（多方）／孰高（空方）構成的階梯狀支撐壓力線 | q2-03 |
| 控盤易主 | 收盤突破/跌破趨勢階梯，只代表控盤方改變，本身不是買賣訊號 | q2-03 |
| 四柱／關卡 | 昨高、昨低、昨收、今開四個價格關卡 | q2-04-02 |
| 金叉區間／死叉區間 | 大週期 KD 黃金交叉到下次死亡交叉之間（或反之），作為順勢方向濾網 | q2-04-01 |
| 均線轉折點（均線谷點、彎曲中點） | 均線方向改變的位置 | q3-08, q3-09-01 |
| 卡在均線 | 拉回/反彈時收盤未真正穿越均線、只貼近均線，仍可能被認可為有效峰谷位 | q3-11 |

## 二、K線型態與訊號

| 術語 | 定義 | 出處 |
|---|---|---|
| 頂雙黑 | 當下盤中最高點為下跌黑K，下一根黑K收盤破前黑K低點 → 空訊 | q3-01 |
| 底雙紅 | 當下盤中最低點為上漲紅K，下一根紅K收盤過前紅K高點 → 買訊 | q3-01 |
| 底V字買訊／頂倒V空訊 | 兩根同向K（第二根為當下唯一極端）＋一根反向K收盤過一高/破一低 | q3-02 |
| 母K線／子K線 | 母K為當下盤中極端K線，子K實體被包在母K實體內（懷孕狀） | q3-03 |
| 頂母子空訊／底母子買訊 | 母子組合後，訊號K反色收盤穿越母K開盤價 | q3-03 |
| 以牙還牙 | 極端K線與隔根反色K線漲跌點數差距 ≤ 1 點的反轉訊號 | q3-04 |
| 過三高／破三低 | K線收盤同時突破（跌破）前 1 根與前 3 根K線區間高（低）點 | q3-05 |
| 連五黑遇首紅／連五紅遇首黑 | 連續 5 根以上同色K（幅度 > 40 點）後，隔根不創新極端的反色K → 反轉訊號；亦作停利口訣 | q3-06 |
| 跳高收黑空訊／跳低收紅買訊 | 開盤離平盤 ≥ 40 點，首根K線收盤方向與跳空方向相反 | q3-07 |
| 豬陽訊號（豬陽變色） | 黑K接紅K收盤突破其高點（買）／紅K接黑K收盤跌破其低點（賣） | q3-08-02 |
| 蜻蜓點水 | 單根K線短暫跌破/突破基準線（均線或平盤），隔根立即收回 | q3-09 |
| RSI 正差買訊／負差空訊 | 極端K線對應 RSI 後值較前值高（低）20 以上，且為 RSI 真正轉折 | q3-10 |
| N型／倒N型（0-1-2-3） | 0 起點 → 1 峰 → 2 拉回（不破 0）→ 3 收盤突破 1；倒 N 為空方鏡像 | q2-03, q2-04, q2-06-04 |
| 紅三兵／黑三兵 | 連續三根同色K線，在盤中極端位置視為反轉 | q2-05-01 |
| 極端位置最大量 | 盤中最高（最低）K線同時是盤中最大量K線 | q2-05-02 |
| 背離 | 價格與指標（或收盤）走勢不同步 | q2-06 |
| 假性創新高／創新低 | 影線創新高（低）但收盤未同步創高（低） | q2-06-01 |
| 鈍化 | 0～100 震盪指標長時間停在極端區，背離變常態、反轉證據力轉弱 | q2-06-04 |
| 順向訊號／逆向訊號 | 順向跟隨趨勢，逆向為反轉；衝突時逆向優先 | q3-09 |
| 對立訊號不可侵入對方收盤 | 短距離內相反訊號，後訊號收盤若未越過前訊號收盤 → 忽略後訊號 | q3-02, q3-09 |

## 三、進出場與風險管理

| 術語 | 定義 | 出處 |
|---|---|---|
| 補進場 | 訊號K距極端點過遠（停損 > 20 點）時，等拉回/反彈使停損縮小到 20 點內再進場；q3-01 規定 10 根K線內完成 | q3-01, q3-05, q3-08 |
| 大K線／超大K線 | q3-09-01：訊號K漲跌 > 30 點（大K線）；q3-09-02：> 60 點（超大K線，直接放棄）；q3-07：訊號K振幅大到 20 點停損蓋不住極端點 | q3-07, q3-09 |
| 反手 | 停損出場後轉向操作；各方法條件不同（60 點、15 點、100 點門檻等），見各文件 | q3-02, q3-07, q3-09-02, q3-10 |
| 停損並反手 | 訊號未獲確認時，在對側濾網被突破時停損原單並反向進場 | q3-10 |
| 折返停利 | 獲利達門檻（常見 15 點）後價格回吐到某點位即出場 | q3-07, q2-04, q2-03-02 |
| SAR 移動停利 | 達獲利目標後以 SAR 追蹤；影線觸及不出場，收盤觸及才出場 | q3-01, q2-01 |
| 均線移動停利 | 達獲利目標後以 MA10（加速時 MA5/MA4）收盤跌破/突破出場 | q3-01, q3-11 |
| 階梯出場 | 每根創新高（低）K線與前一根比較，取較有利者墊高/降低移動停利 | q3-01 |
| 無縫接軌 | 跨日跳空 < 10 點時延用前日行情（超買超賣紀錄、極端點）；≥ 10 點不延用 | q2-06-02, q3-01, q3-10 |
| 0 位設法 | RSI 背離停損設法之一，以 RSI 對應價位作參考 | q2-06-03 |

## 四、指標與選擇權

| 術語 | 定義 | 出處 |
|---|---|---|

| 價平／價外二檔 | 價平＝最接近現貨價的履約價；價外二檔＝離價平兩個履約價級距 | q3-11 |
| 跨月 OP | 非當月到期的選擇權，避免時間價值耗損過快 | q3-11 |
| 對開 | 同時持有方向相反的 CALL 與 PUT；買方最大風險僅權利金，不同於期貨鎖單 | q3-11 |
