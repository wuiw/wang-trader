# 頂母子空訊／底母子買訊

> 一句話摘要：盤中極端K線（母K）之後，緊接一根實體被「懷孕式」包在母K實體範圍內的子K線，第三根訊號K線再以與母K相反顏色、收盤穿越母K開盤價並跌破／突破子K的方式反轉，即構成頂母子空訊或底母子買訊。

## 1. 核心概念

在盤中極端位置，母子線是本書介紹的第三種反轉組合（前兩種見第一章「頂底雙紅黑」、第二章「V字轉折」）。母子線以**實體**（開盤—收盤範圍）來判別：子K線的實體被限制在母K線的實體範圍內，狀似懷孕（p.67）。

母子型態的外觀規定：**子K線最高點必須低於母K線最高點，且子K線最低點必須高於母K線最低點；母子K線之間的高低點絕不能有相等狀況**，這是外觀上最重要的條件。實體之間則可以等高或等低，但若母K線是無上下影線的純實體K線，子K線實體就不能與其同高或同低（p.67）。

- **頂母子空訊**：母K線是當下盤中最高、且為上漲的紅K線；隔一根子K線夾在母K實體與高低點範圍內；第三根訊號K線須為黑K線，收盤跌破子K線最低點，且收盤小於或等於母K線開盤價，即構成空訊（p.67）。
- **底母子買訊**：母K線是當下盤中最低、且為下跌的黑K線；隔一根子K線夾在母K範圍內；第三根訊號K線須為紅K線，收盤突破子K線最高點，且收盤大於或等於母K線開盤價，即構成買訊（p.68）。

## 2. 適用前提

1. 母K線須為「當下盤中最高K線」或「當下盤中最低K線」，且此一「最高/最低K線」須同時符合**最高點最高**與**收盤最高**（或最低點最低與收盤最低）兩個條件，僅符合其一不算（p.74，圖3-8）。
2. 盤中極端位置的高低震幅通常須在**30點以上**；若因跳空使震幅未達30點，可改測「極端位置到平盤的距離」是否超過**40點**，符合者仍視為滿足震幅條件（p.68–69，圖3-3、3-4）。
3. 商品以台指期為主，書中另有滬深300期指、恆生指數期貨的實例（p.78–79），顯示本訊號可跨商品套用。

## 3. 訊號定義

### 3.1 頂母子空訊（空方）

1. **C1** 母K線為當下盤中最高K線（最高點最高且收盤最高須同時成立），且為上漲之紅K線。（p.67, p.74）
2. **C2a**（實體條件）子K線之實體須落在母K線實體範圍內；實體邊界可與母K線實體邊界等高／等低，但若母K線為無上下影線之純實體K線，子K線實體不可與其同高或同低。（p.67）
3. **C2b**（高低點條件）子K線之最高點須**低於**母K線最高點，且子K線之最低點須**高於**母K線最低點；兩者絕不可相等。（p.67）
4. **C3** 訊號K線（第三根）須為黑K線。（p.67）
5. **C4** 訊號K線最高點不能高於母K線最高點。（p.67）
6. **C5** 訊號K線收盤須**小於或等於**母K線開盤價。（p.67）
7. **C6** 訊號K線收盤須**跌破**子K線最低點。（p.67）

### 3.2 底母子買訊（多方，與3.1鏡像）

1. **C1** 母K線為當下盤中最低K線（最低點最低且收盤最低須同時成立），且為下跌之黑K線。（p.68）
2. **C2a／C2b** 子K線之實體與高低點條件同3.1（懷孕式，高低點不可相等）。（p.67, p.68）
3. **C3** 訊號K線須為紅K線。（p.68）
4. **C4** 訊號K線收盤須**大於或等於**母K線開盤價。（p.68）
5. **C5** 訊號K線收盤須**突破**子K線最高點。（p.68）

## 4. 進場

- 訊號K線收盤確認後即可進場（p.70：「直接在訊號C收盤進場」）。
- 若訊號K線收盤距離母K極端點已超過20點（停損將超過書中慣用的20點上限），可選擇**等待拉回／反彈**，讓進場價與母K極端點的距離縮小至20點以內再補進場；也可以**直接在訊號K收盤進場**，但停損仍設為20點（p.70）。
- 圖3-4範例：訊號K線距離母K最低點剛好20點，屬於可以立刻進場的情況（p.70）。
- **距離分級（p.73）**：
  1. 距離 ≤20點：可立刻進場。
  2. 距離20～30點：可等待反彈／拉回，讓補空（多）位置縮小至距母K極端點20點以內；也可以直接進場，但仍設20點停損。
  3. 距離達**40點以上**：這種訊號**宜放生不操作**；若執意進場，只能等稍作反彈、將距離縮小至20點以內才進場，**不可**直接以進場價±20點的方式進場（p.73，圖3-7：訊號B收盤離母K A高點達40點，正常應放生；若執意進場，仍須等反彈縮小至20點才進場，停損點數不變）。
- **折返出場的進場延伸考量（p.77，圖3-11，跨章節示範）**：訊號距離約20～30點時，直接進場設20點停損可能被長上下影線掃到停損；等待小幅拉回（例如僅拉回幾點）再補進場可避免被掃停損，但也可能等不到理想拉回；書中將此列為操作者自行取捨的「哲學問題」，並未給出強制規則。

## 5. 停損

- 停損設在母K極端點（頂母子＝母K最高點、底母子＝母K最低點），且進場價到停損的距離以**20點**為上限：不論是等拉回補進場、或直接在訊號K收盤進場，風險都控制在20點（p.70；本書極端位置訊號一貫以極端點為停損、20點為上限，見 q3-01 §5、q3-02 §5）。
- 圖3-3的案例中，A的高點超過訊號收盤30點，書中提示「在設停損位置自然不能超過20點限制」，故直接進場時以進場價外20點為停損，而非依母K到訊號K的實際距離設定（p.70）；圖3-4 訊號K距母K低點剛好20點，停損即母K低點（p.70）。
- 訊號K線距離母K極端點達**40點以上**時，原則上放生不操作；若執意進場，須先等反彈使距離縮小至20點以內才進場，堅持停損點數不變，不可直接以進場價外20點的方式進場（p.73，圖3-7）。

## 6. 出場 / 停利

- **折返平倉（小賺小賠出場）**：進場後若行情雖朝有利方向前進，但獲利幅度不足以達到一般預期的停利目標（書中示範獲利僅16點，未達期望的20點以上），隨後行情又折返回到進場價位附近時，應在此時**撤單平倉**，寧可小賺小賠了結，也不要冒進拖到觸發停損（p.72–73，圖3-6）。
- 除上述折返平倉規則外，書中本章節未再明確訂出頂底母子訊號本身的停利／移動停損規則。範例圖說中多次出現「連五黑遇首紅平倉」「五連黑遇首紅平倉」等描述（p.68–69圖3-2、p.71圖3-5、p.78圖3-12），暗示可搭配另一套規則作為既有部位的出場依據，但該規則本身屬於其他章節內容（參見 q3-06-連五黑遇首紅與連五紅遇首黑），本章未展開細節。

## 7. 過濾：不做的情況

1. 子K線最高點等於母K線最高點、或最低點等於母K線最低點，皆不成立母子關係（不可有同高同低）。（p.67）
2. 子K線實體超出母K線實體範圍（例如子K實體高點高於母K實體），不符合「懷孕」外觀，不成立訊號。（p.74，圖3-8）
3. 母K線只符合「最高點最高」但收盤不是當下最高收盤（或反之），不能視為合法母K線。（p.74，圖3-8）
4. 訊號K線的影線雖已跌破（或突破）母K線開盤價，但**收盤**未真正小於或等於（或大於或等於）母K線開盤價，不算訊號成立——僅有影線觸及不夠。（p.71，圖3-5的B點）
5. 高低震幅未達30點、且距平盤亦未達40點時，不符合震幅條件，訊號不成立。（p.68–69）
6. 訊號K線距離母K極端點達**40點以上**時，原則上**放生不操作**（p.73，圖3-7）。

## 9. 作者提醒與常見錯誤

- 容易只看外觀「最高/最低K線」就急著判斷母子訊號成立，卻忽略「收盤也必須是當下最高/最低收盤」這項同等重要的條件（p.74）。
- 容易忽略子K線實體是否真的完全落在母K線實體之內，誤把子K實體超出母K實體的組合當作合法母子懷孕外觀（p.74）。
- 訊號K線的影線觸及母K開盤價、但收盤未真正跨越，容易被誤判為訊號成立，須以**收盤**為準（p.71）。
- 跳空開盤時容易忽略「距平盤40點」的震幅替代條件，誤以為震幅不足30點就不能操作（p.68–69）。

## 10. 規則速查（Checklist）

**頂母子空訊（空）**
- [ ] 母K為當下盤中最高K線（最高點最高＋收盤最高同時成立），且為紅K
- [ ] 子K實體落在母K實體內；子K最高點低於母K最高點、最低點高於母K最低點（不可相等）
- [ ] 訊號K為黑K，最高點不高於母K最高點
- [ ] 訊號K收盤 ≤ 母K開盤價
- [ ] 訊號K收盤跌破子K最低點
- [ ] 高低震幅 ≥30點，或極端位置距平盤 ≥40點
- [ ] 訊號K收盤確認後進場放空，停損20點（或等拉回至距極端點20點內補空；距離達40點以上宜放生不操作）
- [ ] 獲利不足且行情折返回進場價 → 撤單平倉了結

**底母子買訊（多）**
- [ ] 母K為當下盤中最低K線（最低點最低＋收盤最低同時成立），且為黑K
- [ ] 子K實體落在母K實體內；子K最高點低於母K最高點、最低點高於母K最低點（不可相等）
- [ ] 訊號K為紅K
- [ ] 訊號K收盤 ≥ 母K開盤價
- [ ] 訊號K收盤突破子K最高點
- [ ] 高低震幅 ≥30點，或極端位置距平盤 ≥40點
- [ ] 訊號K收盤確認後進場買進，停損20點（或等拉回至距極端點20點內補多；距離達40點以上宜放生不操作）
- [ ] 獲利不足且行情折返回進場價 → 撤單平倉了結
