# 過三高買訊／破三低空訊

> 一句話摘要：行情在盤中極端高（低）位置出現之後，若首次有一根K線的**收盤**同時跌破（突破）前1根與前3根K線的區間低（高）點，代表原有慣性遭到破壞，構成反轉空訊（買訊）。

## 1. 核心概念

在5分鐘K線的價格運動中，行情遵循慣性不斷墊高或不斷創低，直到某種反轉現象中止這個慣性。從大波段的角度看，漲勢中止的訊號是跌破前一波低點，跌勢中止的訊號是突破前一波高點；中止不一定代表反轉，也可能只是讓原趨勢陷入整理（p.101）。

中止趨勢的最初徵兆，是K線**收盤**跌破前一根K線低點（漲勢末端）或收盤突破前一根K線高點（跌勢末端），此現象稱為「破一低」或「過一高」，是轉折的第一徵兆。但只破一根或兩根K線的高低點，反轉效力有限；作者發現，一次跌破（突破）**前三根**K線區間的低（高）點，其反轉效果比只破一、二根K線的高低點更可靠（p.101）。

因此，本訊號的核心是：盤中行情來到最高位置後，第一次出現K線收盤**同時**跌破前1根與前3根K線低點，才是真正的破三低空訊；反之，盤中行情來到最低位置後，第一次出現K線收盤**同時**突破前1根與前3根K線高點，才是真正的過三高買訊（p.101–102）。

## 2. 適用前提

1. 週期為5分鐘K線（p.101）；商品以台指期為主，書中另有小DAX、金融時報期指、A50、日經指數期貨的實例（p.116–117），顯示可跨商品套用，惟需留意海期商品訊號常出現大幅K線，停損點數宜自行評估（p.116）。
2. 「破三低空訊」須發生在盤中最高K線出現之後，且**自最高K線出現起算，中途沒有任何一根K線的收盤曾經跌破前1根K線最低點**，直到本次才第一次同時跌破前1根與前3根K線低點，才算數（p.101–102）。
3. 「過三高買訊」對稱要求：自盤中最低K線出現起算，中途沒有任何一根K線的收盤曾經突破前1根K線最高點，直到本次才第一次同時突破前1根與前3根K線高點（p.102）。
4. 跳空開盤時的特殊前提：
   - 跳高開盤後短暫盤整再突破，除非行情已產生「層級1谷點」（左右至少各有一根低點較高的K線），否則過三高視為無效訊號（p.103）。
   - 跳低開盤後短暫盤整再跌破，除非行情已產生「層級1峰點」（左右至少各有一根高點較低的K線），否則跌破三低並無意義（p.103）。
   - 層級1峰點／谷點的判定方式沿用《期貨奇績2》第五章介紹的轉折峰谷點概念，本文件僅轉述其判斷準則，未重新展開完整定義。
5. 優先順序：跳高開盤先找破三低空訊，若出現層級1谷點才考慮過三高買訊；跳低開盤先找過三高買訊，若出現層級1峰點才考慮破三低空訊（p.104）。

## 3. 訊號定義

### 3.1 破三低空訊（空方）

1. **C1** 行情已出現「當下盤中最高K線」，且自該K線起算，尚未有任何一根K線收盤跌破前1根K線最低點。（p.101–102）
2. **C2** 訊號K之前，本交易日須有滿3根K線可供比較（p.104「破三根K線低點，絕對是前面要有三根K線，少一根就不算破三低」；圖5-3：開盤第一根即最高，第三根就跌破前兩根低點，不算）。比較區間是訊號K之前的3根K線，可包含最高K線本身與其之前的K線：最高K線當根收盤即跌破前三根區間低點亦成立（p.103，圖5-2），「一般都是最高K線出現後，三根K線內發生破三低訊號」（p.103）；圖5-4、5-8、5-11、5-12 皆為最高K線隔一根即跌破的案例。
   （舊版文件寫成「最高K線之後須累積3根以上K線」，會排除書中大多數範例，已更正。）
3. **C3** 出現一根K線，其**收盤同時**跌破「前1根K線最低點」與「前3根K線區間最低點」。（p.101–102）

### 3.2 過三高買訊（多方，與3.1鏡像）

1. **C1** 行情已出現「當下盤中最低K線」，且自該K線起算，尚未有任何一根K線收盤突破前1根K線最高點。（p.102）
2. **C2** 訊號K之前本交易日須有滿3根K線可供比較（區間可含最低K線本身與其之前的K線）。（p.103–105）
3. **C3** 出現一根K線，其**收盤同時**突破「前1根K線最高點」與「前3根K線區間最高點」。（p.102）

## 4. 進場

- 訊號K線收盤確認後即可進場（圖5-1範例：B收盤放空、D收盤買進，p.102）。
- 若訊號K線本身為「大K線」（跌／漲點數偏大），距離盤中極端位置（最高／最低點）**超過20點**時，書中列出三種應對方式（p.104–105，p.112–113）：
  1. **忽略不操作**。
  2. **等待拉回／反彈**，使進場價距離極端位置縮小至20點以內，再補進場。
  3. **當下直接進場**，但停損仍設20點（屬較冒險的做法）。
- 若訊號K線距離極端位置**超過40點以上**，通常採用忽略不操作（p.112–113）。
- 若距離約**30點附近**，可等待折返，讓距離縮小至20點以內再補進場（p.112–113，圖5-11）。

## 5. 停損

- 停損設在盤中極端點（p.113：等反彈縮小至20點內再進場放空，「反而上漲觸及A高點停損」），進場價到停損的距離以**20點**為上限；距離超過20點而直接進場時，停損改設在進場價外20點（p.105「當下進場，停損仍設在20點」；p.112–113）。
- 若訊號方向出現後，行情尚未走遠（前行不到15點）即折返並觸及停損，此後若出現K線收盤創新高或破新低，可以進行**反手操作**：反手進場後，同樣依原方向的相反方向設20點停損（p.113，圖5-12：「在C的收盤創下盤中新高時，則可以反手買進操作，並向下設20點停損位置」）。

## 6. 出場 / 停利

書中未明確說明過三高／破三低訊號本身的停利點數或移動停損機制。與既有部位（尤其是先前已用另一次過三高／破三低訊號建立的部位）搭配時，書中提供以下處置原則（用於判斷是否須將原部位平倉反手）：

- 若已持有多單（來自過三高買訊），之後很快又出現破三低空訊，須檢視空訊K線的**實體**是否與原買訊K線的實體**重疊**：
  - 若**重疊**，空訊視為忽略，不將原多單平倉反手（p.108，圖5-7）。
  - 若**不重疊**，空訊視為有效訊號，須將原多單平倉並反手放空（p.109，圖5-8，原文為對稱案例：先有破三低空訊，後出現不重疊的過三高買訊，須平倉反手做多）。

## 7. 過濾：不做的情況

1. 訊號K之前本交易日不足3根K線可供比較（例如開盤第一根即最高、第三根就跌破前2根低點），不能視為破三低（過三高）。（p.104–105，圖5-3）
2. 跳高開盤、短暫盤整後突破，若尚未出現「層級1谷點」，過三高視為無效訊號。（p.103，圖5-2）
3. 跳低開盤、短暫盤整後跌破，若尚未出現「層級1峰點」，破三低視為無意義。（p.103）
4. 窄幅震盪格局下，後出現的訊號若與先前已成立訊號的K線實體重疊，後出現的訊號視為忽略，不將既有部位平倉反手。（p.108，圖5-7）
5. 訊號K線距離盤中極端位置超過40點以上者，通常採忽略不操作。（p.112–113）

## 9. 作者提醒與常見錯誤

- 容易誤把只跌破／突破1、2根K線高低點當作訊號成立，實際上必須跌破／突破**前三根**K線區間高低點才算數，且最高（最低）K線之後必須確實累積滿3根K線（p.104–105）。
- 跳空開盤時容易忽略層級1峰／谷點的前提，誤判過三高／破三低訊號有效性（p.103）。
- 訊號K線距極端位置過遠（如超過40點）時仍勉強進場，忽略「忽略不操作」也是合理選項之一（p.112–113）。
- 容易忘記檢查先後出現的多空訊號K線實體是否重疊，導致「忽多忽空」的頻繁進出（p.108–109）。
- 同一根K線可能同時符合多種反轉條件（如頂雙黑空訊與破三低空訊重疊），此時仍應以更嚴謹的條件（例如是否真正位於盤中極端位置）判斷訊號的有效性，而非照單全收（p.117，圖5-20）。

## 10. 規則速查（Checklist）

**破三低空訊（空）**
- [ ] 已出現當下盤中最高K線，且自該K線起算尚無K線收盤跌破前1根K線低點
- [ ] 訊號K之前本交易日已有滿3根K線可比較（區間可含最高K線本身）
- [ ] 出現K線收盤同時跌破前1根與前3根K線區間低點
- [ ] （跳空情境）已產生層級1峰點
- [ ] 訊號K距極端高點 ≤20點：直接進場，停損20點；20–30點：可等拉回至20點內補空；≥40點：通常忽略
- [ ] 若與先前買訊K線實體重疊，忽略本次空訊

**過三高買訊（多）**
- [ ] 已出現當下盤中最低K線，且自該K線起算尚無K線收盤突破前1根K線高點
- [ ] 訊號K之前本交易日已有滿3根K線可比較（區間可含最低K線本身）
- [ ] 出現K線收盤同時突破前1根與前3根K線區間高點
- [ ] （跳空情境）已產生層級1谷點
- [ ] 訊號K距極端低點 ≤20點：直接進場，停損20點；20–30點：可等拉回至20點內補多；≥40點：通常忽略
- [ ] 若與先前空訊K線實體重疊，忽略本次買訊
