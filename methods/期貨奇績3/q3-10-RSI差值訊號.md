# RSI 差值訊號（正差買訊 / 負差空訊）

> 一句話摘要：當K線來到盤中當下最高（或最低）點，RSI也處於相對高（低）位，若下一根RSI值與前值差距達20以上，即視為反轉有力跡證，形成放空（或買進）訊號。

## 1. 核心概念

盤中行情抵達極端位置時，是否會出現反轉，可以從RSI指標下彎或上勾的幅度取得有力跡證。書中將RSI前後值的增減幅度稱為「RSI差值」（p.227）。

- **當價格K線成為盤中當下最高K線時**，對應的RSI也來到相對高點（不必是盤中RSI最高點），**若下一根RSI值小於前一值20以上**，此RSI差值具有反轉效果，通常表現為跌點較大的黑K線，形成放空訊號，稱為「RSI負差空訊」（p.227）。
- 反之，行情下跌來到**盤中當下最低K線**時，對應的RSI也來到相對低點（非盤中RSI最低點），**若下一根RSI值突然大於前一值20以上**，同樣具有反轉效果，形成買進訊號，稱為「RSI正差買訊」（p.227）。

外觀上，差值買訊的訊號K線必為盤中當下最低K線，或前一根K線為最低K線；差值空訊的訊號K線必為盤中當下最高K線，或前一根為最高K線（p.227）。

## 2. 適用前提

1. RSI差值訊號最好產生在極端位置；在過窄的震盪區間內比較差值，可靠度容易失真（p.227）。
2. 盤中當下高低震幅宜超過30點以上，甚至放大到40點更為合適（p.227）。
3. 訊號發生時間若在開盤不到30分鐘內，震幅尤需特別注意（p.227）。
4. 向上跳高開盤時，最高點距離平盤宜超過40點，此情形下適合優先尋找空訊；該階段若回檔幅度不及30點，縱有RSI正差超過20，須忽略買訊（p.227–228）。
5. 向下跳空開盤時，最低點距離平盤宜超過40點，此情形下適合優先尋找買訊；該階段若反彈不及30點，縱有RSI負差超過20，須忽略空訊（p.228）。
6. 上述兩條限制並非絕對：若跳高（或跳低）開盤距平盤不到40點卻仍產生負差空訊（或正差買訊），仍屬訊號，但「有瑕疵或不成熟」；停損控制嚴謹、敢冒險的交易者仍可一試（p.228，屬可選過濾條件而非強制禁止）。
7. 未到盤中最高或最低的極端位置時，不必時時查看RSI前後值是否超過20界限，只需在真正的極端位置出現時再檢查（p.230，圖10-3）。
8. 開盤跳空幅度在10點以內時，可視為前一日尾盤的延續，得併入前一日行情觀察極端位置，不受盤中震幅30點的極端位置規定限制；但若跳空超過10點，且當日第一根K線無法比前一日區間高（低）點更高（低），則不能套用此特例（p.237，圖10-10）。

## 3. 訊號定義

**空方（RSI負差空訊）**
1. C1：當根K線為盤中當下最高K線，或其前一根K線為盤中當下最高K線（p.227）。
2. C2：C1所指K線之RSI值，必須是本波段RSI「由升轉降」的轉折高點（即真正的相對高點），而非行情持續上漲途中臨時放大的差值；若RSI已提前開始下彎，之後才出現差值放大，不算訊號（p.231，圖10-4）。
3. C3：下一根RSI值 ≤（C2高點RSI值 − 20），亦即RSI後值比前值下彎20點以上（p.227）。
4. C4：RSI前後值若因K線收盤價與前一根相同而呈現水平移動（持平），則不得以該持平點作為C2的起算基準，須等到真正出現由升轉降的高點才成立（p.234，圖10-7）。
5. C5（RSI相對高點的認定）：C2所指的相對高點不要求是盤中RSI的最極端高值，只要是「這一小段推升過程」的相對高點即可（p.232–233，圖10-5）。

**多方（RSI正差買訊）**
1. C1：當根K線為盤中當下最低K線，或其前一根K線為盤中當下最低K線（p.227）。
2. C2：C1所指K線之RSI值，必須是本波段RSI「由降轉升」的轉折低點；若RSI已提前開始上勾，之後才出現差值放大，不算訊號（多空對稱，鏡像自p.231規則）。
3. C3：下一根RSI值 ≥（C2低點RSI值 + 20），亦即RSI後值比前值上勾20點以上（p.227）。
4. C4：RSI前後值持平（因收盤價相同）不得作為C2起算基準，須等到真正的由降轉升低點（多空對稱，鏡像自p.234規則）。
5. C5：C2所指相對低點同樣不要求是盤中RSI最極端低值，只要是這一小段下跌過程的相對低點即可（多空對稱，鏡像自p.232–233規則）。

## 4. 進場

1. 訊號確立當下即可進場：正差買訊出現即買進，負差空訊出現即放空（p.229–231，多次案例）。
2. 補進場：若第一次訊號未進場（如圖11同型態案例中提及最慢在次一個相同型態突破點補進場），可在下一個同型態且更明確的訊號點補進場（p.249，此為第十一章用語，但第十章亦有「以下附圖請讀者自己參閱比對訊號」之延伸練習，本章未另訂獨立補進場規則，書中未明確說明）。
3. 停損調整後反手：見第5節「停損」與下方「停損後反手」規則。

## 5. 停損

1. 訊號成立進場後，停損設在訊號K線極端點外20點（即訊號K的高／低點再加20點，而非以進場價為基準）（p.229「立刻設20點停損位置」；p.230、p.231同樣敘述「設下20點停損位置」；p.233明確以訊號K線極端點為基準）。
2. 過濾：若訊號K線本身漲跌點數過大，導致進場到停損之間的風險超過40點，須忽略該訊號，不進場（p.233，圖10-6，D位置案例）。
3. 停損後可反手（見下）；除反手情形外，其餘依20點停損機制執行，書中未提及反手以外的停損後加碼或其他處理。

### 停損（未確認訊號）後之反手規則

當訊號尚未得到「原方向延續確認」（即價格尚未收盤突破/跌破訊號K線本身的高/低點）時，適用以下反手規則：

1. 負差空訊反手買：放空進場後，若K線收盤**未曾**跌破訊號K線（或其定義的相對低點）之最低點，而行情反而重新收盤突破訊號發生前的相對高點（濾網水平線），則不必等觸及20點停損，即可在該收盤突破的瞬間，停損原空單並反手追買（p.235，圖10-8；p.240圖10-16；p.241圖10-17）。
2. 正差買訊反手空（鏡像）：買進進場後，若K線收盤**未曾**突破訊號K線之最高點，而行情反而收盤跌破訊號發生前的相對低點濾網水平線，則停損原多單並反手放空（p.240，圖10-15）。
3. 若已出現「K線收盤跌破空訊最低點」（或「K線收盤突破買訊最高點」），即代表訊號已按20點停損機制觸發，**不得**再做反手（p.235：「如果B出現RSI負差空訊後，後續行情，K線收盤曾經低於B的最低點，則不能做反手買動作」）。
4. 反手位置的距離濾網：若反手進場位置距平盤已經超過100點以上，通常不宜再反手，除非當日為重挫（急殺）盤（p.236，圖10-9）。

### 訊號已延續確認後之停損（不可反手）

訊號的「已確認」狀態有兩種等價的判準（p.233、p.236）：

1. K線收盤已經突破正差買訊訊號K線的最高點（或跌破負差空訊訊號K線的最低點）；或
2. 行情曾順著訊號方向走了15點以上（見第6節）。

只要滿足其中之一，即視為訊號已確認：其後若行情折返回進場價（訊號K收盤價），必須出場了結，不可反手；若行情反轉並創新低（或新高），也**只能停損**，不可再反手順著新方向操作（p.233、p.236，圖10-9）。未達15點獲利、且K線收盤也未突破/跌破訊號K極端點時，才適用上方「未確認訊號」的反手規則。

## 6. 出場 / 停利

1. 若訊號成立後，行情順著訊號方向前進未達15點又重新折返回到訊號K線收盤價位置（買訊：跌破訊號K收盤；空訊：漲破訊號K收盤），應撤單平倉離場，不留倉續抱（p.232–233，圖10-6）。
2. 若行情已順訊號方向走了15點以上，視為訊號已確認：其後若折返回到進場價（訊號K收盤價），必須出場了結，且不可反手；此時另有其他方法（如均線訊號）可判斷是否進場，本方法不再提供依據（p.233，圖10-6）。
3. 書中舉例以MA10作為停利機制之一（p.229，圖10-2：「假設採取MA10為停利機制，一直持有多單」），但未明確規定此為必用規則，僅為範例中的假設性停利方式。
4. 若同一訊號模式在當日第一趟操作未能獲利，建議同日不再使用相同訊號模式進場（p.233）。
5. 若訊號發生時間已接近收盤，僅可作為平倉出場訊號，不應視為新倉進場依據（p.230–231，圖10-3，F位置）。
6. 除上述規則外，書中未進一步明確說明其他固定停利點數或指標停利機制。

## 7. 過濾：不做的情況

1. 開盤第一根K線不得作為任何訊號判斷依據，因其無法辨認盤中最高或最低（p.228，圖10-1）。
2. 差值放大若非發生在「RSI由升轉降」或「由降轉升」的真正轉折點，而是行情持續上漲/下跌途中臨時出現的差值放大，不視為訊號（p.230–231，圖10-4）。
3. RSI前後值因收盤價相同而持平時，隔一根出現的上勾或下彎不視為差值訊號；需等到真正由高點快速下彎（或由低點快速上勾）的那一根才算數（p.234，圖10-7）。
4. 盤中高低震幅未達30點（跳空情形未達40點）的極端位置條件時，該處差值訊號可靠度低，依第2節之3-6項規則過濾（p.227–228）。
5. 訊號K線本身漲跌點數過大，導致停損可能超過40點以上時，忽略訊號（p.233，圖10-6）。
6. 訊號發生時間接近收盤時，僅作平倉訊號，不作新倉訊號（p.230–231）。
7. 已延續確認之原訊號，反轉時僅可停損，不得反手（p.236，圖10-9）。
8. 反手進場位置距平盤已超過100點，除非為重挫盤，否則不宜反手（p.236，圖10-9）。

## 9. 作者提醒與常見錯誤

1. 訊號的條件本來就有步驟依循，錯誤認定在很多案例中不利於操作（p.232）。
2. 測試RSI前後值是否差距20以上，通常僅需在上揚或下彎幅度較大時才查核，不必特意製作指標檢測（此為講解方便才附上RSI前後值差柱狀圖）（p.229）。
3. 最要警戒行情「走不遠就折返」的狀況（p.233）。
4. 當日第一趟同型態RSI差值訊號未能獲利，同日不宜再用相同模式進場（p.233）。
5. 差值訊號雖須發生在盤中極端位置，但極端位置並非不能被攻破；此時應考慮以反手取代單純停損，讓新方向帶來獲利機會（p.235）。

## 10. 規則速查（Checklist）

- [ ] 訊號K線為盤中當下最高（空訊）或最低（買訊）K線，或其前一根為最高/最低
- [ ] RSI對應值為本波段「由升轉降」或「由降轉升」的真正相對高/低點（非途中臨時放大、非持平延伸）
- [ ] 下一根RSI值與前值差距達20以上（空訊為負20以上，買訊為正20以上）
- [ ] 盤中高低震幅逾30點（跳空情形逾40點），或屬跳空10點內可併入前日行情之特例
- [ ] 開盤第一根K線不作訊號判斷
- [ ] 訊號K線本身漲跌點數未過大（停損不致逾40點）
- [ ] 進場後設20點停損
- [ ] 訊號未確認前，未跌破空訊最低點／未突破買訊最高點，且收盤突破/跌破對側濾網線 → 停損並反手
- [ ] 訊號已確認延續後反轉 → 僅停損，不反手
- [ ] 反手位置距平盤未逾100點（非重挫盤）
- [ ] 訊號前進未達15點即折返回訊號K收盤 → 撤單平倉
- [ ] 訊號時間非接近收盤（否則僅作平倉依據）

    source: p.233
