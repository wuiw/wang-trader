# RSI穿越50買點 / RSI跌破50空點

> 一句話摘要：週KD確認多方（空方）區域後，用日線RSI是否由50下方向上穿越（由50上方向下跌破）50中軸，做為買點（空點）判斷工具。

## 1. 核心概念

- 週KD確認多方區域後，除了過一高之外，另一種常用工具是觀察日線RSI是否穿越50中軸，RSI由弱轉強穿越50，代表短線動能轉為偏多（p.76、80）。
- 空方鏡像：RSI由50上方向下跌破50，代表短線動能轉弱（p.76）。
- 對「跌勢較平緩」的個股，反彈幅度過小，RSI可能衝不上50之上，就不會產生RSI跌破50的空訊，此時須改用其他工具（如破一低）（p.101）。
- 空方訊號原書正式標題為「RSI破50空點」（p.96）。

## 2. 適用前提

- 週KD已確認黃金交叉（多方）或死亡交叉（空方），且已進入交叉後次一週。
- 多方：適用於行情推升較快、RSI能明顯穿越50時；若行情推升太快RSI來不及穿越50，改用過一高法（`gs-02-01`）（p.77）。
- 空方：需搭配基本面（月營收、季EPS、本益比）過濾放空標的的可行性（p.98–101，詳 `gs-02-00` 第7節）。

## 3. 訊號定義

### 多方（RSI穿越50買點，p.80–81）

- C1：週KD已於前一週確認黃金交叉（p.80：「98年11月下旬週KD出現金叉，隔週開始注意買進訊號」）。
- C2：日線RSI由50下方向上穿越50（p.80–81）。
- C3（品質判斷）：品質較佳的訊號是「前一根K線為最低點後，隔天馬上呈現RSI過50，而且K線實體屬中長紅」（p.81，圖2-6標示A、B、C）。
- C4（風險提示，非否定條件）：漲勢已持續一段時間（例如已在2個月內大漲一倍）時出現的RSI穿越50買訊，觸頂風險較高，即使進場也應嚴格用停損控管（p.81，圖2-6標示D）。
- C5（同位階濾網）：同一波推升過程若出現二次以上同位階（價位相近）的RSI穿越50買訊，只取最早出現者進場即可（p.82，圖2-7群光延伸案例：「其中A與B位置都有二次同位階的買訊出現，只要取最早出現進場即可」）。

### 空方（RSI破50空點，p.96–101）

- C0（前提濾網）：週KD死亡交叉後，行情須實際跌落到季線，或出現週KD背離向下現象，才開始考慮放空操作；若既沒有跌破季線、也沒有背離現象，極可能只是多頭市場中途的修正行為，**不宜看到黑影就開槍放空**（p.96）。
- C1：週KD已於前一週確認死亡交叉。
- C2：日線RSI由50上方向下跌破50（p.96–101，各圖文字框「RSI破50空點」）。
- C3（品質判斷）：訊號K線（或RSI跌破50當下）距離最近反彈峰點以「不超過2根K線」為合適，超過則不是合適的空點（p.98：「標示A及B位置為RSI破50的空點，但離峰位都超過2根K線以上，不是合適的空點」；p.97：「放空點位，愈接近反彈頂點K線愈能做到微幅停損」）。
- C4（風險提示）：若標的當季獲利已由盈轉虧（如晶電p.100–101首季虧損），RSI破50空點的可靠度較高；若獲利穩定、本益比偏低（如瀚荃p.99–100），即使RSI破50，放空報酬也可能有限（見 `gs-02-00` 第7節基本面過濾）。
- C5（限制條件）：對跌勢較平緩、反彈幅度過小的個股，RSI可能無法衝過50之上，也就不會產生RSI跌破50的空訊，此時應改用破一低法（`gs-02-01`）尋找空點（p.101）。
- C6（同位階濾網）：同一波反彈若出現二次以上價位相近的空訊，只取最早（或訊號品質較佳）者放空即可（p.96：「B及C價位差距不大，屬同階空點，只取B放空即可」）。
- C7（訊號優先權，與 `gs-02-01` 共用）：反彈頂點確認（K線不再創新高）後的**後2根K線內**，破一低與RSI破50兩種訊號哪一種先出現，就依哪一種進場放空，不須等待另一訊號同時成立；反彈速度快、空間大時，通常破一低較快產生（p.97，圖2-20瑞昱）。

## 4. 進場

- 多方：RSI由50下方穿越50當日，以當日（或當根K線）作為買進訊號日，若配合前一根K線為最低點、隔天RSI即穿越50且K線中長紅，訊號品質最佳（p.81）；同位階的重複訊號只取最早一次進場（p.82）。
- 空方：須先確認C0前提（已跌破季線或已現背離），RSI由50上方跌破50當日，以當日（或當根K線）作為放空訊號日，須同時檢查與最近反彈峰點的距離是否在2根K線以內（p.96、98）；若季線上方即放空（C0未完全成立但技術面已轉弱的過渡情況），須特別嚴格控管7%停損並留意突發翻多（p.96，圖2-19標示A）。
- 均以「隔週起才進場」為前提（見 `gs-02-00`）。

## 5. 停損

- 多方：最大停損設置7%水準（p.81：「即使在D位置進買單，最大停損設置7%水準，亦能小傷出場」）。
- 空方：**7%停損**，p.96原文已明確重述：「標示A在季線上方放空，要特別注意停損7%的設置並嚴格控制突發翻多出現」（此前因p.96–97缺頁僅能推論沿用全章框架，現已由補拍頁確認為原文明列，非推論）。

## 6. 出場 / 停利

- 多方：當週KD形成死亡交叉、進入空方區域，就不宜再留戀買進（p.81：「當標示3位置週KD形成死叉後，進入空方區域，就不宜再留戀買進」）。書中未提供RSI穿越50買點統一的移動停利機制，但有一條補充出場規則：**若週KD死亡交叉後，K值持續停留在超買區（80以上）鈍化游走而未立即反轉走弱**，此時若仍持股，應改依「是否跌破5日均線」或「5日均量線是否明顯縮減」做為出場判斷依據，而非機械式在死叉當下立即出場（p.82，圖2-7群光延伸案例）。
- 空方：確認前提濾網（C0，見第3節）；若未跌破季線也無背離，屬多頭中途修正而非反轉，不宜放空。書中在本節仍未提供RSI破50空點空方的統一移動停利機制，僅確認7%停損框架與訊號距峰點2根K線的品質過濾（p.96–98）；書中未明確說明空方出場/停利規則（原文未規定，此為2026-09-26補拍p.96–97後確認的結論，非因缺頁所致）。

## 7. 過濾：不做的情況

- 多方：漲勢已大幅推升（例如2個月漲一倍）後才出現的RSI穿越50買訊，觸頂風險高，應嚴設停損（p.81）。
- 空方：行情既未跌破季線、也無週KD背離向下現象時，即使週KD死叉，極可能只是多頭中途修正，不宜貿然放空（p.96）。
- 空方：RSI跌破50訊號距最近反彈峰點超過2根K線 → 不是合適的空點（p.96、98）。
- 空方：跌勢平緩、反彈幅度不足以讓RSI衝上50的個股，不會有此訊號，須改用破一低法（p.101）。
- 空方：基本面紮實（獲利穩定、本益比偏低）的個股，即使出現RSI破50空點，放空報酬有限，不宜執意放空（p.99–100，瀚荃案例）。

## 8. 範例解析

- **圖2-6（p.80–81，揚明光，3504）**：低點129.44，標示①②黃金交叉（98年11月下旬），Ⓐ隨後Ⓑ、Ⓒ為RSI穿越50買點，A、B、C三買點皆為前一根K線最低點後隔天RSI即穿越50、K線中長紅，品質良好；標示D位置雖也是RSI穿越50買訊，但因2個月已大漲一倍，最終遭停損，7%停損小傷出場；標示③（Ⓓ）週KD死叉後不宜再留戀買進，末端高點296.79。
- **圖2-7（p.81–82，群光，2385）**：均線空排接近尾聲時，週KD金叉（標示①②，Ⓐ）出現轉折可能，隨後Ⓑ「RSI穿越50買點」；p.82延續說明：季線與月線原呈空排、週KD亦呈空頭向下，6月中旬標示1位置週KD開始金叉；標示2區域價格越過季線連拉3根大漲K線後，於A、B、C三處出現RSI穿越50買訊，其中A、B為二次同位階買訊，只取最早出現進場即可；標示C之後週KD死叉，行情進入偏空可能，本例中週KD在超買區80以上鈍化游走，此時若持股改依「是否跌破5日均線」或「5日均量線是否縮減」判斷出場；末端Ⓒ週KD死亡交叉，高點83.5附近。示範「均線空排尾聲搭配週KD金叉」比單純價格急跌更能提高轉折判斷可靠度，並補齊了鈍化情形下的出場依據。
- **圖2-19（p.96，景碩，3189）**：96年除權後長期貼息，9月底週KD黃金交叉展開反彈，於除權日參考價下緣即壓回，11月中旬週KD死亡交叉（標示1），行情跌破季線，開始觀察反彈後放空時機，以RSI破50為切入參考；標示A~D皆為RSI在跌勢反彈過程中重新跌破50的空點，其中A在季線上方放空，須特別注意7%停損並嚴格控制突發翻多；B、C價位差距不大，屬同階空點，只取B即可；末端於停損位置出場，低點附近106.88，末端56.04。示範前提濾網（已跌破季線）成立時才進場、同位階濾網、季線上方放空的加嚴停損三項規則。
- **圖2-20（p.97，瑞昱，2379）**：100年11月第二週週KD死亡交叉（標示1），標示2起尋找空訊；標示A為破一低空訊（RSI在該次反彈中未曾越過50再折回，只能依破一低進場，見`gs-02-01`）；標示B、C、D為RSI破50空訊，但皆距反彈頂點超過2根K線，不符品質；示範「哪一種訊號先產生就據以進場」的優先權規則，並說明反彈速度快、空間大時，破一低訊號通常較快出現。
- **圖2-21（p.98–99，旺宏，2337）**：標示A、B為RSI破50空點，但距峰位超過2根K線，不合適；標示G改用破一低法提前放空；營收自100年10月起明顯衰退，101年2月雖回升仍低迷；標示C、D的RSI破50空點（其中C賭價格跌破季線，停損須嚴格控管）、標示E、F的RSI破50空點發生在首季EPS證實轉負之後，放空更順應趨勢；標示H、I在找不到RSI破50空點時改用破一低。此圖同時示範RSI破50法與基本面（營收、EPS）過濾的搭配使用。
- **圖2-22（p.99–100，瀚荃，8103）**：首季EPS 1.47元、營收逐月成長，全年獲利可達5元以上，101年5月週KD死叉、價格跌破季線，技術面轉空，但本益比僅8倍，作者評「線形轉劣勢，但放空卻討不到大利潤」——示範基本面紮實時不宜執意放空。
- **圖2-23（p.100–101，晶電，2448）**：營收成長但獲利衰退、毛利率大減，100年Q4轉虧、全年EPS僅0.56元；標示⑦週KD死叉超過1週以上且價格跌破季線，標示A為RSI破50空點，隨後4/26首季虧損消息見報，驗證放空邏輯；標示B為均線死叉後首次反彈結束的空點位置（屬 `gs-02-03` 日K值彎頭空點，一併出現在同圖中）。

## 9. 作者提醒與常見錯誤

- RSI穿越/跌破50法適合行情推升（下跌）較快、動能明顯的個股；跌勢平緩者RSI可能衝不上50，須換用破一低法（p.101）。
- 空方操作務必搭配月營收、季EPS、本益比等基本面資訊，否則技術面轉空未必能賺到大波段（p.98–100）。
- 漲勢已大幅推升後出現的多方RSI穿越50買訊，觸頂風險偏高，須嚴設停損（p.81）。
- 空方切入前務必先確認「已跌破季線」或「已現週KD背離」兩項前提之一，否則多屬多頭中途修正，貿然放空容易受挫（p.96）。
- 多方持股期間若遇週KD死叉但K值持續在超買區鈍化，應改依5日均線/均量線判斷出場，而非機械式在死叉當下砍出（p.82）。

## 10. 規則速查（Checklist）

多方（RSI穿越50買點）
- [ ] 週KD已於上週確認黃金交叉
- [ ] 日線RSI由50下方向上穿越50
- [ ] 前一根K線是否為最低點、隔天即穿越50、K線中長紅（品質判斷）
- [ ] 同位階重複訊號只取最早一次
- [ ] 已設7%初始停損
- [ ] 週KD尚未死亡交叉（若已死叉但K值鈍化於超買區，改依5日均線/均量線判斷出場）

空方（RSI破50空點）
- [ ] 已跌破季線，或已出現週KD背離向下（前提濾網C0）
- [ ] 週KD已於上週確認死亡交叉
- [ ] 日線RSI由50上方向下跌破50
- [ ] 訊號距最近反彈峰點在2根K線以內
- [ ] 同位階重複訊號只取最早（或品質較佳）一次
- [ ] 反彈頂點確認後2根K線內，破一低與RSI破50哪個先出現用哪個
- [ ] 已設7%初始停損（季線上方放空須特別嚴格）
- [ ] 已檢查月營收/季EPS/本益比等基本面是否支持放空
