# 日K值50以下打勾買點 / 日K值50以上彎頭空點

> 一句話摘要：週KD確認多方（空方）區域後，不必等日KD黃金交叉／死亡交叉，只要日K值在50以下出現「打勾」（先降後升的轉折）或在50以上出現「彎頭向下」，就可提早找到買點（空點）。

## 1. 核心概念

- 日KD要形成黃金交叉/死亡交叉，通常晚於K值本身出現轉折的時間點；直接觀察日K值在50以下的「打勾」現象（K值向下後立刻回升），可以不必等到日KD黃金交叉就提早找到買點，作者在另一本著作《期技期招》已有詳細說明，此處不再贅述（p.84）。
- 空方鏡像做法是日K值在50以上出現「彎頭向下」（K值向上後立刻反轉下彎），比等日KD死亡交叉更早提供放空訊號，其優勢在於「反彈峰點出現後，重新發動跌勢時，呈現乾脆俐落的尖頭轉折，是空方力道的強勢體現」（p.101–102）。

## 2. 適用前提

- 週KD已確認黃金交叉（多方）或死亡交叉（空方），且已進入交叉後次一週。
- 多方：訊號宜距離「谷點」（近期低點）不超過2根K線；空方：訊號宜距離「反彈峰點」不超過2根K線（雙邊皆同一過濾邏輯）。
- 空方另需搭配基本面（月營收、季EPS、本益比）過濾（見 `gs-02-00` 第7節）。

## 3. 訊號定義

### 多方（日K值50以下打勾買點，p.84–89）

- C1：週KD已於前一週確認黃金交叉（p.84）。
- C2：日KD的K值在50以下出現「打勾」現象（K值向下後回升）（p.84）。
- C3（品質判斷）：訊號距離谷點（近期低點）不超過2根K線為佳，即谷點產生後2日內出現打勾買點（p.84）；超過2根K線（例如第5根K線才出現打勾）品質不佳，可放棄該次訊號（p.86，圖2-11標示D）。
- C4（K線品質判斷）：若打勾當日對應的K線為黑K線，須忽略，或等隔日K線收盤過一高再確認進場（p.88，圖2-13標示B）。
- C5（風險提示）：股價位處季線之下時出現的打勾買點，須特別謹慎處理停損（p.88–89）。
- C6（背離觀察，非必要條件）：若行情推升穿越前波高點時週KD高度未同步墊高（週KD具背離向下跡象），則該波段找不到任何日KD 50以下打勾的買訊，可視為避開頭部買進的天然保護（p.87：「標示3開始的多方區域，找不到任何日KD指標在50以下打勾的現象，因此沒有買訊，有效避開頭部買進被停損可能性」）。
- C7（正常多頭結構判斷）：連續出現的打勾買點價位應「愈墊愈高」；若後一次買訊價位明顯低於前一次（例如C點遠低於B點），且發生在價格剛跌破季線之後，代表結構不正常，屬翻空前的最後反彈，此時應在反彈被季線壓回、又出現破一低時立刻出場，不宜視為正常買點加碼（p.87）。

### 空方（日K值50以上彎頭空點，p.101–107）

- C1：週KD已於前一週確認死亡交叉（框架前提，見 `gs-02-00`）。
- C2：日KD的K值在50以上出現「彎頭向下」現象（K值向上後反轉下彎）（p.101–102）。
- C3（品質判斷）：訊號距離反彈峰點不超過2根K線為合適；超過則不符合訊號品質要求，宜忽略（p.103，圖2-24標示C；p.105，圖2-25標示D）。
- C4（適用情境）：即使均線尚未出現死亡交叉，只要均線已呈收斂閉合現象，或行情已出現頭肩頂等反轉徵兆並跌破頸線，也可在日K值50以上彎頭向下時進場放空（p.102，圖2-24標示A）。
- C5（追加放空情境）：當均線已呈空排走勢後，反彈行情尾端再次出現日K值50以上彎頭向下，也可視為放空訊號，且通常更符合訊號品質要求（p.103，圖2-24標示B）。
- C6（搭配基本面）：若標的當季獲利已由盈轉虧、營收持續衰退，日K值彎頭空點的可靠度較高（p.102–103，陽明案例）；若獲利穩定、本益比偏低，放空報酬有限（見 `gs-02-00` 第7節）。

## 4. 進場

- 多方：日K值在50以下出現打勾當日（或當根K線），以當日/當根K線做為買進訊號日；若K線為黑K須忽略或等隔日過一高再確認（p.84、88）。
- 空方：日K值在50以上出現彎頭向下當日，以當日/當根K線做為放空訊號日，須同時檢查與反彈峰點距離是否在2根K線以內（p.101–102）。
- 均以「隔週起才進場」為前提（見 `gs-02-00`）。
- 加碼：同一波多方區域內，符合打勾條件、屬同一位階（價位相近）的訊號可取其一，其餘視為加碼買進位置，加碼部位比照原始部位設定停損／停利（p.89：「這些買訊都可視為加碼買進的位置，加碼部位的停損點可以使用階梯停利點，如果觸及則所有原始部位及各加碼部位皆一致出場」）。

## 5. 停損

- 多方：初始停損設在進場點下方7%位置（p.84：「谷點產生後，二日內出現打勾買點，初始停損則設在進場點下方7%位置」；p.88–89同樣採7%）。
- 多方（特定情境的替代停損）：也可用「前一低點被跌破」作為停損依據，例如圖2-11標示C位置，初始停損點設在標示H位置（前低），即使後續出現破一低（標示I），只要未跌破H點仍可續抱（p.86）。
- 空方：設好7%停損（p.104–105：「並設好7%的停損位置」）。

## 6. 出場 / 停利

- 多方：進場後可採「階梯出場機制」作為移動停利線（書中註明「請參閱交易訊號之直覺操作下冊」，本章未展開階梯出場機制的具體計算方式，原文未規定細節）；行情推升越過MA60（季線）後，可改用「大漲K線的低點」作為移動停利點依序上移（p.86）。
- 多方：加碼部位與原始部位共用同一停利／停損點（多為階梯停利線），一旦觸及則所有部位一併出場（p.89）。
- 多方：週KD死亡交叉出現時，須停止繼續找買點（不再新增進場），但既有部位若尚未跌破階梯停利線，仍可繼續持有，直到停利線被跌破才出場（p.86–87、89：「標示3出現週KD死叉必須停止買進動作，但在停利線未被觸及前，仍可繼續持有至標示H為止」）。
- 空方：進場後同樣採「階梯移動停利機制」，可持股（空單）至停利線被觸及（即K線收盤突破階梯停利線）時才回補出場（p.104–105：「從標示C開始的放空操作，採取階梯移動停利機制，可以持股至標示F位置才獲利出場」）。
- 空方：若價格已接近票面或明顯偏低，貼近歷史低檔、非年年虧損公司，繼續放空恐怕討不到大便宜，宜休兵另找標的（p.103，陽明案例：股價跌到11元附近已貼近票面）。

## 7. 過濾：不做的情況

- 多方：訊號距谷點超過2根K線 → 品質不佳，可放棄（p.86）。
- 多方：訊號K線為黑K，須忽略或隔日過一高再確認，不可直接以黑K當日進場（p.88）。
- 多方：連續買訊價位不正常降低（後一次明顯低於前一次）且發生在跌破季線之後，屬翻空前假訊號，應提高戒心（p.87）。
- 空方：訊號距反彈峰點超過2根K線 → 不符合品質要求，宜忽略（p.103、105）。
- 空方：股價已貼近票面或處於歷史低檔、公司非年年虧損 → 繼續放空報酬有限，宜休兵（p.103）。
- 空方：基本面紮實（獲利穩定、本益比偏低）的個股，即使日K值彎頭空點成立，放空討不到大利潤（p.99–100，`gs-02-00`第7節）。

- **圖2-11（p.85–86，凡甲，3526）**：低點起漲，價格翻越MA60（季線）為空翻多第一徵兆；98年10月中旬週KD黃金交叉（標示1），第二週起以日K值打勾找買點（標示A、B）；行情靠近MA60遭壓回、K線收盤跌破前一根K線低點（標示E、F）視為反彈結束的第一徵兆，須在此出場；隨後週KD死叉，停止多方操作；標示4再次金叉後，標示G處突破季線一日即又破一低轉下；標示C、D為日K值打勾買點，其中C位置初始停損設在標示H（前低），行情窄幅盤整期間即使出現破一低（標示I）仍以H點跌破才出場；行情越過MA60後可用大漲K線低點移動停利；標示D雖打勾但距谷點達5根K線，品質不佳，可放棄。
- **圖2-12（p.86–87，深圳新都酒店）**：標示1週KD金叉轉多，標示A為日K值打勾買訊；標示2週KD死叉后，若採大漲K線低點為停利點且未跌破，即使處於偏空環境仍可持有；標示3重新金叉，此時價格已突破前波高點，但週KD高度未同步墊高，構成「背離向下」，日KD在超買區死叉（標示F）具見頂先行表態；此段找不到任何日K值50以下打勾買訊，有效避開頭部買進；標示5金叉後標示B、C的打勾買訊中，C點價位明顯低於B點且發生在價格跌破季線後不久，屬翻空前假訊號，反彈遭季線壓回又破一低時應立刻出場；其後標示6~10交替出現金叉死叉，示範多空切換須逐次確認。

- **圖2-26（p.106–107，國賓，2704）**：陸客觀光概念股，EPS長年約1元；101年初週KD金叉，標示A~C為日K值50以下打勾買點；標示E創新高即壓回前波高點，為見頂先兆；標示F高點止於E點下方即拉回，隱含M頭疑慮；標示2週KD死亡交叉，加強反轉可能性，F點出現平行壓力破一低時應停利出場；行情跌破季線後於M頭頸線測試支撐，標示D位置日K值50以上彎頭向下，形成放空訊號。此圖同時示範同一標的先用打勾法作多、後用彎頭法作空的完整多空轉換。

## 9. 作者提醒與常見錯誤

- 訊號距轉折點是否在2根K線以內，是本方法多空兩側共同的品質門檻，超過即應放棄或降低信心（p.86、103、105）。
- 打勾/彎頭訊號對應的K線顏色（黑K須忽略或再確認）同樣是重要過濾條件（p.88）。
- 多方連續買訊若價位不合理走低（該漲的位階反而更低），要提高警覺，可能是翻空前的誘多（p.87）。
- 階梯出場機制是本方法多空兩側共通的停利工具，其詳細計算規則書中僅引用至《交易訊號之直覺操作下冊》，本章未展開（原文未規定細節）。
- 空方放空後應留意標的股價是否已貼近票面或歷史低檔，避免在報酬有限的位置繼續追空（p.103）。

## 10. 規則速查（Checklist）

多方（日K值50以下打勾買點）
- [ ] 週KD已於上週確認黃金交叉
- [ ] 日KD的K值在50以下出現打勾
- [ ] 訊號距近期谷點在2根K線以內
- [ ] 若訊號K線為黑K，已用隔日過一高再確認
- [ ] 已設7%初始停損（或以前低點為停損）
- [ ] 已規劃階梯移動停利／大漲K線低點移動停利
- [ ] 加碼部位與原始部位是否共用同一停利／停損點

空方（日K值50以上彎頭空點）
- [ ] 週KD已於上週確認死亡交叉（或均線已收斂/跌破頸線等替代確認）
- [ ] 日KD的K值在50以上出現彎頭向下
- [ ] 訊號距反彈峰點在2根K線以內
- [ ] 已設7%初始停損
- [ ] 已規劃階梯移動停利
- [ ] 已檢查股價是否已貼近票面/歷史低檔、公司獲利體質
