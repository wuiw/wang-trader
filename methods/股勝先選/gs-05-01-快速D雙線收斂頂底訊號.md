# 快速D(7)／快速D(45) 雙線收斂頂底訊號

> 一句話摘要：把快速D值（KD指標的K值）取 7 天期（短D）與 45 天期（長D）疊在同一視窗，當長D先進入嚴重超買（90附近）或超賣（10附近）區、短D隨後由內側逼近並與長D同步打勾／彎頭，即為波段頂底的高信賴度訊號；書中依短D與長D的相對走勢，再細分為「觸及收斂」「N型收斂」「外側交叉」三種子型態。

## 1. 核心概念

作者引用 John F. Clayburg《FOUR STEPS TO TRADING SUCCESS》一書提到的快速D值當沖策略（參數45及7、1分鐘K線），但強調重點不在於原策略是否可行、獲利回測高低，而在於「這兩條線的額外用途」——短D向長D逼近的收斂現象，是價格峰谷即將產生的重要徵兆（p.175）。

簡稱快速D(7) 為「短D」、快速D(45) 為「長D」。若軟體無法把兩條快速D值疊在同一視窗，可用一般 KD 指標的K值，分別取參數 7 及 45（p.176）。

## 2. 適用前提

- 商品：個股（宏達電2498、矽統2363、友勁6142、立錡6286、訊連5203、鴻海2317、創見2451、聯詠3034、廣宇2328等）（p.178-192、212-213）。
- 週期：日線（多數範例）。
- 三種子型態的共通前提：短D與長D必須有一方（甚至兩方）真正進入嚴重超買（90以上，最好95以上）或超賣（10以下，最好更低）區，才具備訊號效力；若兩者皆未真正抵達嚴重超買超賣區，訊號不成立（p.177、184、186）。
- 若短D、長D呈現鋸齒狀波動（來回打勾又彎頭），須引用 SAR 或 MA5 輔助濾網（詳見第7節）（p.189-192）。
- 若個股均線多排、長D持續鈍化在70以上（強勢股），觸頂收斂空訊可能只是小波高點，須先辨別是否為長線強勢股（詳見第9節）（p.187、192-193）。

## 3. 訊號定義

### 3.1 子型態一：峰谷觸及收斂訊號（p.176-180）

**觸底收斂（多方）**

1. C1：長D須先觸及 **20以下**，以 **10以下** 為佳（進入超賣區）（p.176）。
2. C2：短D必須由長D的**內側（右側）**向下逼近，兩者距離由大逐漸縮小；過程中不可出現距離放大發散，如有須放棄訊號（p.177）。
3. C3：短D須位在 **30以下**，最佳 **20以下**，愈貼近長D，谷點可靠度愈高（p.177）。
4. C4：短D與長D**同時打勾上揚**＝第一種買進訊號；若短D先打勾、長D未打勾，須等長D也打勾才確認買訊（p.177）。
5. C5（品質加分）：訊號當根若為中長紅K線，訊號品質較佳；若訊號本身為小漲K線，則更須切實執行停損（p.177）。

**觸頂收斂（空方，鏡像）**

1. C1'：長D須先觸及 **80以上**，以 **90以上** 為佳（進入超買區）（p.177）。
2. C2'：短D必須由長D的**內側（右側）**向上逼近，過程不可距離放大發散，如有須放棄訊號（p.177）。
3. C3'：短D須進入 **70以上**，最好 **80以上**（p.177）。
4. C4'：短D與長D**皆上達90以上、同向下彎**＝賣出訊號；距離高點在2根K線以內品質較佳。若短D先下彎、長D未彎，須等長D下彎才成立（p.177）。

### 3.2 子型態二：峰谷N型收斂訊號（p.181-183）

**N型觸底收斂（多方）**

1. C1：短D位在長D**左側**，兩者雙雙朝下滑行；短D先向上穿越長D形成黃金交叉，**但此時尚非買訊**（p.181）。
2. C2：短D進入長D內側（右方）並朝上穿越 **40以上**，此時短D與長D開口達到最大（p.181）。
3. C3：短D開始向下快速逼近長D，長D須進入嚴重超賣區（原文標示「接近90」，依上下文與全章慣例判斷應為「接近10」——見第12節待確認事項）（p.181）。
4. C4：短D與長D同時打勾向上＝買進訊號；若短D先打勾、長D仍朝下，須等長D也打勾才確認買訊；兩者距離收斂越小越好（p.181）。

**倒N型觸頂收斂（空方，鏡像）**

1. C1'：短D位在長D左側，向上穿越長D後向下跌破長D形成死亡交叉，**但此時尚非賣訊**（p.181）。
2. C2'：短D進入長D內側（右方）後，須維持向下跌至 **60以下**，再重新轉折向上並逼近長D，兩者距離由大變小（p.182）。
3. C3'：長D須進入超買區接近90（p.182）。
4. C4'：短D與長D**同時出現下彎**＝賣出訊號；若短D下彎、長D仍向上，須等長D完成下彎動作才確認賣出訊號（p.182）。

> 注意：若短D從長D外側跌破長D後，未繼續下跌到60以下即回頭與長D靠近，**不能**視為倒N型觸頂訊號的啟動點（p.183，圖5-7立錡範例：標示2的收斂不算，真正啟動點在標示3）。

### 3.3 子型態三：外側交叉峰谷訊號（p.184-188）

一般雙線指標（RSI黃金/死亡交叉、KD交叉、均線交叉、乖離率）都把交叉本身當作轉折訊號，但本節使用短D與長D交叉時，**特別限制必須在嚴重超買超賣區域內使用**，且要求短D與長D同時非常接近90或10（至少一方必須真正超過該界線）（p.184）。

1. C1（買訊/外側黃金交叉）：短D在長D**外側**向下，兩者先後抵達嚴重超賣區 **10**；短D向上與長D形成黃金交叉——這是**唯一允許**視為買進訊號的狀況（p.184）。
2. C1'（賣訊/外側死亡交叉）：短D在長D外側，兩者逐漸向上接近嚴重超買區 **90**；短D向下跌破長D形成死亡交叉——這是**唯一允許**視為賣出放空訊號的狀況（p.184-185）。
3. C2（必要條件）：短D、長D須**同在**嚴重超買超賣區最理想；若無法兩者皆達標，則必須一方已進入嚴重超買超賣區、另一方非常接近；若兩者皆無法抵達嚴重超買超賣區，**訊號不成立，應忽略**（p.186）。
4. C3（一致性要求）：黃金交叉必須短D長D**一致性打勾向上**；死亡交叉也必須短D長D**一致性彎頭向下**（p.186）。

## 4. 進場

- 三種子型態的訊號成立後，均以**訊號當根K線收盤**作為進場依據，但**訊號K線品質須符合要求**：
  - 買訊宜為中長紅K線；若為小星線、長上（下）影線的組合（如地火線），則延遲至出現合適的中長紅K線再操作（p.185，圖5-9友勁：延遲到隔月出現向上跳空紅K線才是真正進場買點）。
  - 賣訊宜為中長黑K線（p.182，圖5-6友勁：標示2打勾但為小黑K不符品質，隔日紡錘線也非中長紅仍須忽略，直到標示3出現漲停K線才確認N型觸底買訊；標示4彎頭訊號為長黑K線才形成賣出訊號）。
- 若當根K線收斂平順（4天以上平滑逼近），可直接以彎頭/打勾當根確認；若短D長D呈鋸齒狀（非平順），須改用 SAR 或前一根K線高低點來確認進場時機（詳見第7節）（p.189-192）。

## 5. 停損

- 進場後**設停損7%，或以谷點（底部）／峰點（頂部）為停損位置**（二擇一，書中並列，未規定優先順序）（p.178，圖5-2宏達電範例）。
- 放空觸頂收斂訊號時，因逆勢操作風險較高，務必設好 **7%停損**，以防指標呈現複雜的鈍化（p.180，圖5-4矽統範例）。
- 是否反手：本節未提及。

## 6. 出場 / 停利

- 買進後，行情往上漲即可運用「第一章提到的出場方式」進行**移動停利**（p.178）——本章原文僅以此帶過，未在第五章內重複列出四種移動停利工具的具體公式；讀者可交叉參考同系列《期貨奇績3》等書之移動停利工具說明，但**本節原文本身未展開，屬引用性質，非本章新增規則**。
- 觸頂收斂訊號本身也可作為多單的**出場（減碼／出場）訊號**，不一定要用於放空：尤其當長D呈現高檔鈍化（強勢股）時，觸頂收斂訊號僅代表短波拉回，可當作既有多單的短線出場點，之後再利用短D下跌後上勾時重新買進（p.187-188，圖5-11鴻海範例）。

## 7. 過濾：處理鋸齒狀波動（SAR／MA5輔助確認）

- 短D與長D在逼近收斂過程中若呈現一連串鋸齒狀波動（時而打勾、時而又彎頭），會造成研判困難，此時可用 **SAR** 作為輔助濾網：訊號K線須**收盤突破/跌破SAR**才確認訊號成立，單純影線觸及SAR不算（p.189、190）。
- 收斂過程平順滑動宜有 **4天以上**；若僅上2、3天即下彎、下彎1天後又恢復續高，屬於不平順的鋸齒狀，最好引用SAR或MA5輔助尋找可靠轉折點（p.189-190）。
- SAR延遲確認**不是無限期等待**：宜在 **5根K線內**得到具體訊號；超過5根K線仍未出現符合條件的突破/跌破SAR，應**放棄該次訊號**（p.191、192）。
- SAR參數：使用一般市場常見參數，並無特殊調整（p.190）。
- 選股建議：與其選擇判斷困難的鋸齒狀個股，不如優先選擇短D長D能平順滑行收斂的個股，避開不必要的再確認步驟（p.190）。

## 7.1 過濾／替代方案：改善鋸齒狀的慢速D值（p.212-214）

- 可用一般KD指標（慢速KD）的 **D值** 取代快速D值（K值），慢速D值波動較平順、雜訊較少，但**觸及嚴重超買超賣區的時間點比快速D值慢**，有時甚至觸及不到，導致無法產生訊號（p.212）。
- 範例：圖5-30廣宇——同一黃色區間，快速D值呈現鋸齒、產生3次打勾買訊，經4天平順濾網篩選後僅1次（標示3）符合；改用慢速D值，同區間內保持平順逼近收斂，僅在標示4出現1次打勾，形成買進訊號（p.212-213）。
- 兩種工具各有優劣：慢速D值可再進一步以EMA平滑；不論採用快速或慢速D值，基本判斷原則不變——向嚴重超買超賣區收斂逼近，再透過SAR、突破/跌破前一天K線高低點，或RSI穿越/跌破50來篩選訊號（p.213-214）。
- 慢速D值**僅適合長期大箱形區間震盪的個股**（指標進入鈍化階段時使用）；其即時性與敏感度不如快速D值（p.213-214，圖5-31廣宇範例：比較三線快速D值與三線慢速D值，慢速D值訊號位置較佳但反應較慢——該圖例延伸至三線法，交叉參考`gs-05-03`）。

## 8. 範例解析

- **圖5-2、圖5-3（宏達電2498，p.178-179）**：101年10月中旬，短D從外側逐漸逼近長D，長D進入10以下嚴重超賣區，10月底短D也觸及10以下，標示3位置長短D同時打勾轉折向上，當日K線收中紅K無過長上影線，形成典型觸底收斂買進訊號；設停損7%或以谷點為停損，其後運用第一章出場方式移動停利。圖5-3以RSI(5)與快速D比較尋底：RSI多次觸及超賣區（標示A、B）但難判斷哪次是真正低點，改用長短快速D的觸底收斂現象，一次即尋底成功（標示3對應RSI標示C位置），降低嘗試進場次數與交易風險。
- **圖5-4（矽統2363，p.180）**：98年10月中旬，短D從標示1向上快速逼近長D，距離由40收斂至5以內，標示3長D短D一致性彎頭，形成波段頂點反轉機率大增的賣出/放空訊號；因逆勢放空需設好7%停損，防止指標複雜鈍化。
- **圖5-6、圖5-7（友勁6142、立錡6286，p.182-183）**：友勁96年8月出現N型觸底：短D從外側穿越進入內側並上抵40以上，再下彎逼近長D，標示2兩線同時從10以下打勾向上，但訊號K線為小黑K（不符品質）、隔日紡錘線也非中長紅，須忽略，直到標示3出現漲停K線才確認N型觸底買訊；10月出現倒N型觸頂：短D外側死叉後長D仍上行，短D下探30以下，中旬再快速逼近長D並攻過70，標示4兩線一致性彎頭且訊號為長黑K線，確認倒N型觸頂空訊。立錡範例強調啟動點判斷：標示2的收斂不算（短D未先跌破後續跌至60以下），真正啟動點在標示3向上逼近，標示4長D進入90以上下彎、短D同步下彎才是標準倒N型觸頂點，且須等隔日黑K線才是進場位置。
- **圖5-9、圖5-10（友勁6142、訊連5203，p.185-186）**：友勁91年12月出現外側黃金交叉買訊，但當根K線帶極長下影線的地火線，不符品質，延遲至92年1月第二個交易日出現向上跳空紅K線才是真正進場買點。訊連範例強調嚴格條件：標示1外側黃金交叉但兩者未達嚴重超賣區10以下，不能認定為買訊；標示2、3兩者皆達90以上並形成一致性彎頭死亡交叉、訊號為黑K線，確認為賣出放空訊號；標示4外側黃金交叉但長D仍朝下（不符一致性打勾），亦非訊號；11月中旬出現的N型買進訊符合條件。
- **圖5-11、5-12（鴻海2317、創見2451，p.187-188）**：均線多排、長D鈍化在70以上（強勢股）時，觸頂收斂空訊可能只是小波高點，可進行「來回操作」（短線出場後伺機反手買回）；但當長D跌破70以下，代表趨勢可能真正反轉，不能再進行來回操作。創見範例補充：來回操作可持續進行，直到週KD死叉持續兩週才結束彈性操作；若週KD死叉只維持單週，來回操作仍可繼續。
- **圖5-13、5-14（訊連5203、立錡6286，p.189-192）**：短D長D呈鋸齒狀時引用SAR輔助確認，訊號K線須收盤突破/跌破SAR才確認；延遲確認限期5根K線內，超過則放棄該次訊號。
- **圖5-15（聯詠3034，p.192-193）**：強勢股（60日乖離率穿越10%）長D持續高檔鈍化，觸頂收斂空訊只提供1、2天短暫拉回即重新創高；作者提醒放空強勢股「事倍功半」，宜避開；若長D鈍化超過2個月以上（長線強勢股），須用更嚴苛濾網（短D與長D須全上90以上，長D甚至須達95以上）才進場逆向操作，並嚴格執行7%停損或改採過區間高點停損策略。
- **圖5-30、5-31（廣宇2328，p.212-213）**：兩線（快速D vs 慢速D）與三線（快速D vs 慢速D）的鋸齒對照範例，說明慢速D值可降低雜訊但延後訊號時間點（見第7.1節）。

## 9. 作者提醒與常見錯誤

- 短D、長D的逼近過程中若距離放大發散（不收斂），必須放棄該次訊號，不可牽強認定收斂已成立（p.177、182）。
- 遇到均線多排的強勢股，不應為了尋找放空高點而唱衰個股；應辨別是短線強勢股（1、2個月內即結束表演，觸頂收斂仍可有效偵測頂點）還是長線強勢股（鈍化逾2個月，需更嚴苛濾網），避免「空到老虎股」（p.187、192-193）。
- 收斂過程若鋸齒明顯，不代表訊號無效，而是需要額外的SAR或前一根K線高低點濾網來確認，且延遲確認要有限期（5根K線），不能無限期等待（p.191-192）。

## 10. 規則速查（Checklist）

- [ ] 長D須真正進入嚴重超買（90+）或超賣（10-）區
- [ ] 短D須由長D內側逼近，過程距離不可放大發散
- [ ] 依子型態（觸及收斂／N型收斂／外側交叉）核對對應條件
- [ ] 訊號K線品質：買訊宜中長紅、賣訊宜中長黑，不佳則延遲確認
- [ ] 若短D長D呈鋸齒狀：改用SAR或前一根K線高低點確認，5根K線內未確認則放棄
- [ ] 停損：7%，或以訊號谷點/峰點為停損
- [ ] 觸頂訊號出現但長D高檔鈍化（強勢股）：不追空，可考慮反手做多或忽略
- [ ] 出場：運用第一章移動停利工具（本章僅提及，未展開公式）
