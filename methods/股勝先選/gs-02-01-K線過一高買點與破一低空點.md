# 回檔後K線收盤過一高買點 / 反彈後K線收盤破一低空點

> 一句話摘要：週KD確認多方（空方）區域後，等價格回檔（反彈）再看K線收盤是否突破（跌破）前一根K線的最高點（最低點），以此當作切入買點（空點）。

## 1. 核心概念

- 這是週KD多方架構下最直覺的找買點方法：不必等RSI或KD指標轉折，只要K線收盤價「過一高」（突破前一根K線最高點），就視為多方力道重新啟動的訊號（p.76、77）。
- 空方鏡像做法是「破一低」：K線收盤跌破前一根K線最低點，視為空方力道重新啟動（p.76、92）。
- 適用時機：當RSI等其他指標因行情推升過快而來不及穿越50產生訊號時，可以改用過一高的方式找買點（p.77：「在行情推升快速，RSI無法出現穿越50產生買訊時，可以使用K線過前一根K線最高點的方式，尋找買進機會」）。
- **強勢股的優先工具**：若回檔過程中RSI指標無法跌破50以下就出現過一高現象，這種情形多發生在強勢股——推升猛、拉出大漲K線，回檔又偏好小黑K線壓盤、跌幅甚至不到5%即又重新展開攻勢；遇到這種強勢股，用過一高切入比用RSI過50切入法更能有效掌握較佳買點（p.82，圖2-8可成、圖2-9鈺象：兩檔股票在週KD金叉當週即強勢推升，回檔期間RSI始終無法跌破50，只能用過一高方式取得切入機會）。

## 2. 適用前提

- 週KD已確認黃金交叉（多方）或死亡交叉（空方），且已進入交叉後的次一週（見 `gs-02-00` 第2節框架）。
- 多方：適用於回檔後尋找買點；空方：適用於反彈後尋找空點。
- 距離最近轉折點（谷點/峰點）的根數是訊號品質的重要判斷依據（見第3節）。

## 3. 訊號定義

### 多方（過一高買點，p.77–79）

- C1：當週KD已於前一週確認黃金交叉（p.76、77）。
- C2：股價出現回檔（拉回）走勢後，某日K線收盤價突破「前一根K線最高點」（p.77）。
- C3：訊號K線須為紅K線（p.77：「訊號K線為紅K線」）。
- C4（品質判斷，非硬性條件）：訊號K線的「真實高點」定義——若前一根K線為跳空開低，其真實高點應取「前第二根K線的收盤位置」，而非該跳低K線本身的高點；不符合此定義的訊號不算過一高（p.79，圖2-5標示E的說明）。
- C5（品質判斷）：訊號K線距離回檔最低點的根數以「2根K線以內」為佳；出現後2天內產生買訊最能接受；也可以是最低點後續數根K線都在最低點K線的高低點範圍內震盪，等震盪結束後出現的訊號（p.78）。超過2根K線者品質較有疑慮（p.78，圖2-4標示3為第4根K線，品質存疑）。
- C6（品質判斷）：訊號K線若帶有瑕疵（例如過長上影線、漲幅過小(<1%)、或為小黑K線），可以等隔日K線收盤越過該瑕疵訊號K線最高點時再「補票上車」（p.78）。

### 空方（破一低空點，p.92–95）

- C1：當週KD已於前一週確認死亡交叉，或至少價格已跌破MA60（季線），縱使均線尚未死亡交叉也可嘗試（p.92：「標示A位置的空點，均線尚未形成死亡交叉…但已發生價格跌破MA60的情形」）。
- C2：股價出現反彈走勢後，某日K線收盤價跌破「前一根K線最低點」（破一低）（p.92）。
- C3（較嚴格做法）：反彈連續墊高三根以上K線後再破一低，訊號較可靠（p.92）。
- C4：訊號K線與最近峰點（反彈高點）距離「不超過2根K線」為合適的放空位置，超過2根K線不予採用（p.93圖2-16標示A：「距離最近高點超過二根K線 不符訊號品質」）。
- C5：若均線已呈現空排朝下運行，放空的勝算高於均線尚未死叉時（p.92）。
- C6：若空訊K線本身為紅K線，須忽略，或等隔日K線再創新低時才確認進場（p.94，圖2-17文字框：「空訊為紅K線 隔日創低再確認」）。
- C7（背離向下，提高把握度的加分條件，非必要條件）：若週KD死亡交叉後，價格仍創新高、但週K值小於週D值，即為「背離向下」，須等「價格創新高後，指標死亡交叉」才能認定背離發生（p.94–95）；出現背離向下時，若同時日KD指標在超買區死叉，具有見頂先行表態，是較積極的放空切入點（p.87）；但若價格之後翻過該最高頂點，須承認誤判並立即停損出場（p.87）。
- C8（不宜放空的情況）：若均線仍呈多排、開口未收斂、價格未跌破MA60，即使週KD死叉，也代表行情多屬於盤整區間而非反轉，放空風險偏高（p.93，圖2-16標示1）；此類情況下週KD死叉的作用僅在提醒操作者「停止操作」（停止做多），並非翻空訊號，須有更多濾網（背離、跌破MA60等）支持才能放空（p.91）。
- C9（訊號優先權，與 `gs-02-02` RSI跌破50空點共用）：反彈頂點確認（K線不再創新高）後的**後2根K線內**，破一低與RSI破50兩種空方訊號，哪一種先出現就依哪一種進場，不須等待另一訊號同時成立；反彈速度快、空間大的個股通常破一低較快產生（p.97，圖2-20瑞昱：標示A為破一低空訊，RSI在該次反彈中未曾越過50再折回，只能依破一低放空；標示B、C、D雖是RSI破50空訊但距反彈頂點已超過2根K線，不合品質）。

## 4. 進場

- 多方：回檔後，於K線「收盤」時確認已突破前一根K線最高點且為紅K，當根K線收盤價即為進場價（p.77、78）。
- 空方：反彈後，於K線「收盤」時確認已跌破前一根K線最低點，當根K線收盤價即為進場價（p.92）。
- 均以「隔週起才進場」為前提（週KD交叉當週不進場，見 `gs-02-00`）。
- 同一波多方區域內若有多次可買進的訊號點，書中建議「取前二次交易即可」，因為「不管多方區域是反彈或回升行情，價格愈高，訊號愈容易錯誤」（p.77）；價格接近的訊號點（例如圖2-5標示C、D）也只需取其一（p.79）。

## 5. 停損

- 多方：初始停損為「買進K線的停損7%」（p.79：「若買進K線的停損7%被觸及，則要出場停止操作」）。
- 空方：初始停損同樣採7%（p.92「7%停損位置」、p.93「隔二天被觸及7%停損」）。
- 空方另有K線層級停損：訊號K線收盤過一高，或價格越過該波峰點，即視為停損／出場條件（p.93：放空後若出現K線收盤過一高或越過峰點的狀況，立刻出場不宜再戰）。
- 加碼部位（若有）與原始部位共用同一停損／出場條件，一旦觸及則所有部位一併出場（此規則明確見於 `gs-02-03` 的階梯停利機制，過一高/破一低法本身未特別提及加碼機制，原文未規定）。

## 6. 出場 / 停利

- 多方：多方區域結束於週KD出現死亡交叉；死叉出現時，應了解價格將進入較長時間的整理或回跌走勢，宜出場觀望（p.77）。
- 空方：空方區域結束於週KD出現黃金交叉，代表停止繼續放空；原有空單若已觸及停損，須平倉（p.92–93）。**書中未明確說明金叉出現時，尚未觸及停損的既有空單是否須立即回補**，僅提到「停止放空」與「觸及停損須平倉」兩種情形（待確認，見第12節）。
- 除7%固定停損外，本方法本身未提供移動停利機制；若需要移動停利，書中在 `gs-02-03`（日K值打勾／彎頭方法）另有「階梯出場機制」可參考，但過一高/破一低法的原文段落沒有直接提及階梯停利（原文未規定）。

## 7. 過濾：不做的情況

- 多方：訊號K線距回檔最低點超過2根K線，品質存疑，應謹慎或放棄（p.78）。
- 多方：訊號K線的「真實高點」若受跳空開低影響而誤判，不應以該K線高點為基準（p.79）。
- 多方：波段末端（頭部區）任何買進動作都存在停損風險，不代表訊號永遠有效（p.78）。
- 空方：訊號K線距最近峰點超過2根K線，不採用（p.93、94）。
- 空方：均線仍呈多排、開口未收斂、價格未破MA60時，即使週KD死叉，放空風險偏高，行情多屬盤整而非反轉（p.93）。
- 空方：若在「三段式反彈格局」中，A波反彈結束的破一低空點容易在B波下壓後、C波反彈時被觸及停損，須在C波反彈結束再度出現破一低時重新放空（p.101，總結段落提及此為破一低法的已知缺點）。
- 空方：搭配基本面過濾（見 `gs-02-00` 第7節），基本面紮實者不宜執意放空。
- 多方：個股若採「進二退一」方式推升，或大漲一根K線後常需十天以上整理，過一高切入法容易陷入等待泥淖，選股時宜先觀察個股過去慣性，避開這類牛皮股（p.82–83）。

## 9. 作者提醒與常見錯誤

- 過一高/破一低訊號本身不難找，難在「品質判斷」：距轉折點根數、訊號K線顏色/漲幅、真實高低點的定義（跳空影響）都要一併檢查（p.78–79）。
- 空方操作最大的陷阱是「三段式反彈」造成的假破一低被軋停損，須有耐心等下一次反彈結束再進場（p.101）。
- 背離向下的判斷必須「先看到價格創新高，才能回頭確認死叉背離」，不能在死叉當下就先入為主認定背離（p.95）。
- 均線結構（是否收斂、是否跌破MA60）與週KD交叉須合併判斷，任一項未到位都會拉低放空勝算（p.92–94）。

## 10. 規則速查（Checklist）

多方（過一高買點）
- [ ] 週KD已於上週確認黃金交叉
- [ ] 股價已回檔
- [ ] 當根K線收盤突破前一根K線最高點，且為紅K
- [ ] 訊號K線距回檔低點在2根K線以內（或最低點後續K線都在其高低點內震盪）
- [ ] 若前一根K線跳空開低，已改用前第二根K線收盤點位判斷「真實高點」
- [ ] 已設7%初始停損
- [ ] 週KD尚未死亡交叉

空方（破一低空點）
- [ ] 週KD已於上週確認死亡交叉，或至少價格已跌破MA60
- [ ] 股價已反彈（較嚴格：連續墊高3根以上K線）
