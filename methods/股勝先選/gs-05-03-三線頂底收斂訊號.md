# 三線頂底收斂訊號（K(60)/K(120)/K(240)，另有週線版本）

> 一句話摘要：把快速D值（KD指標K值）擴充為三條，參數取60、120、240天（或週線102/52/26週），三線一致收斂進入嚴重超買（90附近）或超賣（10附近）區並同向打勾／彎頭時，可大幅壓縮波段頂底發生的可能時間範圍，且不需再考慮雙線法的N型結構或內外側交叉判斷。

## 1. 核心概念

`gs-05-01` 的雙線收斂法（短D 7天、長D 45天）可以擴充為三線收斂：改用三條快速D值，參數分別為 **60天、120天、240天**（大致對應3個月、6個月、12個月），只擷取三線一致朝嚴重超買或超賣區收斂的現象來鎖定最具可能性的峰谷區間，判斷流程比雙線法更簡化，因為不用再考慮N型結構或內外側交叉狀況（p.200）。

原理：假設 K(240) 抵達超賣區10以下可能長達30天（代表空方勢力最強期間），這30天內必有一天是真正的最低點；若再加入 K(120)，且 K(120) 比 K(240) 晚10天進入10以下、比 K(240) 提早5天脫離10以下，原30天的尋底期即可壓縮為15天；再加入 K(60)，若比 K(120) 晚5天離開10以下，三線同時在超賣區10以下的時間便只剩5天——透過大漲K線、RSI(5)確認，或SAR尋找突破K線，即可確認可靠的底部切入點（p.200-201）。三線進入超買超賣區的先後順序不一定固定（可能是K(240)先進入，也可能K(60)先進入），重點在於「三線同時位在嚴重超買超賣區」所代表的頂底最可能區域（p.203）。

## 2. 適用前提

- 商品：個股（精英2331、瑞智4532、景岳3164、大聯大3702、光寶科2301、鴻海2317、昆盈2365、友通2397、華夏1307）、加權指數（p.202-211）。
- 週期：日線為主；當個股跌破前一年區間最低點、日線三線鈍化時，改用**週線版本**：參數102週（2年）、52週（1年）、26週（半年）（p.209）。
- 須先了解各條K值觸及90/10的內涵：K(60)接近90代表當下為60天內最高點且收盤在最高點；K(120)觸及10以下代表可能跌破六個月價格區間最低點；K(240)觸及10以下代表可能跌破十二個月價格區間最低點（p.206）。
- 須搭配 **MA240（年線）** 的方向（朝上／朝下／走平）決定操作策略（詳見第3節濾網規則）（p.206-211）。

## 3. 訊號定義

### 3.1 基本三線收斂訊號

1. C1（底）：K(60)、K(120)、K(240) **三線同時**收斂至嚴重超賣區 **10以下**（p.200-201）。
2. C1'（頂）：K(60)、K(120)、K(240) **三線同時**收斂至嚴重超買區 **90以上**（p.200）。
3. C2：三線於收斂區間內**同向打勾**（底）或**同向彎頭**（頂）當天，即代表最可能的波段低點/高點發生時刻（p.201、203）。
4. C3（確認）：搭配大漲K線／大跌K線、RSI(5)超賣區打勾/超買區彎頭、或K線收盤突破/跌破SAR，作為切入買賣點的確認方式（p.201-202）。

### 3.2 單根反轉K線的例外規則（三線同向彎頭當天即放空/買進）

- 三線同向彎頭當天若要**逕行放空**（不必等隔日K線確認），必須出現**單根反轉K線**，例如：
  - 爆量長倒T線（長上影線）；
  - 開盤最高、收盤最低的**黑實帶**（黑K實體超過5%）；
  - 開低走低的**下墜線**（前一日為大漲K線）（p.204，並引用作者另一著作《股技期招》第一章K線反轉組合）。
- 若三線同向彎頭但**沒有爆量**，則**不宜當日逕行放空**，須等大跌K線出現才確認（p.204，圖5-23景岳範例）。

### 3.3 年線濾網規則（排除鈍化，區分多空策略）

4. C4（多頭濾網）：當 **MA240（年線）彎頭向下**行進時，三線收斂進入超賣區前，**必須有某一條K值曾從40以上開始向下進入超賣區**——此條件可排除K(240)或K(120)在低檔長期鈍化所造成的頻繁假訊號（p.207）。
5. C5（年線朝上時的買點簡化規則）：當年線朝上行時，買點**只須三線K值任一條觸及10以下打勾**即可，再以過一高、大漲K線，或SAR過濾訊號確認（p.211）。
6. C5'（年線朝下時的空點簡化規則）：當年線朝下行時，空點**只須三線K值任一條觸及90以上彎頭**即可，以破一低、大跌K線，或跌破SAR做為濾網（p.209、211）。
7. C6（週線切換條件）：若個股不斷破底、前一年區間最低點附近不見長線買盤簇擁，三線將在嚴重超賣區持續鈍化游走，此時宜改用**週線三線K值**（102/52/26週）協助尋底（p.208-209）。

## 4. 進場

- 三線同時收斂進入嚴重超買/超賣區、且同向打勾/彎頭後，依第3.1、3.2節的確認方式（大漲/大跌K線、RSI轉折、或SAR突破/跌破）決定實際進場時點（p.201-202）。
- 若年線方向已知（見3.3節），可直接採用簡化規則：年線朝上僅需**任一條**K值觸及10以下打勾即可視為買進訊號參考點（不必等三線全部到齊）；年線朝下僅需**任一條**K值觸及90以上彎頭即可視為放空參考點（p.209、211，圖5-28友通範例：標示A~H買點多為單一K值觸及10以下即成立）。
- 個股突破前一年度區間最高點後，若隨即橫向整理，不宜貿然依三線觸頂訊號放空——書中提醒此時做空無法獲取暴利，若股價再度突破前波高點，應**停損並反手買進**，改賺多頭漲勢的利潤（p.213，圖5-31廣宇範例）。

## 5. 停損

- 找到一次底部買點，進場操作的**風險設定在7%停損**（p.201）。
- 圖5-15聯詠強勢股放空範例（同`gs-05-01`第8節亦有引用）中提到嚴格條件下放空仍須嚴格執行7%停損，或改採**過區間高點停損策略**（p.193）——此規則原文置於雙線法段落，但邏輯上亦適用於三線法的放空操作，本節列為交叉參考，非本節原文重複規定。
- 除上述7%的通則外，各個別範例（精英、瑞智、景岳、大聯大、光寶科、鴻海、昆盈、友通、華夏）**未再逐一重複列出停損點數**。

## 6. 出場 / 停利

- 書中未針對三線收斂法明確說明統一的停利／出場規則。
- 可交叉參考3.3節C5/C5'的確認工具（SAR、過一高、破一低）在訊號成立時作為進場確認手段，但原文未將其定義為出場工具；本文件不推論擴充其用途。

## 7. 過濾：不做的情況

- 三線尚未真正抵達嚴重超買超賣區前，即使RSI等單一指標已顯示超買超賣，也**應忽略**，不逕行進場（p.204-205，圖5-24大聯大範例：RSI兩度觸及超賣區但只有一次成功反彈；三線齊備前的RSI訊號應忽略）。
- 三線同向彎頭但當日未爆量，不宜逕行放空（p.204）。
- 年線彎頭向下時，三線收斂進入超賣區前若**沒有任一條K值曾從40以上開始向下**，此收斂訊號應視為低檔鈍化的假訊號，不應進場（p.207-208，圖5-25光寶科範例：標示3~4之間的收斂買訊因不符此條件而未進場，隨後果然再破底）。
- 個股持續創新低、前一年低點無買盤支撐時，日線三線收斂訊號可能只是短暫反彈後再破底的雜訊，應改用週線三線協助判斷，而非直接採信日線訊號（p.208-209，圖5-26鴻海範例）。

## 8. 範例解析

- **圖5-21（精英2331，p.202-203）**：100年11月下旬K(240)（藍）先進入10以下，隨後K(120)（綠）進入且提早脫離，12月中旬K(60)（紅）最後進入且提早脫離，三線收斂在10以下共約7天（對應K線圖黃色框線區間），標示2位置三線同時在10以下時出現的大漲K線，視為買進訊號。
- **圖5-22（瑞智4532，p.203）**：100年9月中旬三線同時處於嚴重超買區90以上僅3天，三線同向下彎當天正好是最高點，K線呈現倒T線型態。
- **圖5-23（景岳3164，p.204）**：100年1月中旬三線在90以上收斂，標示1三線同向彎頭當日爆量、K線為天雷線（長上影線倒T型反轉線），形成單根反轉高點；6月出現的三線同向打勾（標示2~5，其中K(240)與K(120)黏合同行）皆為小星線，不具單根反轉能力，直到標示6出現大漲K線才確認買進訊號。
- **圖5-24（大聯大3702，p.204-205）**：100年9月下跌行情中，RSI(5)兩度觸及20以下超賣區（標示1、2），但只有標示2成功出現反彈；用三線觀察，標示1位置三線尚未達10以下不宜進場；10月初三線同向打勾但訊號K線皆為小星線，須再觀察（標示C跳空仍為小星線），直到10月底出現大漲K線才確認買點；11月標示3 RSI再度下探10以下（容易誘使搶短），但三線尚未齊備前應忽略此RSI訊號，下旬三線才同時進入嚴重超賣區並打勾，同時RSI也下探10，且K線為大漲K線，才確認買進訊號，之後展開更大幅度上漲。
- **圖5-25（光寶科2301，p.207-208）**：96年8月標示1三線10以下收斂同步向上的買進訊號，K(60)起始下探位置在90以上，此時年線走平、多空未定；到標示2的收斂買訊時MA240已開始向下，且價格已跌破12個月低點，切入買點後反彈無感、立刻標示A再度破底；標示3到標示4之間的三線收斂買訊皆未符合「須有一方位於40以上」的濾網規定，因此不應進場；直到標示5出現K(60)、K(120)上揚超過40以上再往下與K(240)收斂，才形成符合濾網規定的買進訊號。
- **圖5-26（鴻海2317，週線對照日線，p.208-209）**：100年初從101.75元跌到8月底55元（跌幅約5成），6月底日線在前一年區間最低點附近出現三線進入10以下打勾買訊，卻只短暫橫向、隨即再破底，三線鈍化在10附近；改用週線三線K值（102/52/26週）協助尋底，標示2黃色區塊為週三線10以下收斂，標示A大涨K線三線同步打勾，回頭對應日線標示B涨停K線進行買進，可有效避開日線指標鈍化。
- **圖5-27、5-28（昆盈2365、友通2397，p.209-210）**：年線彎頭向下的空頭市場中，不必尋底，可用「三線K值任一條觸及90以上彎頭」直接進行順勢放空；友通範例（96至101年跌幅達8成）標示1、10為三線90以上收斂彎頭的空點，標示2~9為任一條K值觸及90以上之空訊；標示A~H為買點，其中標示D因年線向上，僅需任一條K值觸及10以下即視為買進訊號參考點。
- **圖5-29（華夏1307，p.211）**：98至101年長期箱形震盪範例，標示1~6為放空訊號（其中標示2、4為年線下彎時K(60)觸及90下彎成立的空訊，標示1、3、5、6為三線90以上收斂彎頭空訊）；標示A~D為買進訊號（標示A、C年線朝上，任一條觸及10以上打勾即視為買訊；標示B、D為三線10以下收斂打勾買點，須以SAR或大漲K線過濾）。

## 9. 作者提醒與常見錯誤

- 三線收斂並非萬靈丹，遇到指標鈍化一樣會失靈，需搭配年線方向與「須有一方曾達40以上」的濾網規則來排除低檔鈍化假訊號（p.206-208）。
- 對於基本面不差、但被市場非理性追殺的個股（例如EPS 6元卻跌到本益比5倍），懂得用三線收斂法掌握底部發生區間，比用本益比猜合理價位更容易掌握進場時機（p.201-202）。
- 三線齊聚超買超賣區會持續多久時間，**無法在當下判斷**，須耐心等待三線同向打勾或彎頭那天出現（p.203）。

## 10. 規則速查（Checklist）

- [ ] K(60)/K(120)/K(240)（或週線102/52/26週）三線是否同時收斂至嚴重超買（90+）或超賣（10-）區
- [ ] 三線是否同向打勾（買）／彎頭（賣）
- [ ] 是否有大漲/大跌K線、RSI轉折或SAR突破/跌破確認
- [ ] 若要當日逕行放空：是否出現單根反轉K線（爆量倒T線／黑實帶／下墜線）
- [ ] 若年線向下：三線收斂進入超賣區前是否有一方曾從40以上下探（濾網），沒有則忽略訊號
- [ ] 若年線方向已知：可簡化為「任一條」K值觸及10以下（多，年線朝上）或90以上（空，年線朝下）
- [ ] 個股持續破底、日線鈍化：改用週線三線K值協助尋底
- [ ] 停損：7%
